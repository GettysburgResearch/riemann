## 1. Separate six different judgments

Every extracted result should retain distinct fields for source identity, source-coverage status, mathematical statement fidelity, input nonvacuity/applicability, proof/build status, and integration/publication disposition. In particular:

- a matching historical head is not a new scientific review;
- a PASS string or self-hash is not a primitive-source certificate;
- a proved generic helper is not its stronger canonical analytic packet;
- exact comparator type agreement does not establish that its input type is inhabited;
- compiling a conditional theorem does not discharge its hypotheses;
- accepting a research note does not license copied third-party material or authorize privileged CI.

The Xi half-node contradiction supplies a concrete reason for a **nonvacuity/applicability gate**, not an abstract request for more process.
