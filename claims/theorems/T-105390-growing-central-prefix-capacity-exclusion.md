# T-105390 — A polynomially growing central critical prefix cannot cause high-Xi capacity failure

Claim ID: `T-105390`  
Status: **MAJOR UNCONDITIONAL MESOSCOPIC LOCALIZATION — COMPLETE TAIL OPEN**  
Created: 2026-08-23  
Depends on: `T-105380`, `L-105389`, `L-105390`  
RH status: **unproved**

## 1. Fixed order and admissible prefix growth

Fix a matrix order `k>=1` and put

\[
\boxed{
d_k=3k(k-1)+4.}
\tag{T-105390.1}
\]

Choose any exponent

\[
\boxed{
0<\gamma_k<{1\over2(d_k+1)}
={1\over2(3k(k-1)+5)}.
}
\tag{T-105390.2}
\]

For a derivative order `r`, define

\[
J_r=\lfloor r^{\gamma_k}\rfloor.
\tag{T-105390.3}
\]

Use the scale `omega_r` and the first `J_r` positive critical pairs supplied by
`L-105389`.

## 2. Normalized source error

For either parity and either block `a in {0,1}`, let

\[
\widehat{\mathsf A}_{k,r}^{(a)}
=
\left[
{a_{m+n+a}(\Xi^{(r)})
 \over\omega_r^{2(m+n+a)}}
\right]_{m,n=0}^{k-1}.
\]

The real-saddle moment estimate and the rational source recurrences give

\[
\boxed{
\left\|
\widehat{\mathsf A}_{k,r}^{(a)}
-
\mathsf T_{k,p}^{(a)}
\right\|_{\rm op}
=
O_k\left(\sqrt{\omega_r/r}\right).
}
\tag{T-105390.4}
\]

Here `T_(k,p)^(a)` is the full unit-scale tangent or cotangent source matrix.

## 3. Growing-prefix critical error

Let `Chat_(k,r,J_r)^(a)` be the normalized critical matrix formed from the
first `J_r` actual critical pairs. By `L-105389`, with a rescaled window of
length comparable to `J_r`,

\[
\boxed{
\left\|
\widehat{\mathsf C}_{k,r,J_r}^{(a)}
-
\mathsf T_{k,p,J_r}^{(a)}
\right\|_{\rm op}
=
O_k\left({J_r\over\sqrt{r\omega_r}}ight).
}
\tag{T-105390.5}
\]

All those actual critical points are real and simple, and all their residues
are negative, for sufficiently high `r`.

## 4. The model tail beats both errors

The unused trigonometric tail is

\[
\mathsf R_{k,p,J_r}^{(a)}
=
\mathsf T_{k,p}^{(a)}
-
\mathsf T_{k,p,J_r}^{(a)}.
\]

By `L-105390`,

\[
\boxed{
\lambda_{\min}
\left(\mathsf R_{k,p,J_r}^{(a)}\right)
\ge c_{k,p}J_r^{-d_k}.
}
\tag{T-105390.6}
\]

Since `omega_r` is asymptotic to a constant multiple of `log r`, condition
(T-105390.2) gives

\[
J_r^{d_k}\sqrt{\omega_r/r}\longrightarrow0
\tag{T-105390.7}
\]

and

\[
{J_r^{d_k+1}\over\sqrt{r\omega_r}}
\longrightarrow0.
\tag{T-105390.8}
\]

Therefore the sum of the source and critical approximation errors is
`o(J_r^(-d_k))`, strictly smaller than the positive model-tail margin.

## 5. Growing-prefix capacity exclusion

Weyl's inequality yields, for both blocks and every sufficiently high
`r` of the chosen parity,

\[
\boxed{
\widehat{\mathsf A}_{k,r}^{(a)}
-
\widehat{\mathsf C}_{k,r,J_r}^{(a)}
\succ0,
\qquad a=0,1.
}
\tag{T-105390.9}
\]

Undoing the positive scaling congruence gives

\[
\boxed{
\mathsf C_{k,r,J_r}^{(a)}
\prec
\mathsf A_{k,r}^{(a)},
\qquad a=0,1.
}
\tag{T-105390.10}
\]

Thus a polynomially growing initial segment of the actual critical-residue
measure cannot overfill the fixed order-`k` Xi source space.

## 6. Explicit examples of the admissible exponent

The theorem permits any

```text
k=1: gamma < 1/10;
k=2: gamma < 1/22;
k=3: gamma < 1/46;
```

using the deliberately crude tail bound. Better conditioning estimates for the
trigonometric tail would enlarge these exponents.

## 7. Localization of every remaining high-tail failure

If the order-`k` source-critical capacity inequality fails for arbitrarily high
derivatives, the failure cannot be generated by the first `r^(gamma_k)`
central critical pairs. It must involve at least one of:

```text
critical cells with index beyond r^(gamma_k);
a nonreal or positive-residue event in that omitted region;
collective overfilling by the remote critical tail;
or a failure of the canonical window/exhaustion interface outside the
controlled rescaled strip.
```

The high-tail obstruction has been pushed from fixed central geometry into a
genuinely mesoscopic or global tail.
