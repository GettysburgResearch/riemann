# T-91720 — Moving-node Clark-entropy exhaustion with o(1/Y) error would prove RH

Claim ID: `T-91720`  
Status: **FULL CONDITIONAL RH PROPOSAL / RATE-CERTIFIED EXHAUSTION OPEN**  
Created: 2026-08-13  
Depends on: `L-91720/L-91721`, `R-91720`, `T-91620`  
RH status: **unproved**

For every dyadic annulus `j`, construct the arithmetic/source and
critical/stable model factors at the moving node

\[
\eta_j(Y)=\sqrt{a_{j-1}^2+Y^2}
\]

and prove the source-identified entropy ledger

\[
\mathscr L_j^{\rm arith}
=
\mathscr L_j^{\rm crit}
+
\mathscr L_j^{\rm st}
+
\Lambda_j^{\rm ann}
+
\mathscr L_j^{\rm aux},
\]

with all remainder terms nonnegative and

\[
\boxed{
\Lambda_j^{\rm ann}(\eta_j(Y))
+
\mathscr L_j^{\rm aux}(\eta_j(Y))
\le
\varepsilon_j(Y),
\qquad
\varepsilon_j(Y)=o_j(Y^{-1}).
}
\]

Then `L-91721` deletes every crossed zero in annulus `j`. If this holds for
all `j`, RH follows.

The theorem permits a nonzero finite-stage error. The load-bearing condition
is that the error be generated by the same source-to-model factorization and
decay faster than the optimized `1/Y` zero moat.
