# L-105422 — Source-weighted one-sided phase gap

Let `a_n>=0`, `x_n=log n`,

\[
C=\sum_na_nS_{x_n},\qquad A=\sum_na_n.
\]

For every real `theta`,

\[
\boxed{AI-\operatorname{Re}(e^{i\theta}C)\succeq\Gamma_L(a)I},
\]

where

\[
\Gamma_L(a)=\sum_na_n\left(1-\cos\frac\pi{\lceil L/x_n\rceil+1}\right).
\]

Moreover

\[
\boxed{
\Gamma_L(a)\ge\frac2{9L^2}
\sum_na_n\min\{(\log n)^2,L^2\}.}
\]

This is a strict phase estimate before physical collapse.
