The stopped Type-I boundary is

\[
\begin{aligned}
\mathcal T_{p,q}^{\rm bdry}(Y)
={}&\sum_{d,e\le U}
{\mu^{<q}(d)\mu^{<q}(e)\over de}

\end{aligned}
\tag{L-102881.1}
\]

with only support-active primes `ell` retained.

## 1. Exact squared-shift structure

Let

\[
(S_{\ell^2}f)(Y)=f(Y/\ell^2)
\]

and let `Pi_(<=ell)` restrict to the monoid generated by primes at most `ell`.
Each boundary owner is exactly

\[
\boxed{{1\over\ell}S_{\ell^2}\Pi_{\le\ell}.}
\tag{L-102881.2}

All fixed filters, owner projections and Euler/half-divisor/Wick gauges commute
with this shift.

## 2. Uniform per-squareclass coefficient bound

The support of `R_L` is contained in `[1,8]`.  For fixed `d,e,ell`, the active
`k` therefore lie in one interval of multiplicative length `sqrt(8)`, so

\[
\sum_{\substack{P^+(k)\le\ell\\R_L\ne0}}{1\over k}
\le 1+\frac12\log8.
\]

Also

\[
\sum_{d,e\le U}{1\over de}\ll(\log(2U))^2,
\qquad
\sum_{\ell\le\sqrt{8Y}}{1\over\ell}
\ll\log\log(3Y).
\]

Consequently

\[
\boxed{
|\mathcal T_{p,q}^{\rm bdry}(Y)|
\ll_R
(\log(2Y))^2\log\log(3Y),
}
\tag{L-102881.3}

uniformly in the external owners.  The same estimate holds for every fixed
additive owner phase and for the corresponding vector-valued one-octave kernel,
because the phases have unit modulus.

## 3. Exact scope

Equation (L-102881.3) closes the boundary's **fixed-squareclass coefficient
norm**.  It does not by itself bound coherent summation over all owner
squareclasses.  That coherent sum must remain inside the same phase/dispersion
theorem as the balanced Type-II row.

Thus `SCB102869` is not a new local analytic estimate, but neither is it deleted:
it is a polylogarithmic coefficient packet carried through the final coherent
owner theorem.  No recursive contraction or independent RH conclusion is
claimed here.
