## 1. Endpoint map

The finite shifted central operator sends an input supported through `Y` to an
analytic output supported through

\[
 H(Y)=\left\lfloor{Y+1\over2}\right\rfloor
 =\left\lceil{Y\over2}\right\rceil.
\tag{L-30503.1}
\]

Iterating gives

\[
\boxed{
 H^a(Y)=\left\lceil{Y\over2^a}\right\rceil.
}
\tag{L-30503.2}

Put `L_a=2^a`.

## 2. Exact aggregated endpoint weights

The initial positive stopped-power resolution has weights

\[
 \ell_Y=\log{Y+1\over Y},
 \qquad1\le Y<X.
\tag{L-30503.3}

For an interior endpoint `Z` at depth `a`, define the aggregate

\[
 \alpha_{a,Z}
 =\sum_{\substack{1\le Y<X\\H^a(Y)=Z}}\ell_Y.
\tag{L-30503.4}

If the complete preimage lies below `X`, namely `L_aZ<=X-1`, then

\[
 H^a(Y)=Z
 \iff
 L_a(Z-1)<Y\le L_aZ.
\]

The endpoint weights telescope exactly:

\[
\boxed{
 \alpha_{a,Z}
 =\log{L_aZ+1\over L_a(Z-1)+1}.
}
\tag{L-30503.5}

At the final truncated endpoint the same formula holds with `L_aZ` replaced by
`X-1`. In particular every aggregate coefficient is nonnegative.

## 3. Monotonicity and cumulative formula

The ratio in (L-30503.5) is

\[
 1+{L_a\over L_a(Z-1)+1},
\]

so `alpha_(a,Z)` is decreasing in `Z`. More importantly, for every complete
prefix,

\[
\boxed{
 \sum_{Z=1}^{M}\alpha_{a,Z}
 =\log(L_aM+1).
}
\tag{L-30503.6}

Thus the endpoint bank never becomes an arbitrary positive measure. At every
analytic depth it remains one exact affine-log layer.

## 4. Recombined complement profile

Fix a power exponent `s>0`. The analytic extension of every stopped power is
`x^(-s)`. After all endpoints with the same depth-`a` destination are added,
the complement profile appearing in the complete finite/infinite boundary is,
on integers,

\[
\boxed{
 h_{a,X,s}(n)
 =n^{-s}
  \log\!\left(
   \min\{L_a(n-1)+1,X\}
  \right).
}
\tag{L-30503.7]

(The closing bracket in the tag is typographical only.)

Indeed the endpoints strictly below `n` contribute the cumulative weight
(L-30503.6), capped by the total initial mass `log X`.

For `a=0`, equation (L-30503.7) reduces to the profile of `L-30502`:

\[
 h_{0,X,1/2}(n)=n^{-1/2}\log(\min(n,X)).
\]

## 5. Uniform derivative regularity

Use the continuous interpolation

\[
 h_{a,X,s}(x)
 =x^{-s}
 \log\!\left(
  \min\{L_a(x-1)+1,X\}
 \right),
 \qquad x\ge1.
\tag{L-30503.8}

Away from its single cap point, direct differentiation gives constants
`C_s,C'_s`, independent of `a,X`, such that

\[
\boxed{
 |h_{a,X,s}'(x)|
 \le C_s(1+\log X)x^{-s-1},
}
\tag{L-30503.9}

and, with `u=xh'`,

\[
\boxed{
 |u_{a,X,s}'(x)|
 \le C'_s(1+\log X)x^{-s-1}.
}
\tag{L-30503.10}

To see the uniformity, note that

\[
 {L_a\over L_a(x-1)+1}\le {1\over x-1}
 \le {2\over x}
 \qquad(x\ge2).
\]

The cap creates one derivative jump of size at most
`C_s X^{-s}`. Exactly the same disjoint-interval argument as in `L-30502`
handles it.

## 6. Uniform sparse-boundary consequence

Let

\[
 G_{a,X,s}=\mathscr C h_{a,X,s}.
\]

Repeating Sections 3--5 of `L-30502` with (L-30503.9)--(L-30503.10) gives

\[
\boxed{
 |G_{a,X,s}(2)|
 +\sum_{P=2^r}
  P|G_{a,X,s}(2P-1)-G_{a,X,s}(2P)|
 \le C_s''(1+\log X),
}
\tag{L-30503.11}

where `C_s''` is independent of the cascade depth `a` and endpoint `X`.

Thus every analytic-bank boundary generated by support halving has the same
logarithmic sparse Mersenne size. No endpoint-by-endpoint atomic norm is
required.

## 7. Consequence for the proof graph

PR #286 proves strict contraction of the analytic coefficient bank. Equation
(L-30503.11) shows that the boundary injected by that bank remains uniformly
logarithmic in the reciprocal-eta/Mersenne coordinate at every analytic depth.

Therefore an all-generation obstruction cannot come from loss of endpoint
regularity in the contracted analytic bank. It can only arise from the
subsequent propagation/recombination of the boundary bank itself.
