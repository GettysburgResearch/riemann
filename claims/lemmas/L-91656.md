# L-91656 — Corrected literal-score base and tail

Define

\[
E(u)=\sum_{2\le m\le u}\frac{\log m}{\sqrt m}\log\frac um,
\qquad
D(u)=E(u)-(5\sqrt u-3).
\]

On an arithmetic cell `N<u<N+1`,

\[
D'(u)=\frac1u\sum_{m=2}^{N}\frac{\log m}{\sqrt m}
       -\frac5{2\sqrt u}.
\tag{L-91656.1}
\]

For `N>=67`, the function `log(x)/sqrt(x)` is decreasing on `[8,infinity)`, so

\[
\sum_{m=2}^{N}\frac{\log m}{\sqrt m}
\ge\int_8^{N+1}\frac{\log x}{\sqrt x}\,dx.
\]

Using

\[
\int\frac{\log x}{\sqrt x}\,dx
=2\sqrt x\log x-4\sqrt x,
\]

the resulting lower bound exceeds `(5/2)sqrt(N+1)` at `N=67`; its excess is
increasing thereafter. Consequently

\[
\boxed{D'(u)>0\qquad(u>67).}
\tag{L-91656.2}
\]

The directed standard-library replay `X-91650` gives

\[
E(67)=39.2031645789172167\ldots,
\]

\[
5\sqrt{67}-3=37.9267638593622498\ldots,
\]

and hence

\[
\boxed{D(67)=1.2764007195549669\ldots>1.}
\tag{L-91656.3}
\]

The previously quoted `3.2764` used the wrong additive constant and is
withdrawn.

For a base datum, the positive declared-minus-literal score is therefore
confined to the compact interval `1<=u<=67`.

For a causal datum let `p>=67`, `r=p^{-1/2}`, and `v=u/p`. Its
literal-score shortfall is

\[
-[D(u)-rD(v)].
\]

If `v>=67`, then `u>=v`, `D(u)>=D(v)>0`, and

\[
D(u)-rD(v)\ge(1-r)D(v)\ge0.
\]

If `v<67`, the positive shortfall is bounded on the fixed compact child window;
more explicitly it is at most

\[
C_{\rm cau}=\max_{1\le v\le67}[5\sqrt v-3-E(v)]_+.
\]

Thus every base or causal generator has one absolute literal-score debt bound
per unit certificate coefficient.
