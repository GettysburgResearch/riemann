## 1. Evaluation row

Let

\[
L=\log c,
\qquad
\mu=\frac{L\gamma}{2\pi},
\qquad
x=\mu^2,
\]

and assume the nonresonance conditions

\[
\sin(L\gamma/2)\ne0,
\qquad
x\notin\{1^2,2^2,\ldots,N^2\}.
\]

In the orthonormal even Fourier basis

\[
e_0,\qquad
e_n=\frac{\delta_n+\delta_{-n}}{\sqrt2}\quad(1\le n\le N),
\]

the critical-line D-0001 evaluation row is

\[
\boxed{
 v_\gamma
 =s_\gamma
 \left(
 1,
 \frac{\sqrt2x}{x-1^2},
 \frac{\sqrt2x}{x-2^2},
 \ldots,
 \frac{\sqrt2x}{x-N^2}
 \right),
}
\tag{L-20701.1}
\]

where

\[
\boxed{
 s_\gamma=-\frac{2\sin(L\gamma/2)}{\gamma\sqrt L}.
}
\tag{L-20701.2}
\]

This is an identity: substitute
\(\mu=L\gamma/(2\pi)\) into the released full-coordinate Cauchy formula and
combine the \(n\) and \(-n\) coordinates.

## 2. Fixed column transform

Put

\[
a_n=n^2.
\]

For the normalized row \(q(x)=s_\gamma^{-1}v_\gamma\),

\[
\frac{q_n(x)}{\sqrt2}
=\frac{x}{x-a_n}
=1+\frac{a_n}{x-a_n}.
\]

Therefore the fixed invertible column operation

\[
q_0\longmapsto1,
\qquad
q_n\longmapsto
\frac{q_n/\sqrt2-q_0}{a_n}
\]

turns the row into

\[
\boxed{
C(x)=\left(1,\frac1{x-a_1},\ldots,\frac1{x-a_N}\right).
}
\tag{L-20701.3}
\]

Thus every finite critical-line frame is, up to exact diagonal row scaling and
one support-independent column transform, a Cauchy–Vandermonde matrix.

## 3. Determinant

For distinct nonresonant nodes \(x_0,\ldots,x_N\), let

\[
C_{i0}=1,
\qquad
C_{in}=\frac1{x_i-a_n}.
\]

Then

\[
\boxed{
\det C
=(-1)^{N(N+1)/2}
\frac{
 \displaystyle
 \prod_{0\le i<j\le N}(x_j-x_i)
 \prod_{1\le m<n\le N}(a_n-a_m)
}{
 \displaystyle
 \prod_{i=0}^N\prod_{n=1}^N(x_i-a_n)
}.
}
\tag{L-20701.4}
\]

In particular, distinct nodes and pole avoidance are already a complete
invertibility certificate. A generic numerical singular-value computation is
not needed.

### Proof

Multiply row \(i\) by

\[
P(x_i)=\prod_{n=1}^N(x_i-a_n).
\]

The resulting columns are the degree-\(N\) polynomials

\[
P(x),\qquad \frac{P(x)}{x-a_1},\ldots,\frac{P(x)}{x-a_N}.
\]

Their coefficient determinant is the Vandermonde product in the \(a_n\), with
sign \((-1)^{N(N+1)/2}\). Evaluation at the \(x_i\) contributes the
Vandermonde product in the \(x_i\). Divide by the row multipliers. QED.

## 4. Explicit structured inverse

Let

\[
F(x)=b_0+\sum_{n=1}^N\frac{b_n}{x-a_n}
=\frac{H(x)}{P(x)},
\qquad
\deg H\le N.
\]

Given data

\[
F(x_i)=y_i,
\]

we have

\[
H(x_i)=y_iP(x_i).
\]

Let

\[
\ell_i(x)
=\prod_{j\ne i}\frac{x-x_j}{x_i-x_j}.
\]

Then

\[
\boxed{
H(x)=\sum_{i=0}^Ny_iP(x_i)\ell_i(x).
}
\tag{L-20701.5}
\]

The constant-at-infinity coefficient and residues are therefore

\[
\boxed{
 b_0
 =\sum_{i=0}^N
 \frac{y_iP(x_i)}{\prod_{j\ne i}(x_i-x_j)},
}
\tag{L-20701.6}
\]

and

\[
\boxed{
 b_n
 =\frac{H(a_n)}{P'(a_n)}
 =\frac1{P'(a_n)}
 \sum_{i=0}^Ny_iP(x_i)\ell_i(a_n).
}
\tag{L-20701.7}
\]

Every operation is a product, sum, and division by a separately certified
nonzero interval. This is the proof-facing inverse.

## 5. Explicit first-frame kernel

Select only \(m=N+1-r\) distinct rows with nodes
\(z_1,\ldots,z_m\). A vector in their kernel corresponds to a numerator
\(H\) divisible by

\[
Q_Z(x)=\prod_{i=1}^m(x-z_i).
\]

Hence

\[
\boxed{
H(x)=Q_Z(x)R(x),
\qquad
\deg R\le r-1.
}
\tag{L-20701.8}
\]

The selected-zero kernel has dimension exactly \(r\), with the explicit
rational basis

\[
\boxed{
\Phi_k(x)=\frac{x^kQ_Z(x)}{P(x)},
\qquad 0\le k<r.
}
\tag{L-20701.9}
\]

Thus the first frame requires no inversion at all.

## 6. Conditional second frame

Choose distinct additional nodes \(y_1,\ldots,y_r\), disjoint from \(Z\) and
from the poles. On the basis (L-20701.9), the conditional evaluation matrix is

\[
S_{jk}
=s_{y_j}
\frac{Q_Z(y_j)}{P(y_j)}y_j^k.
\]

Therefore

\[
\boxed{
\det S
=
\left(
 \prod_{j=1}^r
 s_{y_j}\frac{Q_Z(y_j)}{P(y_j)}
\right)
\prod_{1\le i<j\le r}(y_j-y_i).
}
\tag{L-20701.10}
\]

Any distinct nonresonant second block frames the kernel. More strongly, replace
\(x^k\) by the Lagrange cardinal polynomials of the \(y_j\); then the
conditional evaluation matrix is exactly the identity.

For \(r=1\), the complete kernel is generated by

\[
\boxed{
F_Z(x)=\frac{Q_Z(x)}{P(x)},
}
\tag{L-20701.11}
\]

and the conditional second-frame scalar is simply

\[
\boxed{
s_yF_Z(y).}
\tag{L-20701.12}
\]
