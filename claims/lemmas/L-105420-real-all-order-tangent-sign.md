# L-105420 — Real frozen all-order tangent sign

For real `L>0`, the resolvent

\[
R_L=\sum_{k\ge0}L^{-k-1}\Lambda^{*k}
\]

has nonnegative coefficients. If

\[
C(N;L+\delta)=\sum_{r\ge0}e_r(N)\delta^r,
\]

then

\[
\boxed{e_r=(-1)^rC_J*R_L^{*r}},
\qquad
\boxed{(-1)^re_r(N)\ge0}.
\]

For squarefree `n=p_1...p_k`,

\[
\boxed{
e_r(L;n)=(-1)^r\frac{(k+r-1)!}{r!}
\frac{\log n\prod_j\log p_j}{L^{k+r}}.}
\]

The real Hardy/Z-prime tangent has no Euler-parity oscillation; only physical
phases remain signed.
