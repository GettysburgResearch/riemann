## 1. All-depth endpoint profile

Fix

\[
 a\ge0,
 \qquad L=2^a,
 \qquad s\ge\frac12.
\]

PR #309 proves that after every initial stopped endpoint which lands at the same
depth-`a` destination is recombined, the analytic complement profile is

\[
\boxed{
 h_{a,X,s}(x)
 =x^{-s}
 \log\!\left(
  \min\{L(x-1)+1,X\}
 \right),
 \qquad x\ge1.
}
\tag{L-30902.1}

Let

\[
 G_{a,X,s}(q)
 =\sum_{k\ge1}
 \left[
 h_{a,X,s}(2kq-1)
 -h_{a,X,s}((2k+1)q)
 \right]
\tag{L-30902.2}

be its shifted-central boundary injection.  The pairs converge absolutely.

## 2. Uniform derivative data

Put

\[
 u_{a,X,s}(x)=x h_{a,X,s}'(x).
\]

The exact affine-log formula gives constants `A_s,B_s`, depending only on `s`,
such that away from the single cap point

\[
\boxed{
 |h_{a,X,s}'(x)|
 \le A_s(1+\log X)x^{-s-1},
}
\tag{L-30902.3}

and

\[
\boxed{
 |u_{a,X,s}'(x)|
 \le B_s(1+\log X)x^{-s-1}.
}
\tag{L-30902.4}

The cap lies at

\[
 x_*=1+\frac{X-1}{L}.
\tag{L-30902.5}

The one-sided derivatives give the exact jump

\[
\boxed{
 |[u]_{x_*}|
 =\frac{Lx_*^{1-s}}X.
}
\tag{L-30902.6}

Since `L(x_*-1)+1=X`,

\[
 |[u]_{x_*}|
 \le2x_*^{-s}
\tag{L-30902.7}

for every nontrivial cap `x_*>=2`.  Every constant is independent of the depth
`a` and endpoint `X`.

## 3. Derivative of the shifted boundary

Treat `q` as real.  At ordinary differentiability points, put

\[
 A_k=2kq-1,
 \qquad B_k=(2k+1)q.
\]

As in `L-30901`,

\[
\begin{aligned}
 G_{a,X,s}'(q)
 =\frac1q\sum_{k\ge1}
 \left[
 u(A_k)-u(B_k)+h'(A_k)
 \right].
\end{aligned}
\tag{L-30902.8}

The intervals `[A_k,B_k]` are disjoint for fixed `q`.  The smooth part of one
pair is bounded by (L-30902.3)--(L-30902.4), and at most one pair contains the
cap.  Since

\[
 A_k\ge kq,
 \qquad B_k-A_k=q+1\le\frac32q,
\]

one obtains

\[
\boxed{
 |G_{a,X,s}'(q)|
 \le
 C_s(1+\log X)q^{-s-1}
 +\frac{|[u]_{x_*}|}{q}
  \mathbf1_{\{\text{one pair crosses }x_*\}}.
}
\tag{L-30902.9}

The indicator prevents the cap jump from being charged once for every dilation
leg at the same output coordinate.

## 4. Weighted adjacent variation

Let

\[
 M_a=\left\lfloor\frac{x_*+1}{2}\right\rfloor
\]

be the natural output support of the boundary.  Integrating (L-30902.9) across
every unit interval and summing gives

\[
\begin{aligned}
 \sum_{n=2}^{M_a-1}
 \sqrt n\,|G(n+1)-G(n)|
 &\le
 C_s(1+\log X)
 \sum_{n=2}^{M_a}n^{-s-1/2}\\
 &\quad+
 |[u]_{x_*}|
 \sum_{n=2}^{M_a}n^{-1/2}.
\end{aligned}
\tag{L-30902.10}

The second line deliberately drops the crossing indicator.  This avoids any
false claim that one fixed dilation index can cross the cap for only one output
integer.

For the smooth term,

\[
 \sum_{n=2}^{M_a}n^{-s-1/2}
 \le
 \begin{cases}
  C(1+\log X),&s=1/2,\\
  C_s,&s>1/2.
 \end{cases}
\tag{L-30902.11}

For the cap term, (L-30902.7) and `M_a<=x_*` give

\[
\begin{aligned}
 |[u]_{x_*}|
 \sum_{n=2}^{M_a}n^{-1/2}
 &\le Cx_*^{-s}\sqrt{x_*}\\
 &=Cx_*^{1/2-s}\\
 &\le C,
\end{aligned}
\tag{L-30902.12}

because `s>=1/2`.

The final endpoint coefficient is bounded by the same paired formula. Hence

\[
\boxed{
 \sum_{n=2}^{M_a}
 \sqrt n\,|G_{a,X,s}(n)-G_{a,X,s}(n+1)|
 \le
 \begin{cases}
  C(1+\log X)^2,&s=1/2,\\
  C_s(1+\log X),&s>1/2,
 \end{cases}
}
\tag{L-30902.13}

uniformly in the analytic depth `a`.

## 5. Explicit central-flow certificate

Put the signed coefficient

\[
 d_{a,X,s}(n)
 =G_{a,X,s}(n)-G_{a,X,s}(n+1)
\tag{L-30902.14}

on the central split `[n,floor(n/2)]`.  Then

\[
\boxed{
 L(d_{a,X,s})
 =G_{a,X,s}-\mathcal T G_{a,X,s}
}
\tag{L-30902.15}

and, because every central split has capacity at most `2sqrt(n)`,

\[
\boxed{
 \mathcal N_\omega(d_{a,X,s})
 \le
 \begin{cases}
  C(1+\log X)^2,&s=1/2,\\
  C_s(1+\log X),&s>1/2.
 \end{cases}
}
\tag{L-30902.16}

The remaining load is supported at a strict half scale.
