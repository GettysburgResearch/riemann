## 1. Fix one balanced split policy

For every parent `n>=2`, fix a probability law `pi_n` on the declared balanced splits `j+(n-j)=n`. Let `P_n(k)` be its size-biased selected-child kernel from `L-33107`:

\[
P_n(k)=\sum_j\pi_n(j)
\left[{j\over n}\mathbf1_{k=j}
+{n-j\over n}\mathbf1_{k=n-j}\right].
\tag{L-33108.1}
\]

The chain is strictly descending.

Retain the exact capacity potential

\[
\mathcal G(n)=\sum_{q=2}^n{1\over\sqrt q}
\left\lfloor{n\over q}\right\rfloor,
\]

whose split defect is

\[
\delta_{\mathcal G}(n,j)=\omega_{n,j}.
\]

Normalize

\[
g(n)={\mathcal G(n)\over n}.
\]

Its one-step policy drift is

\[
\boxed{
 d_{\mathcal G}(n)
 :=g(n)-P_ng
 ={1\over n}\sum_j\pi_n(j)\omega_{n,j}>0.
}
\tag{L-33108.2}

By `L-27205.3`, on a fixed balanced cone

\[
\boxed{
 {c_\eta\over\sqrt n}
 \le d_{\mathcal G}(n)
 \le {2\over\sqrt n}.
}
\tag{L-33108.3}

## 2. Any exact dual has fractional policy drift

Let `F` be any feasible Cycle-Debt dual:

\[
0\le\delta_F(n,j)\le\omega_{n,j}
\]

on every allowed split, with `F(1)=0`. Put

\[
f(n)={F(n)\over n}.
\]

Exactly as in `L-33103`, averaging the split defect under `pi_n` gives

\[
\boxed{
 d_F(n):=f(n)-P_nf
 ={1\over n}\sum_j\pi_n(j)\delta_F(n,j).
}
\tag{L-33108.4}

Thus

\[
\boxed{
0\le d_F(n)\le d_{\mathcal G}(n).
}
\tag{L-33108.5}

Since `d_G(n)>0`, define

\[
\boxed{
\theta_F(n)={d_F(n)\over d_{\mathcal G}(n)}\in[0,1].
}
\tag{L-33108.6}

Then

\[
\boxed{
d_F(n)=\theta_F(n)d_{\mathcal G}(n).
}
\tag{L-33108.7}

This is not an approximation: every feasible dual determines one statewise capacity-allocation fraction for **every** chosen split policy.

## 3. Exact Markov potential representation

The recursion

\[
f=d_F+Pf,
\qquad f(1)=0,
\]

terminates after finitely many steps. Therefore

\[
\boxed{
 f(n)=\mathbb E_n
 \sum_{0\le t<\tau_1}
 d_F(N_t)
 =\mathbb E_n
 \sum_{0\le t<\tau_1}
 \theta_F(N_t)d_{\mathcal G}(N_t),
}
\tag{L-33108.8
}

where `N_t` is the selected-child chain and `tau_1` its hitting time of node one.

Likewise

\[
\boxed{
 g(n)=\mathbb E_n
 \sum_{0\le t<\tau_1}d_{\mathcal G}(N_t).
}
\tag{L-33108.9
}

Thus the full dual interval `0<=delta_F<=omega` is, after fixing a policy, an adaptive occupation of the single positive capacity drift.

No assertion that an arbitrary choice of `theta(n)` satisfies all individual split inequalities is needed; only the forward representation of every genuine dual is used.

## 4. Pair with the exact critical source

Let `r_X` be the critical target divergence and put

\[
s_n=nr_X(n).
\]

Let `M` be the signed Green occupation of this same policy:

\[
\boxed{
M-MP=s,
\qquad
M=s(I-P)^{-1},
}
\tag{L-33108.10
}

as in `L-33107`.

Since `F(n)=nf(n)`, the target pairing is

\[
\langle r_X,F\rangle=\sum_ns_nf(n).
\]

Using `f=(I-P)^{-1}d_F`, finite matrix multiplication gives the exact identity

\[
\boxed{
\langle r_X,F\rangle
=\sum_nM_nd_F(n)
=\sum_nM_n\theta_F(n)d_{\mathcal G}(n).
}
\tag{L-33108.11
}

Hence the Cycle-Debt dual objective is

\[
\boxed{
-\langle r_X,F\rangle
=-\sum_nM_n\theta_F(n)d_{\mathcal G}(n).
}
\tag{L-33108.12
}

## 5. One-policy upper bound for the full optimized debt

Because `0<=theta_F<=1` and `d_G>=0`,

\[
- M_n\theta_F(n)d_{\mathcal G}(n)
\le(-M_n)_+d_{\mathcal G}(n).
\]

Taking the maximum over **all** feasible duals and using exact finite LP duality from `L-27205` gives

\[
\boxed{
\mathfrak N_\eta(X)
\le
\sum_{n=2}^X(-M_n)_+d_{\mathcal G}(n).
}
\tag{L-33108.13
}

The right side is exactly the negative capacity debt of the signed split flow generated by the chosen policy. Indeed, with

\[
D_n={M_n\over n},\qquad d_{n,j}=D_n\pi_n(j),
\]

one has

\[
\begin{aligned}
\sum_{n,j}\omega_{n,j}(-d_{n,j})_+
&=\sum_n{(-M_n)_+\over n}
 \sum_j\pi_n(j)\omega_{n,j}\\
&=\boxed{
\sum_n(-M_n)_+d_{\mathcal G}(n).}
\end{aligned}
\tag{L-33108.14
}

Thus primal and dual upper bounds coincide in one Markov coordinate.

## 6. Immediate consequences

For any explicit cofinal policy:

1. if `M_n>=0` for every node, then
   \[
   \mathfrak N_\eta(X)=0,
   \]
   so exact nonnegative balanced carry saturation holds;
2. if
   \[
   \sum_n(-M_n)_+d_{\mathcal G}(n)=X^{o(1)},
   \]
   then Cycle Debt is subpower and the existing prime-ramp/Landau consumer gives RH;
3. by (L-33108.3), it is enough on a fixed balanced cone to prove the scale-equivalent bound
   \[
   \sum_n{(-M_n)_+\over\sqrt n}=X^{o(1)}.
   \]

This is precisely the size-weighted Markov form of the earlier BTF negative-variation target.
