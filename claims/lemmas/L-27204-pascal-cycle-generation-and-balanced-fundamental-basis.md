## 1. Split chain complex

Fix `X>=2`. For

\[
2\le n\le X,
\qquad
1\le j\le \lfloor n/2\rfloor,
\]

write `[n,j]` for the unordered split of `n` into `j` and `n-j`. Define

\[
\boxed{
\partial[n,j]=e_n-e_j-e_{n-j},
}
\tag{L-27204.1}
\]

with the central child counted twice. The image lies in

\[
\mathcal H_X=
\left\{r\in\mathbb R^X:
\sum_{m=1}^X m r_m=0
\right\}.
\tag{L-27204.2}
\]

The unit splits

\[
h_n=[n,1],\qquad 2\le n\le X,
\tag{L-27204.3}
\]

have triangular divergences `e_n-e_1-e_(n-1)` and form a basis of
`mathcal H_X`. Hence `partial` has rank `X-1`.

## 2. Elementary Pascal cycles

For every nonunit split `2<=j<=floor(n/2)`, define

\[
\boxed{
P_{n,j}
=[n,j]+[j,1]-[n,1]-[n-1,j-1].
}
\tag{L-27204.4}
\]

Direct expansion gives

\[
\boxed{\partial P_{n,j}=0.}
\tag{L-27204.5}
\]

There is one `P_(n,j)` for every nonunit edge. Ordered first by parent `n` and
then by `j`, the coefficient of `[n,j]` is one and no earlier cycle contains
that edge. Thus the cycles are linearly independent.

Their number is

\[
\#\{[n,j]\}-(X-1)
=\dim\ker\partial.
\]

Therefore

\[
\boxed{
\ker\partial
=\operatorname{span}\{P_{n,j}:2\le j\le\lfloor n/2\rfloor\}.
}
\tag{L-27204.6}
\]

Equivalently, modulo Pascal cycles,

\[
[n,j]
\equiv[n,1]+[n-1,j-1]-[j,1],
\tag{L-27204.7}
\]

and induction gives the explicit unit-edge reduction

\[
\boxed{
[n,j]
\equiv
\sum_{t=n-j+1}^{n}[t,1]
-
\sum_{t=2}^{j}[t,1].
}
\tag{L-27204.8}
\]

This proves that no hidden carry-preserving deformation exists outside the
Pascal cycle space.

## 3. Canonical balanced fragmentation trees

Now fix `0<eta<=1/4` and retain only balanced splits

\[
\eta n\le j\le n/2.
\tag{L-27204.9}
\]

Choose the canonical central split

\[
s(n)=\lfloor n/2\rfloor,
\qquad h_n^{\rm bal}=[n,s(n)].
\tag{L-27204.10}
\]

It is eta-balanced for every `n>=2`. Define recursively

\[
T_1=0,
\qquad
\boxed{
T_n=h_n^{\rm bal}+T_{s(n)}+T_{n-s(n)}.
}
\tag{L-27204.11}
\]

Then

\[
\boxed{
\partial T_n=e_n-n e_1,
\qquad
\|T_n\|_1=n-1.
}
\tag{L-27204.12}
\]

The first identity is immediate by induction; the second says that a full
binary tree with `n` unit leaves has exactly `n-1` internal splits.

The canonical balanced edge divergences are triangular and again form a basis
of `mathcal H_X`.

## 4. Balanced fundamental cycles

For any eta-balanced split `[n,j]`, define

\[
\boxed{
C_{n,j}
=[n,j]+T_j+T_{n-j}-T_n.
}
\tag{L-27204.13}
\]

Then

\[
\boxed{
\partial C_{n,j}=0.
}
\tag{L-27204.14}
\]

If `[n,j]=h_n^(bal)`, the cycle is zero. Otherwise `[n,j]` is the unique
noncanonical edge occurring in `C_(n,j)`, with coefficient one; every other
edge belongs to the canonical trees. Consequently the nonzero cycles

\[
\{C_{n,j}:[n,j]\ne h_n^{\rm bal}\}
\]

are linearly independent. Their number is the number of balanced edges minus
`X-1`, exactly the dimension of the balanced kernel. Hence

\[
\boxed{
\ker(\partial|_{E_\eta})
=\operatorname{span}
\{C_{n,j}:[n,j]\in E_\eta,\ [n,j]\ne h_n^{\rm bal}\}.
}
\tag{L-27204.15}
\]

Moreover,

\[
\boxed{
\|C_{n,j}\|_1\le2n-2.
}
\tag{L-27204.16}
\]

## 5. Canonical signed solution and complete affine normal form

Let `r in H_X`. The canonical central-tree flow

\[
\boxed{
 d^{\rm tree}(r)
 =\sum_{m=2}^{X}r_m T_m
}
\tag{L-27204.17}
\]

satisfies

\[
\boxed{\partial d^{\rm tree}(r)=r.}
\tag{L-27204.18}
\]

Indeed, the node-one coordinate is correct because
`r_1=-sum_(m>=2)m r_m`.

Every eta-balanced exact realization of the same divergence has the unique
form

\[
\boxed{
 d
 =d^{\rm tree}(r)
 +\sum_{
 [n,j]\in E_\eta\setminus\{h_n^{\rm bal}\}}
 z_{n,j}C_{n,j}.
}
\tag{L-27204.19}
\]

Uniqueness follows because the coefficient on each noncanonical edge is exactly
`z_(n,j)`.

Thus Möbius Fragmentation Transport is equivalent to one explicit orthant
intersection:

\[
\boxed{
\exists z:
\quad
 d^{\rm tree}(r^{w_X})+C_\eta z\ge0.
}
\tag{L-27204.20}
\]

This is not a new hypothesis. It is a complete coordinate normal form for the
finite MFT cone.
