## Statement

Let \(G=(V,E)\) be a finite directed acyclic graph with a distinguished root
\(r\).  For each node \(v\), let \(X_v\) be a concrete value space and let
\(\widehat X_v\) be an abstract enclosure space with a concretization map

\[
 \gamma_v:\widehat X_v\longrightarrow\mathcal P(X_v).
\]

Each leaf \(\ell\) has a concrete value \(x_\ell\) and an abstract value
\(A_\ell\) satisfying

\[
 x_\ell\in\gamma_\ell(A_\ell).
\]

Each internal node \(v\), with ordered parents
\(p_1,\ldots,p_k\), has:

- a concrete operation

  \[
  f_v:X_{p_1}\times\cdots\times X_{p_k}\to X_v;
  \]

- an abstract transformer

  \[
  \widehat f_v:
  \widehat X_{p_1}\times\cdots\times\widehat X_{p_k}\to\widehat X_v
  \]

  satisfying the local inclusion contract

  \[
  f_v\bigl(\gamma_{p_1}(A_1),\ldots,\gamma_{p_k}(A_k)\bigr)
  \subseteq
  \gamma_v\bigl(\widehat f_v(A_1,\ldots,A_k)\bigr)
  \]

  for every admissible tuple of abstract parent values.

Define concrete and abstract node values recursively by

\[
 x_v=f_v(x_{p_1},\ldots,x_{p_k}),
 \qquad
 A_v=\widehat f_v(A_{p_1},\ldots,A_{p_k}).
\]

Then

\[
 x_v\in\gamma_v(A_v)
\]

for every node, in particular

\[
 x_r\in\gamma_r(A_r).
\]

More generally, if each leaf ranges over its entire concretization set, then
\(\gamma_r(A_r)\) contains every possible root value generated by all admitted
leaf realizations.

Consequently, if the root is the D-4501 evaluation and

\[
 \gamma_r(A_r)\subseteq\mathcal D,
\]

then the exact witness survives every admitted quantitative uncertainty.  If
all logical gates are also proved, the finite witness has a full
witness-survival certificate.

## Definitions

- The set expression
  \(f_v(S_1,\ldots,S_k)\) denotes the image of the Cartesian product under
  `f_v`.
- A local inclusion contract is a theorem about the exact concrete operation,
  not a test on sampled inputs.
- The abstract domains may differ by node.  A certificate can combine rational
  intervals, complex disks, affine forms, polytopes, exact finite sets, Taylor
  models, and topological tubes if the conversion contracts are sound.
- A leaf is exact when its concretization is a singleton.

## Motivation

Finite-witness computations are long enough that a single final “error bar” is
not auditable.  The useful theorem shape from abstract interpretation is local:
each operation promises only that its abstract output encloses all concrete
outputs from the abstract inputs.  Structural induction then turns those small
promises into a global guarantee.

This has two operational benefits.

1. Every uncertainty-destruction mechanism must enter through a leaf or an
   explicitly proved transformer.
2. Producers can change algorithms, precision, or abstract domains without
   changing the tiny final checker, provided the same local contracts are
   emitted and verified.

## Proof

Choose a topological ordering of the finite DAG.

For a leaf \(\ell\), the desired inclusion

\[
 x_\ell\in\gamma_\ell(A_\ell)
\]

is an assumption.

Now let \(v\) be an internal node and assume the claim has been proved for all
of its parents.  Then

\[
 x_{p_j}\in\gamma_{p_j}(A_{p_j})
 \qquad (1\le j\le k).
\]

Therefore

\[
 x_v=f_v(x_{p_1},\ldots,x_{p_k})
 \in
 f_v\bigl(\gamma_{p_1}(A_{p_1}),\ldots,
           \gamma_{p_k}(A_{p_k})\bigr).
\]

The local inclusion contract gives

\[
 f_v\bigl(\gamma_{p_1}(A_{p_1}),\ldots,
           \gamma_{p_k}(A_{p_k})\bigr)
 \subseteq
 \gamma_v\bigl(\widehat f_v(A_{p_1},\ldots,A_{p_k})\bigr)
 =\gamma_v(A_v).
\]

Hence \(x_v\in\gamma_v(A_v)\).  Induction along the topological ordering proves
the claim for every node and the root.

For set-valued leaves, apply the same induction to an arbitrary admitted leaf
realization.  Since the realization was arbitrary, every concrete root value
lies in the root concretization.  Root containment in \(\mathcal D\) then proves
quantitative survival. ∎

## Uncertainty-closure corollary

Suppose the certificate format additionally proves that:

1. the declared leaf identifiers equal the actual leaf identifiers of the
   concrete DAG;
2. every declared leaf is used;
3. no internal node has an undeclared data dependency.

Then every variation of the root within the specified concrete semantics is
caused by a declared leaf variation and is already included in
\(\gamma_r(A_r)\).  There is no remaining **quantitative** uncertainty channel
inside that semantics.

This corollary does not prove that the selected concrete semantics or logical
gates are correct.  Those remain separate proof obligations.

## Analytic domain audit

The lemma is set-theoretic and finite.  A concrete analytic operation may be
used at a node only on a domain where its local inclusion contract is proved.
Division by an interval or disk containing zero, a branch-crossing logarithm,
or an unevaluated pole must fail closed rather than produce an ordinary node.

## Dependency audit

D-4501 supplies the witness, uncertainty, and disproof-region terminology.  The
proof itself uses only induction on a finite DAG and local set inclusion.

The theorem shape is closely related to abstract interpretation, but no
external abstract-interpretation theorem is needed for the proof presented
here.

## Gap audit

- A sampled numerical test of a transformer is not a local inclusion proof.
- Cyclic computations need a separate invariant or fixed-point proof; they
  cannot be smuggled into a DAG certificate.
- Converting from a correlated abstract domain to independent intervals is
  sound only if the resulting box contains the correlated set.
- A root enclosure that intersects the disproof boundary is unresolved, even
  when its midpoint is deep inside the desired region.
- The leaf-closure check must be tied to the exact witness and exact operation
  graph, for example by canonical serialization and digests.
- An incorrect concrete formula can be enclosed perfectly and still prove the
  wrong statement; normalization and formula identity are logical gates.

## Adversarial tests

1. Replace one addition interval transformer by endpointwise addition without
   outward rounding and construct a counterexample to local inclusion.
2. Add an undeclared tail leaf to the concrete root and require closure failure.
3. Declare an unused “rounding” leaf and require closure failure rather than
   silently accepting decorative uncertainty.
4. Convert a complex disk to a rectangle, then verify that all disk points are
   contained before using rectangular arithmetic.
5. Attempt a division with a denominator enclosure containing zero and require
   rejection.
6. Mutate one witness coordinate while keeping the old DAG digest and require
   rejection.

## Remaining uncertainty

The abstract theorem is complete.  The practical open problem is choosing
abstract domains that are both sound and sharp enough.  Naive independent
intervals can lose a true strict moat through dependency overestimation.
