## 1. Positive endpoint source

For each typed endpoint \(Y\) and fixed row \(j\), let

\[
dM_Y(t)
=
\mathbf1_{t\le Y}T(Y/t)\eta_j(t)\frac{dt}{t},
\qquad
\eta_j(t)>0.
\]

Let the active children have endpoints \(Z_i\le Y\) and coefficients

\[
\alpha_i=r_i\lambda_i,
\qquad
\sum_i\alpha_i<67^{-1/2}<1/8.
\]

Define

\[
R_i(t)=R_{Z_i\mid Y}(t)
=
\mathbf1_{t\le Z_i}\frac{T(Z_i/t)}{T(Y/t)}.
\]

Then \(0\le R_i\le1\), and

\[
\sum_i\alpha_iR_i(t)<1/8
\]

pointwise on the parent source.

On \(M_Y\otimes du\), the disjoint intervals

\[
E_i
=
\left\{
(t,u):
\sum_{h<i}\alpha_hR_h(t)
\le u
<
\sum_{h\le i}\alpha_hR_h(t)
\right\}
\]

project exactly to

\[
\boxed{\alpha_iM_{Z_i}.}
\]

The complementary cylinder projects to

\[
\boxed{
M_Y-\sum_i\alpha_iM_{Z_i}\ge0.
}
\]

This defines one literal nonnegative child operator \(\mathsf T\) on the typed
source DAG. The Hall bonus belongs to the complement and never enters
\(\mathsf T\).

## 2. Positive frame recursion

Let \(P\) be the row-valued positive frame generated by these source measures,
and let \(J\) be the current plus terminal observation. The random-key
partition is precisely

\[
\boxed{
P=J+P\mathsf T,
\qquad
J\ge0.
}
\tag{L-99450.1}
\]

The equation is source-faithful in every row because the RN multiplier is
independent of \(j\); the same scalar target source is lifted by the positive
row atom \(\eta_j(t)\).

## 3. Exact frame and primitive calibration

Let \(E\) be the exact signed native frame and define its primitive calibration
potential by

\[
\boxed{A=E-P.}
\tag{L-99450.2}
\]

The same typed endpoint map \(\mathsf T\) acts on \(E\), \(P\), and \(A\).
Substituting (L-99450.1) and (L-99450.2),

\[
\begin{aligned}
J+E\mathsf T+(A-A\mathsf T)
&=
P-P\mathsf T+(P+A)\mathsf T+A-A\mathsf T\\
&=P+A\\
&=E.
\end{aligned}
\]

Therefore

\[
\boxed{
E=J+E\mathsf T+(A-A\mathsf T).
}
\tag{L-99450.3}
\]

The local signed correction is the Bellman coboundary
\(\Delta_{\mathsf T}A=A-A\mathsf T\), not an independent debt.

## 4. Nilpotent resolution

At a fixed root, endpoints strictly decrease and \(\mathsf T\) is nilpotent.
Hence

\[
(I-\mathsf T)^{-1}
=
I+\mathsf T+\cdots+\mathsf T^N
\]

is a finite nonnegative polynomial. Equations (L-99450.1) and (L-99450.3)
resolve to

\[
\boxed{
P=J(I-\mathsf T)^{-1}\ge0,
}
\]

and

\[
\boxed{
E=J(I-\mathsf T)^{-1}+A=P+A.
}
\tag{L-99450.4}
\]

All descendant calibration terms cancel exactly:

\[
(A-A\mathsf T)(I-\mathsf T)^{-1}=A.
\]

There is no geometric \(1/(1-\kappa)\) loss and no generationwise sum.

## 5. Fail-closed conditions

The composition fails if:

- the child uses a raw cutoff instead of \(R_{Z\mid Y}\);
- different rows use different child operators;
- a Hall bonus is copied into a child;
- calibration is inserted as \(A\) rather than \(A-A\mathsf T\);
- independently normalized children are coupled only after normalization.

Under the RN construction, the positive-frame recursion and the calibration
coboundary are one commutative source diagram.
