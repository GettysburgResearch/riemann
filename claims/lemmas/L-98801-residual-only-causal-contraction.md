## 2. Exact fibrewise causal identity

For a positive residual packet `P` with ordered active rough primes
`p_1<...<p_k`, put

\[
 r_i=p_i^{-1/2},\quad
 s_i=\prod_{h\le i}(1-r_h),\quad
 \lambda_i=r_is_{i-1},\quad
 \alpha_i=r_i\lambda_i.
\]

The exact realized identity is

\[
\boxed{
 P=s_kP+
 \sum_i\lambda_i(P-r_iU_{p_i}P_{/p_i})+
 \sum_i\alpha_iU_{p_i}P_{/p_i}.
}
\]

Every current difference is positive on the frozen causal-generator theorem,

\[
 s_k+\sum_i\lambda_i=1,
 \qquad
 \sum_i\alpha_i<67^{-1/2}<\frac18.
\]

The bonus row is added to the current output after this identity and is never
present in a child term.

## 3. Actual target-mass contraction after integration

Let `P_s` be a positive residual fibre over a positive endpoint measure.  For a
measurable variable list of children assume the frozen same-index
nonexpansivity

\[
 m(U_{s,i}Q_{s,i})\le m(P_s).
\]

Then pointwise

\[
 \sum_i\alpha_i(s)m(U_{s,i}Q_{s,i})
 \le\frac18m(P_s).
\]

Tonelli gives

\[
\boxed{
 \int\sum_i\alpha_i(s)m(U_{s,i}Q_{s,i})d\nu(s)
 <\frac18\int m(P_s)d\nu(s).
}
\]

After grouping by complete placement/provenance label `b`, let `M_b` be the
actual grouped child mass and `M` the parent residual mass.  For `M_b>0` set

\[
 \widehat P_b=M_b^{-1}P_b,\qquad
 \beta_b=M_b/M.
\]

Then

\[
\boxed{
 P=P^{\rm cur}+\sum_b\beta_bU_b\widetilde P_b,
 \qquad \sum_b\beta_b<\frac18,
}
\]

with every child normalized by its actual mass.  Common restrictions,
omissions, and scalar thinning only decrease both sides and preserve the bound.
