# L-96652 — Finite positive-operator parity resummation

Status: **EXACT ABSTRACT THEOREM**

Let `T` be the positive nilpotent child operator on the finite first-owner tree.  If the canonical current scalar satisfies `g>=Tg`, then the history-signed solution of

```text
F+TF=g
```

is nonnegative, because

```text
(I+T)^-1 = (I-T)(I-T^2)^-1
F = (I-T^2)^-1(g-Tg) >= 0.
```

This theorem is the reason odd-history leaves need not be positive separately.
