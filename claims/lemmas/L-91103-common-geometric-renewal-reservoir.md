## 1. The endpoint factorization

Let
\[
 L=\log4.
\]
PR #352 `L-90026` defines:

- the critical endpoint atom \(V\);
- the positive factor-four block atom \(Y\);
- a geometric random variable \(J\) with
  \[
  \mathbb P(J=j)=2^{-(j+1)},\qquad j\ge0.
  \]

It proves
\[
\boxed{
 V\overset d=Y+LJ,
 \qquad
 Y\perp J.
}
\tag{L-91103.1}
\]

Equivalently,
\[
 \phi_J(s)=\frac1{2-4^{-s}},
\tag{L-91103.2}
\]
and
\[
 \phi_V(s)=\phi_Y(s)\phi_J(s).
\tag{L-91103.3}
\]

## 2. The Gamma target has the same reservoir

Let
\[
 G\sim\operatorname{Gamma}(2,1/2),
 \qquad
 \phi_G(s)=\frac1{(1+2s)^2}.
\tag{L-91103.4}
\]

PR #352 `L-90028` defines the capped-Gamma factor-four target \(H\) by
\[
 f_H(t)=\frac12\min(t,L)e^{-t/2},
\]
and proves
\[
\boxed{
 \phi_H(s)=\frac{2-4^{-s}}{(1+2s)^2}.
}
\tag{L-91103.5}
\]

Combining (L-91103.2), (L-91103.4), and (L-91103.5),
\[
 \phi_H(s)\phi_J(s)=\phi_G(s).
\]
By Laplace uniqueness,
\[
\boxed{
 G\overset d=H+LJ,
 \qquad
 H\perp J,
}
\tag{L-91103.6}
\]
with exactly the same geometric law \(J\) as in (L-91103.1).

Thus the factor-four renewal is not an artifact of the endpoint producer. It is a common independent reservoir of both the source atom and the sharp target.

## 3. The entire discrepancy is the block transport

PR #352 `L-90028` proves the strict stochastic order
\[
\boxed{
 Y<_{\rm st}H.
}
\tag{L-91103.7}
\]

Choose the monotone quantile coupling with
\[
 Y\le H\quad\text{almost surely},
\]
and take an independent copy of \(J\). Then
\[
 Y+LJ\le H+LJ
\quad\text{almost surely}.
\]
Using (L-91103.1) and (L-91103.6),
\[
\boxed{
 V<_{\rm st}G.
}
\tag{L-91103.8}
\]

More strongly, every state-dependent delay kernel transporting \(Y\) to \(H\) lifts, by tensoring with the identity kernel on \(J\), to a state-dependent delay kernel transporting \(V\) to \(G\).

The endpoint-to-Gamma problem therefore factors as
\[
\boxed{
\begin{array}{ccc}
Y&\longrightarrow&H\\
\downarrow\ +LJ&&\downarrow\ +LJ\\
V&\longrightarrow&G,
\end{array}}
\tag{L-91103.9}
\]
where the vertical arrows are the same independent geometric renewal.

## 4. Consequence for finite discretization

The continuum factor-four detail removes the common reservoir before transport:
\[
 V\mapsto Y,
 \qquad
 G\mapsto H.
\]

This explains why the radix-four detail coordinate of PR #352 is unusually natural:

1. it turns the endpoint and target into positive laws;
2. it removes an identical independent scale-lattice component;
3. it leaves the strict stochastic transport \(Y\to H\);
4. PR #352 `L-90027/L-90029` supplies a matching positive finite detail matrix and positive finite target.

A finite approximation should therefore quantize the block coupling \(Y\to H\), not independently deconvolve \(V\) from \(G\). Independent deconvolution retains the reciprocal-zeta obstruction; a state-dependent block coupling does not.

## 5. Shadow-transport interpretation

The monotone coupling \(Y\le H\) is one-dimensional and canonical under quantiles. When finite endpoint mass is constrained to the ordered state grid \(r_T\), `L-91101` shows that every convex-order correction is generated by adjacent butterflies.

```text

finite:
    quantize the block law on the endpoint-state grid;

```

The first step is stochastic order; the correction step is convex order. This is precisely the geometry of monotone/shadow martingale transport.
