## 1. Positive Jordan row partition function

Retain the Q=4 Jordan deformation

\[
J_{4,\tau}(s)=\frac{A_4(s-\tau)}{A_4(s)}
\]

from PR #339. Its coefficients are nonnegative for every `tau>=0`, and

\[
J_{4,0}=\varepsilon,
\qquad
J'_{4,0}=\Lambda_4,
\qquad
J''_{4,0}=C_4.
\]

For a nontrivial carry row `e=(n,j)`, define

\[
\boxed{
F_e(\tau)=1+\mathcal L_e(J_{4,\tau}).
}
\tag{L-34402.1}
\]

The carry column `d=1` is zero, so

\[
F_e(0)=1.
\]

Differentiating at zero gives

\[
\boxed{
F_e'(0)=P_4(n,j),
\qquad
F_e''(0)=S_4(n,j).
}
\tag{L-34402.2}
\]

Consequently

\[
\boxed{
-(\log F_e)''(0)
=P_4(n,j)^2-S_4(n,j)
=R_4(n,j).
}
\tag{L-34402.3}
\]

Thus the Q=4 Selberg–Kummer reserve is exactly the negative logarithmic curvature of one positive Jordan row partition function.

## 2. Exact radix-four ratio

Let

\[
e^+=(4n,4j).
\]

Define the scale-ratio partition function

\[
\boxed{
H_e(\tau)=\frac{F_{e^+}(\tau)}{F_e(4\tau)}.
}
\tag{L-34402.4}
\]

Since both factors equal one at zero,

\[
H_e(0)=1.
\]

The first logarithmic derivative is

\[
\begin{aligned}
(\log H_e)'(0)
&=F_{e^+}'(0)-4F_e'(0)\\
&=P_4(4n,4j)-4P_4(n,j).
\end{aligned}
\]

Therefore

\[
\boxed{
(\log H_e)'(0)=E(n,j),
}
\tag{L-34402.5}
\]

where `E` is exactly the nonnegative first-moment innovation of PR #342.

For the second derivative,

\[
\begin{aligned}
(\log H_e)''(0)
&=(S_4(4n,4j)-P_4(4n,4j)^2)\\
&\quad-16(S_4(n,j)-P_4(n,j)^2)\\
&=-R_4(4n,4j)+16R_4(n,j).
\end{aligned}
\]

Hence

\[
\boxed{
-(\log H_e)''(0)
=R_4(4n,4j)-16R_4(n,j)
=\Delta_4R(n,j).
}
\tag{L-34402.6}
\]

This is an exact identity, with no asymptotic estimate and no prime enumeration.

## 3. Critical-scale interpretation

PR #342 proves on the complete quarter-balanced cone, cofinally,

\[
(\log2)n\log n
\le\Delta_4R(n,j)

\[
\boxed{

\tag{L-34402.7}

At the same time its first logarithmic derivative is only logarithmic:

\[

\]

The reserve increment is therefore not merely a difference between two large positive row reserves. It is an intrinsic curvature generated by the radix-four refinement itself.

## 4. Schur-complement interface

Suppose a source parameter `sigma` can be incorporated into a positive two-parameter row partition function

\[
\mathcal H_e(\tau,\sigma)
\]

\[
\mathcal H_e(\tau,0)=H_e(\tau)

\[
-\partial_\tau\partial_\sigma
\log\mathcal H_e(0,0)=I_\circ(n,j).
\]

If `-Hess log mathcal H_e(0,0)` is positive semidefinite and the source-source diagonal is bounded by an absolute constant `C_0`, then its `2 x 2` Schur inequality gives immediately

\[
\boxed{
|I_\circ(n,j)|^2
\le C_0\,\Delta_4R(n,j).
}
\tag{L-34402.8}
\]

By `L-34401`, this is exactly the dimensionless estimate needed for the coefficient-one critical recurrence.

Equation (L-34402.8) is **not** claimed here: the two-parameter positive row partition and its Hessian sign still have to be constructed. This section fixes the exact form a successful Schur proof must take and prevents spending the much larger full reserve `R_4`.

The former discovery inequality

\[
