# R-100401 — Neutral-phase cancellation is not removal of the Euler root

Claim ID: `R-100401`  
Status: **PROVED SCOPE FIREWALL**  
Created: 2026-08-20

`L-100401` proves

\[
\mathscr S_B(\gamma)
={1\over2}[\mathscr T_B(\gamma)+s_B-P_B(\gamma)].
\]

Thus the neutral value is zero, but at nonzero phase the complete Euler product
`P_B(gamma)` remains with coefficient `-1/2`.  An estimate for the local edge
factor `1-p^{i gamma}` is therefore not by itself a root-free cross-core
estimate.

The phase-Hasse construction remains a useful decomposition, but it is not a
third independent escape from the ordinary-Möbius correlation.  Any closure
claim must bound the complete source-specific expression, including the
retained Euler root.
