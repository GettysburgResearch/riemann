# R-93016 — The actual critical Cycle-Debt source is not rational

Claim ID: `R-93016`

## 1. The overstatement

`L-93012` correctly observes that every size-weighted action column

\[
A_e=e_n-P_e
\]

has rational entries. It then states that “the action matrix and critical source are rational.” The second clause is false for the actual critical target.

The critical carry columns are

\[
w_X(q)=q^{-1/2}\log(X/q),
\]

and their exact multiples-Möbius transform gives a node source containing square roots and logarithms. There is no rationality theorem for that source, and ordinary decimal approximations must not be inserted into an exact source equality.

## 2. Correct rational statement

The valid statement is:

> If a supplied finite source vector `s` is rational, every basic feasible action-mass vector for the rational action matrix is rational.

This is the standard rational-polyhedron conclusion used in `L-93012`. It applies directly to rational synthetic controls and to any rationally encoded finite target. It does not apply verbatim to the actual critical source.

The rank-sparsity conclusion is independent of source rationality:

\[
\boxed{
\text{whenever the finite LP is feasible, an optimum exists on at most }
\operatorname{rank}(A)
\text{ signed action columns.}
}
\]

The active coefficients at such a basic optimum belong to the coefficient field generated by the exact source coordinates.

## 3. Correct proof-producing treatment of the critical source

A proof-producing critical certificate must use one of the following explicit contracts.

### 3.1 Exact symbolic contract

Keep every source coefficient as a finite symbolic linear combination of the primitive quantities

\[
q^{-1/2}\log(X/q),
\]

perform the exact Möbius and source-column operations symbolically, and authenticate equality in that symbolic field.

### 3.2 Directed interval contract

Use outward rational intervals for every primitive square root and logarithm, propagate them through the complete Möbius/source calculation, and prove that the proposed action channels cover the full resulting source interval with a declared exact residual mechanism. A point estimate inside the interval is not an exact source certificate.

The capacity costs require independent outward intervals as already stated in `L-93012`. Source uncertainty and cost uncertainty must not be merged into one undocumented numerical tolerance.

## 4. What survives from `L-93012`
