# M-97700 — Hostile protocol for threshold-flexible causal claims

Reject a proposed continuation at the first occurrence of any of the following:

1. a rough edge `r` is replaced by a smaller recursive coefficient without
   depositing the residual `r-a` in the current source;
2. the old two-copy alpha accounting omits `r-2r^2`;
3. the finite `P_61` base is identified with the native root;
4. an odd history is terminalized in canonical parity orientation;
5. source ownership or scale descent is cited as proof of scalar positivity;
6. a contracted child budget is used to bound raw exposure;
7. a threshold depth satisfying `L log L=o(log log X)` is claimed positive;
8. a local Target-Lorenz margin is promoted to the global critical-depth Hall
   inequality;
9. a finite replay is represented as proof of `CSHT67` or RH.

Mandatory regression cases:

```text
one prime p=67                     residual r-2r^2 > 0
X=184                              native root differs from P61 base by >1.36
X=67*71*13                         odd-history target gap >17
abstract two-node thinning         current a-r <0
X=32605 / 32606                    directed depth-two sign change
raw exposure                       (r-a)+a=r exactly
```
