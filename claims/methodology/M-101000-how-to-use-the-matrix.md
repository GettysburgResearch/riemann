# M-101000 — How to use the implication matrix

1. Contract RH-equivalent detector nodes before counting missing lemmas.
2. Preserve the structural coordinate attached to each equivalent criterion.
3. Compose only hyperedges whose inputs are on the same source, scale and
   normalization.
4. Treat no-go records as deleted edges, not as negative evidence about every
   possible reframing.
5. Prefer attacks on the two minimal structural classes:
   critical variation and signed cross-core dispersion.
6. When proposing a conjunction, state the exact source partition and prove
   that each term is charged once.
7. Use canonical `IM-*` aliases in new dependency files; include the original
   claim number, PR, path and exact head SHA only as provenance.
