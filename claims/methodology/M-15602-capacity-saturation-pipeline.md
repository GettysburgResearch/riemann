## Objective

At a support `a`, produce one exact certificate proving

\[
 D_{\rm sat}(a)=C(a)=d
\]

and one ambient floor `F_a`.  Do not compare a loose symbol rank cap directly to
a packet rank.

## Stage 1 — directed symbol geometry

1. Build the complete Suzuki multiplier with directed phases and the full
   prime-power manifest.
2. Run the scalar bathtub floor from PR #155.
3. If the whole-space floor is adequate, record it and stop; no packet is
   needed.
4. Otherwise cover the low-symbol set and construct a complete finite
   multiband/generalized-prolate packet `U` with an outer floor.
5. Preserve the total bad-set measure, concentration threshold, rank cap, and
   every analytic tail gate.

The rank cap is only a scheduling bound.  It is not yet `D_sat`.

## Stage 2 — exact radical capacity

1. Build a uniformly concentrated source packet `P`.
2. Impose the exact source constraints by rational nullspace computation.
3. Use `L-15605` to record the precise codimension loss.
4. Localize the resulting exact radical sources and form the packet `L`.
5. Enclose its Gram, compression, and complete residual Gram:

```text
-alpha G <= B <= alpha G
R_cross^* R_cross <= beta^2 G.
```

6. Require a single uniform packet bound; fixed-mode limits are not accepted as
   growing-rank evidence.

## Stage 3 — certified-zero evaluation split

On the finite mismatch space generated by `L+U`, evaluate at a declared set of
proof-grade zeta zeros as in `L-15304`.

1. Freeze a rational basis for the small-singular near-kernel.
2. Verify its evaluation Gram upper bound.
3. Enlarge `L` by any directions that can be repaired into exact radicals with
   the same residual scale.
4. Retain the evaluation-visible directions in a separate finite block `V_vis`.
5. Never infer a lower Weil floor solely from nonzero evaluation; the visible
   block must pass the direct finite Schur test.

## Stage 4 — exact saturation

Put

```text
W = L + U
V = W intersect L^perp
E = W^perp.
```

Certify:

```text
A|E >= Gamma I + h M
Y-Gamma I-h^-1 R* M^-1 R >= 0  on V.
```

The second inequality is a finite directed matrix certificate.  Once it passes,
`L-15604` proves

```text
A|L^perp >= Gamma I.
```

Together with `B<tG`, this returns the exact count

```text
N_A(t)=N_A(Gamma)=dim L.
```

This is the proof-grade meaning of `D<=C`.

## Stage 5 — inverse-Ritz floor

Construct

```text
H = J*(A-t)J
K = J*(A-t)^2 J.
```

Find rational `q<0` with

```text
q K_upper - H_upper >= 0.
```

The ambient floor is

```text
F = t + 1/q - delta.
```

Alternatively use the closed envelope from `L-15602`.

## Stage 6 — cofinal theorem

The retained sequence must include one symbolic proof of

```text
alpha_j -> 0
alpha_j/t_j -> 0
beta_j^2/t_j -> 0
delta_j -> 0.
```

A fitted numerical trend, however long, is not sufficient.  With the exact
saturation certificate at every level, `T-15602` gives `F_j->0-` and then RH.

## Candidate scheduling statistics

Rank supports by:

1. scalar bathtub floor;
2. bad-symbol measure divided by source pre-plunge capacity;
3. codimension-repaired capacity surplus;
4. dimension of the evaluation-visible block;
5. smallest finite visible Schur moat;
6. normalized residual penalty `beta^2/t`;
7. assembly radius relative to the predicted floor.

Do not rank by:

- a loose symbol cap alone;
- a smallest Ritz value alone;
- a principal angle not certified in the form metric;
- a fixed-rank leakage curve.

- Source constraints are exact, not approximately repaired.

- The visible finite block includes every direction in `(L+U) intersect L^perp`.
