## Mission

Construct an explicit characteristic-one / \(\mathbf F_1\)-type geometry in which the repository's **literal prime-labelled native source** is a Frobenius correspondence, its activation boundary is a tropical divisor, and the recurring critical middle estimates become one Hodge–Riemann or Hodge-index statement plus one arithmetic trace/occupancy statement.

The objective is not to announce that \(\overline{\operatorname{Spec}\mathbf Z}\) should be a curve over \(\mathbf F_1\). That slogan is classical and does not by itself prove any live repository gate. The objective is to build a finite, source-faithful model whose maps can be checked coefficient by coefficient and whose cofinal limit feeds one fixed Mellin–Landau detector already resident on main.

A successful programme should produce a genuinely new **middle-layer producer**:

```text
native Euler/Frobenius correspondence
        ↓
primitive absolute-Hodge class + arithmetic height/trace
        ↓
strict root return and root-free packing
        ↓
fixed Mellin–Landau detector
        ↓
RH.
```

## Why this geometry is now plausible

The integrated and post-integration work has exposed several features that are naturally geometric over a multiplicative or tropical base.

1. The source is a free prime-labelled multiplicative monoid before physical collapse.
2. Every dilation `S_n` is a Frobenius-type action, and in logarithmic scale it is translation by `log n`.
3. Physical activation is the tropical half-space
   \[
   \sum_e x_e\log p_e\le \log X.
   \]
4. Least-owner, greatest-owner and double-owner decompositions are opposite shellings of the same prime-product incidence object.
5. The common-mother programme produces scale and phase derivatives with a strict local determinant, but not yet an arithmetic sign.
6. The completion-defect programme produces several positive SHARP rays sharing one affine carrier; their conclusion-facing combination has coefficient sum zero and is therefore formally **primitive** with respect to the carrier direction.
7. The Xi reverse–Rolle programme reduces descent to a signed first moment versus a quadratic second moment, again the geometry of an angle between a degree direction and a primitive fluctuation.

No existing branch turns these observations into an actual \(\mathbf F_1\) space, divisor class, intersection form and trace map. This programme attempts exactly that.

## Chosen framework

No single existing definition of \(\mathbf F_1\)-geometry supplies every required feature. The programme uses three compatible layers, each for a specific reason.

### 1. Monoid / blueprint skeleton

Use the free pointed commutative monoid generated by labelled prime occurrences. This preserves multiplication, parity, first ownership and the two separately labelled copies of `67` before physical collapse.

### 2. Tropical scaling-site chart

Use a real tropical chart for logarithmic scale and Frobenius translations. Real lengths `log p` are intrinsic; they should not be replaced by rational approximations in the mathematical statement.

### 3. Toric-polymatroid Hodge package

Use the activation polymatroid and its generalized-permutohedral fan as the finite intersection-theoretic model. The desired signature theorem is a Hodge–Riemann/Lorentzian statement on the **actual weighted activation object**, not on a generic Boolean cube.

The programme may use established external Hodge–Riemann or Lorentzian theorems only after an exact theorem verifies that the constructed fan, divisor classes and source cycle satisfy their hypotheses.

## Exact finite source model

Fix a finite labelled prime set

\[
E_Z=\{e_p:p\le Z\}\cup\{e_{67}'\},
\]

where the second `67` label is retained whenever the duplicate-67 source is used. Put

\[
\lambda_e=\log p_e,
\qquad
r_e=p_e^{-1/2}
\]

for the unnormalised half-order source. A normalized-box implementation must instead use the separately locked coefficient `p^{-1}`; the two normalizations may not be mixed.

Let

\[
M_Z=\langle x_e\mid e\in E_Z\rangle
\]

be the free pointed commutative monoid. On a log-scale section `f(u,theta)`, define the half-density Frobenius correspondence

\[
(\Gamma_e f)(u,\theta)
 =r_e e^{-i\theta\lambda_e}f(u-\lambda_e,\theta).
\]

Then the finite native Euler operator is exactly

\[
\boxed{
\mathcal E_Z=\prod_{e\in E_Z}(I-\Gamma_e).
}
\]

Expanding `mathcal E_Z` gives every labelled squarefree occurrence once with coefficient

\[
(-1)^{|S|}\prod_{e\in S}p_e^{-1/2}.
\]

This is the source to be geometrized. A contracted positive-child tree, finite completion, squared source or post-collapse substitute is not the same correspondence.

## The prime-activation scaling space

For `T=log X`, define the real tropical activation polytope

\[
P_{Z,T}
 =\left\{x\in[0,1]^{E_Z}:
          \sum_{e\in E_Z}\lambda_e x_e\le T\right\}.
\]

Its Boolean vertices are the active labelled subset products. As `T` crosses `log n`, one physical product activates. Distinct labelled subsets may map to the same physical product only through deliberately duplicated labels, most notably the two copies of `67`.

Define the saturated weight function

\[
\rho_T(A)=\min\left(T,\sum_{e\in A}\lambda_e\right).
\]

### Exact seed lemma — activation submodularity

`rho_T` is normalized, monotone and submodular.

Indeed, for `e notin A`,

\[
\rho_T(A\cup\{e\})-\rho_T(A)
 =\min\left(\lambda_e,
            \bigl(T-\sum_{a\in A}\lambda_a\bigr)_+
       \right).
\]

This marginal decreases as `A` grows, which is the diminishing-returns form of submodularity.

Thus every finite activation chamber has a canonical polymatroid and generalized permutohedron. This is an unconditional entry point for a toric/tropical Hodge package. It does **not** yet identify the native signed source with a positive or primitive Chow class.

## The completion homotopy as a divisor current

The most concrete first geometry should be built on the source-faithful completion homotopy used in the post-integration defect programme.

Let `E_tau` interpolate between the native source and a finitely squared source without changing occurrence labels. Its derivative

\[
\dot E_\tau
\]

is a sum of one-prime Frobenius currents. The endpoint difference is

\[
E_1-E_0=\int_0^1\dot E_\tau\,d\tau.
\]

The geometric task is to realize `dot E_tau` as a divisor class on the activation scaling space and to prove that the existing positive shifted-SHARP rays are nef metrics on the **same** class.

The three-ray carrier cancellation from the current defect programme is the first test case. If

\[
P_-,\ P_0,\ P_+
\]

share one affine carrier and

\[
a_-+a_0+a_+=0,
\]

then

\[
\alpha=a_-P_-+a_0P_0+a_+P_+
\]

should be primitive relative to the carrier degree. The programme must prove this in the finite intersection ring, not infer it from the zero sum of coefficients alone.

## Central geometric theorem A — native primitive realization

### `NPR105300`

Construct, for every finite `(Z,T,tau)`, a class

\[
\alpha_{Z,T,\tau}\in A^1(\mathscr X_{Z,T})
\]

and an ample class `omega_{Z,T}` such that:

1. the source coefficients of `alpha` are exactly those of the labelled tangent current `dot E_tau`;
2. activation restriction and physical collapse commute with the trace map only in the declared order;
3. the degree component is exactly the deterministic carrier already isolated analytically;
4. the centered class
   \[
   \alpha^\circ
   =\alpha-
     \frac{\deg_\omega(\alpha)}{\deg_\omega(\omega)}\omega
   \]
   is the carrier-recombined physical fluctuation;
5. least-owner, greatest-owner and double-owner decompositions are functorial boundary decompositions of the same class.

This is a source-typing theorem. Failure here invalidates the programme before any Hodge inequality is attempted.

## Central geometric theorem B — absolute Hodge gap

### `AHG105301`

Prove a Hodge–Riemann signature and a quantitative primitive gap for the actual activation classes:

\[
\boxed{
-\,Q_{Z,T}(\alpha^\circ,\alpha^\circ)
 \ge \delta(T)\,\|\alpha^\circ\|_{\mathrm{src}}^2,
\qquad
\delta(T)^{-1}=e^{o(T)}.
}
\]

The finite sign may follow from a toric, matroidal, polymatroidal or Lorentzian theorem. The quantitative cofinal moat is additional arithmetic information and must be proved uniformly as the number of active primes grows.

A fixed finite cutoff or a moat that decays like `e^{-cT}` is not conclusion-producing.

## Central arithmetic theorem C — trace and occupancy

### `ATO105302`

Let `Obs_Phi` be the fixed physical observation defined by the compact common mother. Prove

\[
\boxed{
\int_T^{T+1}
 \left|\operatorname{Obs}_\Phi(\alpha^\circ_{Z,T,\tau})\right|\,dT
 \le e^{o(T)}
 \left(-Q_{Z,T}(\alpha^\circ,\alpha^\circ)\right)^{1/2},
}
\]

uniformly in the source-faithful cofinal regime and integrably in `tau`.

This is the arithmetic height/trace theorem. It is where physical near-collision occupancy, source recombination and the noncontractive labelled-to-physical map must be handled. Generic Cauchy–Schwarz on free labels is forbidden.

## The two-input closure

The intended conclusion is genuinely conjunctive:

```text
NPR105300 native primitive realization
AND
AHG105301 absolute Hodge gap
AND
ATO105302 arithmetic trace/occupancy
    -> strict source-owned root return
       + root-free cross-core packing
    -> subpower negative mass of one fixed detector
    -> RH.
```

More explicitly, the degree/primitive Lefschetz decomposition should yield the scalar Schur/Perron inequality

\[
|g_T|^2
 \le \theta_T\left(|g_T|^2+E_T\right)+R_T,
\qquad
(1-\theta_T)^{-1}=e^{o(T)},
\]

while `AHG+ATO` give

\[
\int_T^{T+1}\left(\sqrt{E_T}+\sqrt{R_T}\right)dT=e^{o(T)}.
\]

The already-proved conjunctive absorption theorem then gives subpower negative mass for the fixed detector.

## Relation to the two post-integration proof programmes

### Scale–phase/common-mother programme

The common mother and covariant scale–phase stress tensor should be the analytic chart of the proposed Hodge metric. The strict determinant already obtained locally is evidence for the expected one-positive-direction signature, but it is not itself the arithmetic Hodge theorem. This programme must explain the arithmetic source class and its trace.

### Xi reverse–Rolle/residue programme

For real critical points `c` of an Xi derivative, the current programme studies

\[
M_1=-\sum_c\frac{F(c)}{F''(c)},
\qquad
M_2=\sum_c\left|\frac{F(c)}{F''(c)}\right|^2.
\]

A later bridge should test whether `M_1` is an absolute degree and `M_2` an absolute Hodge norm of one archimedean restriction of `alpha^circ`. If so, residue coherence is an angle bound in the same Hodge cone. This comparison is optional and must not be used in the first arithmetic closure unless an exact trace theorem is proved.
