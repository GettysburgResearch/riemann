## Exact scalar quotient theorem

Let one fixed real detector `g` have an exact positive-square decomposition

```text
Q = |g|^2 + E,    E >= 0.
```

Suppose a source-owned return inequality and a root-free packing estimate hold
on each dyadic block:

```text
|g|^2 <= theta_L Q + R,      0 <= theta_L < 1,
(1-theta_L)^(-1) = 2^o(L),

integral (sqrt(E)+sqrt(R)) dX/X = 2^o(L).
```

Then

```text
integral g_- dX/X = 2^o(L).
```

Applied to the fixed zero-safe detector inherited from PR #697, the frozen
Mellin--Landau consumer gives RH.

The proof is the exact one-dimensional Schur/Perron absorption

```text
(1-theta_L)|g|^2 <= theta_L E + R <= E+R.
```

This is a scalar quotient of PR #697's two-channel Perron matrix and is
compatible with PR #704's matched-transfer theorem.  It is useful as a typed
allocation theorem; it is not claimed as a new independent arithmetic route.
