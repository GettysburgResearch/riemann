## What is not true

The `xi'''` proportion by itself does not imply any positive `xi''` proportion.
Even among even real Cartwright entire functions,

```text
f(z)=2+cos(z)
```

has no real zero, while `f'(z)=-sin(z)` has only real zeros.  Every genuine
reverse implication therefore needs an additional Xi-specific input such as
critical-value orientation, derivative-ratio residue coherence, or a
Hermite–Biehler argument constraint.
