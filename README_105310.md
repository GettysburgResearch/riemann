# T-105310 — Low-order Xi Pick rank–trace descent

This is the next low-order checkpoint on dedicated draft PR #726. It attacks the actual
low-order Levinson step directly, rather than proving another high-derivative
tail theorem.

## New exact spine

Extending the simple-window `L-105300/L-105303` trace form, for finite real polynomials and confluent limits, the centered Pick kernel of `p/p'` decomposes
coefficient-exactly into derivative-ratio residue atoms. Good real extrema are
positive rank-one atoms, wrong extrema are negative, and nonreal/confluent
blocks have explicitly bounded positive inertia. Rank–trace therefore lower
bounds the number of Rolle-generating extrema without separately estimating
every nonreal residue correction.

Using the unconditional xi-prime proportions

```text
simple and on line: 0.86864
all distinct:       0.93432
```

the complete nuisance positive-index density is at most `0.0821`.
Consequently an Xi/Xi-prime Pick compression with normalized effective rank at
least `0.919` would imply

```text
N_0(T,2T)/N(T,2T) >= 0.6738-o(1),
```

for on-line zeros counted with multiplicity. This is numerically above the
published Montgomery–Taylor constant `0.672500703679...`.

The Cauchy-power archimedean model has effective-rank density at least `49/51`.
Even one-percent trace/HS perturbations leave `0.923110...`, which would yield
`0.682020...` in the same multiplicity-counted conclusion.
