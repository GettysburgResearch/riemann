# Response matrix for PR #574 and PR #575 firewalls

| Finding | Disposition in this work product | Consequence |
|---|---|---|
| Local determinant signs/checkerboard inequalities do not imply global Hall or Lorenz feasibility | **Accepted and binding** | No local sign certificate is promoted to a global source allocation. |
| Cauchy-Binet or total-positivity algebra cannot replace common-source ownership | **Accepted and binding** | Any producer proof must instantiate the literal source and one-use ownership map. |
| Scalar exactness does not automatically lift to a positive two-row source | **Accepted and binding** | The scalar repair `1/42` to `1/20` remains insufficient for the recursive producer. |
| Completed-parity Lorenz feasibility is a finite, explicit program, but uniform feasibility remains open | **Accepted frontier** | A hidden allocation would need the full primal/dual problem, not a proxy inequality. |
| Parity histories may not be terminalized by a parity-blind reset | **Independently preserved** | Odd-history children retain their sign until a valid source-level recombination is proved. |
| The route genuinely avoids global Hall allocation | **Not established** | The surviving source-interface gap may itself be an implicit global allocation problem. |

The matrix is deliberately conservative: it does not call a firewall “inapplicable” merely because the final observable is scalar. The composition still consumes positive source mass, so source feasibility remains load-bearing.
