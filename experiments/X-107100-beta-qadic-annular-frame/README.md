# X-107100 exact replay

Checks the `(1,-2,1)` q-free source law, finite prefix inversion, annular
reconstruction, exact gcd regrouping for an arbitrary rational symmetric
kernel, and the corewise-squaring separator. It does not evaluate zeta or
prove an unbounded cancellation estimate.

```bash
python -B experiments/X-107100-beta-qadic-annular-frame/verify.py \
  --output experiments/X-107100-beta-qadic-annular-frame/results/verification.json
```
