# X-99120 exact row-resolvent replay

The Fraction-only replay checks:

- strict nilpotence of a labelled child operator;
- the exact finite resolvent `E=J(I-T)^(-1)`;
- equality of three independent physical-row functionals;
- positivity of the resolved row;
- fail-closed cycle and negative-current mutations.

It does not replay the PR #620 compact Hall campaign, endpoint integrals,
finite/continuum discrepancy, all-column theorem, prime-square asymptotic,
Mellin–Landau consumer, or RH.
