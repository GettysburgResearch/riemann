# X-91431 — Brownian endpoint hyperbolic completion

This replay checks the finite algebra behind `R-91430/L-91431`:

1. the endpoint evaluation matrix has eigenvalues `(+1/2,+1/2,-1/2,-1/2)`;
2. adding one half of the four-point diagonal mass is exactly a sum of two squares;
3. the coefficient `1/2` is attained by anti-phase data;
4. a one-frequency exponential polynomial gives endpoint value `-2`;
5. the weighted Young/Green completion is an exact square identity;
6. the Stein endpoint coefficient remains nonnegative for `|tanh Delta|<=1`.

The replay does not prove that the theta reserve supplies the required diagonal
and potential energy, and it does not prove RH.
