# X-103080

Lightweight exact replay for the quarter-power Boolean cutoff proposal.

It verifies:

- the Boolean Vaughan identity for many finite labelled prime sets and cutoffs;
- exact cutoff transfer;
- half-source vanishing below the cutoff;
- the floor/support inequality;
- the universal `sqrt(2)` quarter-power Type-I scale ratio;
- fixed kernel support orientation.

It does not prove the analytic Type-I operator theorem, the inherited
Mellin--Landau consumer, or RH.
