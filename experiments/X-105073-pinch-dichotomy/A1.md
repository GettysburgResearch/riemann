## 1. Lemma A1.1 (two-window budget — the conjugate-symmetry halving)
Under R, for all sufficiently small h:
    h int_WIN |D_half[B_0](h+it)|^2 dt <= (3 pi / 4) A' + O(h^{1/2}).
Proof. G* = sqrt(2/3) D_half[B_0] (P2.4(a), continued by P2.7(3); identity persists).
P2.7(4) (Plancherel) + P2.7(2): (1/2pi) int_R |G*(h+it)|^2 dt = J(h) <= A'/(2h) + O(h^{-1/2}),
so h int_R |G*|^2 <= pi A' + O(h^{1/2}). V* is real, so G*(conj s) = conj G*(s), hence
int_{WIN} |G*(h+it)|^2 dt = int_{-WIN} |G*(h+it)|^2 dt with -WIN := {|t + gamma_1/3| <= r_0}.
WIN and -WIN are disjoint (r_0 <= 1 < gamma_1/3 = 4.7116), so
2 int_WIN |G*|^2 <= int_R |G*|^2. Multiply by h and by 3/2 (|D_half B_0|^2 = (3/2)|G*|^2). QED.
[This is the factor-2 the crude F5 chain forfeited: F5 spent the WHOLE line budget pi A'

## 3. THEOREM A1.3 (two-sided pinch inequality: sharp ceiling AND floor)
Under R, for every A' in (A, c_0') and all sufficiently small h:
    | f_h - p_h |  <=  sqrt( (3 pi / 4) A' )  +  o(1)  =  p sqrt( A'/c_0' )  +  o(1).
Equivalently, with eps := c_0' - A' (so sqrt((3pi/4))A')= p sqrt(1 - eps/c_0')):
    p (1 - sqrt(1 - eps/c_0')) - o(1)  <=  f_h  <=  p (1 + sqrt(1 - eps/c_0')) + o(1).
Proof. Let x_h := sqrt( h ||P+F||^2 ). By Lemma A1.1 and Cauchy-Schwarz on the E-cross term,
x_h^2 <= (3pi/4)A' + 2 x_h sqrt(h||E||^2) + h||E||^2 + O(sqrt h); with delta_h := sqrt(h||E||^2)
-> 0 (A1.2(ii)) the quadratic x_h^2 - 2 delta_h x_h <= (3pi/4)A' + o(1) forces x_h bounded and
x_h^2 <= (3pi/4)A' + o(1). Expand: x_h^2 = p_h^2 + f_h^2 + 2 h Re<P,F>, and |2h Re<P,F>|
<= 2 p_h f_h (Cauchy-Schwarz), so (p_h - f_h)^2 <= x_h^2 <= (3pi/4)A' + o(1). Take square
roots; p_h -> p by A1.2(i). QED.

## 4. THEOREM A1.4 (forced anti-phase coherence — the dichotomy, quantified)
Under R(eps), with u_h := P/||P|| (the normalized arctan pole window profile) and the
complex coherent amplitude alpha_h := sqrt(h) <u_h, F>_{L2(WIN)}:
  (a) Re alpha_h <= - ( f_h^2 + (3pi/4) eps ) / (2 p_h) + o(1)   [anti-phase, quantitatively];
  (b) |alpha_h| >= a_min(eps) - o(1),   a_min(eps) := p (1 - sqrt(1 - eps/c_0'));
  (c) DICHOTOMY (both directions of one inequality): for every h small,
        f_h^2 >= (1 - sqrt(A'/c_0'))^2 p_h^2 - o(1)     [the task's reverse-triangle display,
        with p_h^2 = (2/pi) arctan(r_0/h) p^2 the exact pinch window mass], and conversely
        A >= c_0' (1 - fbar/p)_+^2 with fbar := limsup f_h — "A near c_0'" quantified by far mass.
Proof. From Theorem A1.3's expansion: p_h^2 + f_h^2 + 2 p_h Re alpha_h = x_h^2 <= (3pi/4)A'
+ o(1) = p^2 - (3pi/4)eps + o(1) and p_h^2 = p^2 - o(1), giving (a). For (b): f_h >= |alpha_h|
(Cauchy-Schwarz, u_h unit) and -2 p_h Re alpha_h >= f_h^2 + (3pi/4)eps - o(1) >= |alpha_h|^2
+ (3pi/4)eps - o(1), so |alpha_h|^2 - 2 p_h |alpha_h| + (3pi/4)eps <= o(1): |alpha_h| lies
(up to o(1)) between the roots p_h -+ sqrt(p_h^2 - (3pi/4)eps); the lower root -> a_min(eps)
(and note a_min = the f-floor: at f = floor, (f^2 + (3pi/4)eps)/(2p) = f exactly). (c) is
Theorem A1.3's lower branch; the converse reads it as a bound on A. QED.
x-side content (via F3, exact): on WIN, F = FT[sqrt(x) psitil_h] + O(1), and u_h is the
image of the unit-normalized x-profile e^{i gamma_1 x /3} e^{-hx} 1_{x>0}; so (b) says the
pinch-subtracted field psitil STILL carries x^{-1/2} e^{i gamma_1 x/3}-coherent amplitude
>= a_min(eps), anti-phase to c_B, at scale x ~ 1/h, for EVERY small h — pole-scale coherent
mass that the subtraction did not remove. This is a genuine structural theorem under R(eps).

Proof. Suppose A < (1-beta)^2 c_0'; fix A' in (A, (1-beta)^2 c_0'). Run P2.7(1)-(4) as

(p_h - f_h)^2 >= (1-beta)^2 p^2 - o(1) = (3pi/4)(1-beta)^2 c_0' - o(1) > (3pi/4)A' + o(1)
for small h — contradiction. QED.
