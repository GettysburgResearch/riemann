# X-0001 results

`scan-metadata.json` records the 82-cell parameter grids, software environment, aggregate counts, and SHA-256 digests of the full raw JSON outputs. The raw files contain per-cell precision comparisons, residuals, empirical inertia, and per-index geometric-tail diagnostics; they are intentionally regenerated rather than committed.

The exact commands are in the parent experiment README.  Redirect each run to a
new file to reconstruct the full output.

`synthetic-negative-certificate.json` is a unit-test fixture only.  It is not a
Weil matrix and not an RH counterexample candidate.
