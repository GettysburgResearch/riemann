Every verified integer height $H$ here also gives a finite uniform Jensen hyperbolicity range. Griffin, Ono, Rolen, Thorner, Tripp and Wagner, Theorem 1.2 with $m=0$, proves that every even-coefficient Jensen polynomial $J^{d,n}$ has only real zeros for all $n\ge0$ and $d\le H^2$. At the [500,000-index checkpoint](checkpoint-0050.json) this is $d\le9,001,052,728,520,570,210,842,129$, extending the bound from the exact published Platt–Trudgian height by 700,978,979,455,002,129 degrees for every coefficient shift. [Griffin et al., Theorem 1.2](https://arxiv.org/abs/1910.01227)

A narrower sector gives a stronger explicit degree range. Write $R=5.558691$. The explicit classical zero-free region and the functional equation give $|\Re\rho-1/2|\le1/2-1/(R\log|\Im\rho|)$ above $H$. The ratio of this bound to $t=|\Im\rho|$ decreases for $t\ge H$, since the sign of its derivative is that of $-1/2+1/(R\log t)+1/(R\log^2 t)$. Put $u=(1/2-1/(R\log H))/H$. Every zero of $F(z)=\xi(1/2+\sqrt z)$ lies in the sector of half-angle $2\arctan u$ about the negative real axis: the zeros through $H$ map to its axis, and squaring doubles each remaining deviation from the imaginary axis. The genus-zero canonical product places $F$ in the sector class of Griffin et al., Lemma 5.1; its derivatives stay in that class. Their Lemma 5.2 thus gives hyperbolicity for **every** shift and degree
$$
d\le\left\lfloor\frac{(1+u^2)^2}{4u^2}\right\rfloor.
$$
At the 500,000-index checkpoint this gives $d\le9,230,809,478,390,266,303,518,729$. Applying the same zero-free sector to the old published height already gives $9,230,808,759,835,755,081,505,020$; the new finite arithmetic adds 718,554,511,222,013,709 degrees to that sharpened bound. A [256-bit directed evaluation](jensen_sector.py) reproduces the [degree comparison](jensen-sector-0050.json). [Mossinghoff–Trudgian–Yang, Theorem 1.3](https://arxiv.org/abs/2212.06867) · [Griffin et al., Lemmas 5.1–5.2](https://arxiv.org/abs/1910.01227)

## Why a block certifies total-strip coverage

FLINT 3.6.0 evaluates the real scaled completed zeta function on the critical line by Platt's rigorous multi-evaluation with interpolation and error bounds. An opposite-sign pair supplies an open interval containing a critical-line zero. Indexed completeness uses Turing's method in addition to the signs. In FLINT's convention $N(t)$ counts all nontrivial zeros in the full critical strip with $0<\Im\rho\le t$, with multiplicity. Sufficient runs of good Gram blocks on both sides of a shared Gram point force equality between this count and its Gram index plus one. Between successive such anchors the difference of counts is known exactly. The implemented test separates at least that many sign changes before returning the indexed brackets. Consequently each returned interval accounts for one simple critical-line zero and there is no missing off-line zero in the associated indexed segment. Input precision and the Fourier-grid tuning affect successful isolation and the count returned; the caller consumes exactly that returned count. [Turing bound and zero-count API](https://github.com/flintlib/flint/blob/8d5454b96761fafe4d5a9da76a369a602f500f49/doc/source/acb_dirichlet.rst#L666) · [Native anchor and separation loop](https://github.com/flintlib/flint/blob/8d5454b96761fafe4d5a9da76a369a602f500f49/src/acb_dirichlet/platt_local_hardy_z_zeros.c#L1002) · [Index assignment and returned signs](https://github.com/flintlib/flint/blob/8d5454b96761fafe4d5a9da76a369a602f500f49/src/acb_dirichlet/platt_local_hardy_z_zeros.c#L690)

The [producer](isolate.py) calls the unrefined native interval API. It checks that each bracket is strictly ordered and positive and that consecutive open intervals have disjoint interiors. Each native call repeats the preceding final index and intersects both enclosures. Independently produced archive blocks also share a full index; the checker requires an open intersection at each join. A block has 10,001 brackets and adds exactly 10,000 new indices. A completed block is written atomically before its JSON manifest; incomplete trailing output is excluded. The initial index is already covered by the imported theorem.

The optional `--shifted` producer centers the grid closer to the middle of the requested interval. Its [adapter](shifted_isolator.py) supplies explicit integer and dyadic inputs to the released parameterized FLINT routine. Both native entry points call the same Turing isolation and sign-separation core. The per-call manifest stores every explicit grid input under `shifted_parameters`, which the checker passes back to the native routine on replay. A shifted call that certifies no progress falls back to the default grid. Blocks 0000–0049 use the default grid. From block 0050 the producer first tries $h=170$, $K=16$, $J=925000$ and a grid-center offset of at most 540. An independent trial at each of the first three starting indices gave 5,131, 5,372 and 5,361 new-grid isolating intervals. Every one of those 15,864 intervals intersected the corresponding default-grid interval. The configuration-boundary join repeats the last default index. An [independent two-configuration replay](grid-overlap.json) starting 1,000 indices below the switch matches all 1,871 default and 3,500 accelerated intervals through the transition. Its [checker](check_grid_overlap.py) reproduces both native streams. [Parameterized native routine](https://github.com/flintlib/flint/blob/8d5454b96761fafe4d5a9da76a369a602f500f49/src/acb_dirichlet/platt_local_hardy_z_zeros.c#L1074-L1086)

For each explicitly parameterized call, a [companion checker](check_grid_errors.py) reproduces the native grid's analytic error terms and writes their rigorous power-of-two upper envelopes in [grid-errors](grid-errors/), keyed by the raw call digest. Records include the A5 and A7 terms for every Taylor coefficient, the maximum of Lemma 3.2 at $x=0$, B1, B2 after multiplication by $2\sqrt J-1$, A9 and A11. They also enclose both interpolation errors over the whole grid, testing every supported truncation length $1\le N_s\le200$ and reporting the full-support and worst allowed C3 exponent. A stored integer $e$ means the term is bounded by $2^e$ in that term's own units at its insertion in the algorithm. Taylor-table rows undergo further multiplication and factorial scaling, and the native code propagates the resulting ball radii through the subsequent transforms. For example, the first accelerated call has scaled B2 below $2^{-47}$, interpolation alias error below $2^{-214}$, and full-support C3 below $2^{-206}$. The broad all-support estimate includes edge configurations. At each actual sampling ordinate native FLINT uses the actual support length and rejects any ambiguous sign. Run `python check_grid_errors.py --first 50 --stop 51 --verify` to reproduce the first accelerated block's error record. [Grid error insertion](https://github.com/flintlib/flint/blob/8d5454b96761fafe4d5a9da76a369a602f500f49/src/acb_dirichlet/platt_multieval.c#L577-L648) · [Interpolation error insertion](https://github.com/flintlib/flint/blob/8d5454b96761fafe4d5a9da76a369a602f500f49/src/acb_dirichlet/platt_ws_interpolation.c#L503-L516)

The [default-grid diagnostic](capture_default_grid.c) captures the stock wheel's actual grid parameters in a separate process by printing the inputs to its grid-construction functions. This diagnostic exits before numerical zero isolation. The unchanged native API supplies the archived zero brackets. On the Linux LP64 wheel, compile the probe against the same shared library and reproduce a default-grid record as follows, with the wheel's bundled library directory in `libdir`.

```sh
cc -std=c99 -O2 -Wl,--export-dynamic -Wl,-rpath,"$libdir" capture_default_grid.c "$libdir"/libflint*.so* -o /tmp/capture-default-grid
python check_grid_errors.py --first 0 --stop 1 --native-probe /tmp/capture-default-grid --verify
```

The last archived root is used as an upper guard. Its exact lower bracket endpoint gives a height with total count equal to its index minus one. Rounding that endpoint down gives the reported verified integer height. With the count option the checker independently invokes FLINT's ordinary Riemann–Siegel/Turing count, distinct from its Platt grid path, at the historical endpoint, the exact dyadic guard and the integer height. It requires exact single integers and validates the integer count against the archived brackets. This second route shares FLINT's ball-arithmetic and Turing inputs.

## Data and replay

Each XZ archive contains the entire indexed interval stream for one block in increasing order. One ASCII line has the lower mantissa, lower exponent, a tab, upper mantissa and upper exponent. Each signed integer is lower-case hexadecimal. An endpoint $(m,e)$ has exact value $m2^e$. Each JSON manifest records the first and last indices, actual native return counts, working precisions, per-call SHA-256 digests and full compressed and plain-stream digests. The checkpoint root digest hashes the ordered block index and uncompressed stream digest pairs. The zero locations are encoded directly, including coincident outer endpoints of neighboring open brackets.

Use a Linux LP64 environment with Python, python-flint 0.9.0 and its FLINT 3.6.0 wheel library. The native release checkout is 8d5454b96761fafe4d5a9da76a369a602f500f49. SHA-256 hashes of the shared library used here and its release implementation of the local Platt isolator are respectively 871a4132fd1e9f3638391b2208e07088f8e3e72a10e41d45f58b150a60c2a1a9 and b1c18e82e913f381b6e44aeab48fbb1c00b0625b6606844f4ddf1e2a10485c5e. The LP64 binding follows the release's public [arf and interval layouts](https://github.com/flintlib/flint/blob/8d5454b96761fafe4d5a9da76a369a602f500f49/src/arf_types.h) and [isolation signature](https://github.com/flintlib/flint/blob/8d5454b96761fafe4d5a9da76a369a602f500f49/src/acb_dirichlet.h#L303).

To check hashes, coverage, overlapping indices and the independent total counts for checkpoint 3, run from this directory

```sh
python check_frontier.py --max-blocks 3 --count
```

To regenerate a specific block's native arithmetic, compare the raw sign-interval digests, and reconstruct and verify its merged stream, add the zero-based block number

```sh
python check_frontier.py --max-blocks 3 --replay-block 0 --count
```

To recreate three archive blocks into a fresh destination

```sh
python isolate.py --first-block 0 --stop-block 3 --output replay-blocks
python check_frontier.py --blocks replay-blocks --max-blocks 3 --count
```

The uncompressed-stream hash and arithmetic isolation provide independent levels of checking. Replaying only the artifact checker authenticates storage and indexing. Replaying the native call also reruns the underlying arithmetic. Different valid native implementations can produce different endpoints, so equality of stream hashes is specific to the stated implementation. The published earlier census is imported and was not rerun. No claim about zeros beyond the largest checked guard follows.
