# Independent replay with Platt's original program

This archive uses the unmodified program published by David Platt with the earlier verification. Its Arb 2.23 and FLINT 2.9 implementation runs separately from the modern FLINT 3.6.0 producer. It evaluates its own scaled completed zeta samples, searches sign changes and stationary points, and runs its own Turing count. Its parameter header permits heights from $10^{10}$ through $3.01\times10^{12}$. The source is pinned to commit d918aa093a304819a0f7d1c27bfaf67c8c0f0602. [Original repository](https://github.com/djplatt/arb_zeta/tree/d918aa093a304819a0f7d1c27bfaf67c8c0f0602) · [Parameter table](https://github.com/djplatt/arb_zeta/blob/d918aa093a304819a0f7d1c27bfaf67c8c0f0602/parameters.h) · [Turing checks](https://github.com/djplatt/arb_zeta/blob/d918aa093a304819a0f7d1c27bfaf67c8c0f0602/turing.c)

The [final combined historical inventory](checkpoint-final.json) verifies the complete interval from 3,000,175,332,800 to **3,000,176,224,460**, where the whole-strip zero count is **12,363,157,253,411**. This adds 3,816,273 distinct simple critical-line zeros over 891,660 height units. Both endpoint counts were independently recomputed with generic FLINT. The 202 raw transcripts contain 751 successful unmodified regional searches and 28 failed attempts. One 504-unit interval uses the finer historical sign sampler described below. Its 2,158 transitions exactly exhaust the original Turing difference. An independently rebuilt sampler reproduced all 98,305 signs and the packet digest. The unmodified-only prefix reaches 1,394,386 new zeros before the first interval requiring this finer sampling.

To rerun the final archival and endpoint checks, use `python check_runs.py --snapshot checkpoint-final.json --count`. The ordered transcript SHA-256 is `972a64531e7511bcc688e27a5e86ed7a1a882711dffc4952d6a129b056cd86ae`. The supplemental sign SHA-256 is `717a96f6925ade9c9cb71d40b1a50bee34ec31b1d2166e913b26677e318e4ba5`.

From this directory on Debian amd64 with gcc, git, dpkg-deb, GMP development headers and the MPFR runtime, build in a separate workspace. The builder fetches exact source and checks SHA-256 for all seven historical development and runtime packages before local extraction.

```sh
python build_original.py /tmp/riemann-legacy
python run_original.py --binary /tmp/riemann-legacy/platt-original/arb_zeta \
  --library-dir /tmp/riemann-legacy/old-libs/usr/lib/x86_64-linux-gnu \
  --until 3000175356164 --runs /tmp/riemann-legacy/runs
python check_runs.py --runs /tmp/riemann-legacy/runs --check-chains
python check_error_reserve.py
```

The executed historical binary had SHA-256 `9aa12c66e9d3c4078c408d1aa7f330fe843d0653e6558845afbac6af2ee6b691`. The optional modern endpoint check uses python-flint 0.9.0. With no arguments the checker audits the archived raw stdout transcripts in [runs](runs).

The program can return process status zero after a failed search. The checker therefore requires one original regional outcome for each requested iteration, in order, with the exact stated height boundaries. It counts a region only after the program reports that its sign search obtained exactly its Turing upper-minus-lower count. It checks that repeated endpoint counts agree and that all counts are nondecreasing in physical height. The reported frontier includes only the union of successful intervals continuously connected to the historical height. Failed searches stay visible. The runner automatically retries gaps on shifted exact dyadic grids and archives each raw result. Parallel lanes may cover separate ranges before they meet.

The [error-reserve calculation](error-reserve.md) checks the original interpolation path and its Fourier allowances at the heights in this archive, including the unused DC-bin allowance which pays the sinc truncation. The historical run returns regional counts. Individual root brackets are available in the modern producer's archive.

The optional `--check-chains` partitions successful regions into chains having exactly matching height boundaries. It checks both endpoint counts of every chain with generic zeta_nzeros. Within a chain, historical sign changes occur in disjoint open intervals and the total number found equals the modern full-strip count difference. Thus this stronger crosscheck verifies exhaustion independently of the internal historical Turing estimates. The builder also verifies every Taylor bucket residual at every archived precision.

To replay a fixed inventory after new runs have been added, select a checkpoint explicitly. For example, `python check_runs.py --snapshot checkpoint-half-million.json --check-chains` reads and hashes precisely the listed raw transcripts and recomputes their chain endpoint counts. Produce a new inventory with `python check_runs.py --check-chains --write-snapshot checkpoint-name.json`.

The audited interval widths include the wider historical producer grids through 2,184 height units. The largest grid index used, including the 21-height Turing interval and 70 interpolation nodes, is at most $65536+2184/(2(21/512))+512+70<93000$, inside the 131,072-point array. The left endpoint has the same margin. The [Fourier reserve and time-alias bounds](error-reserve.md) hold on that entire array. The old program removes its Gaussian by explicit interval multiplication on each of the requested nodes, so precision loss toward the edges can cause a failed search, which remains in the transcript inventory.

The source's regional lower count also has a direct sign-witness interpretation. In `zeros_st`, the first pass skips undetermined grid samples and counts transitions between successive definite signs. In the second pass, a positive strict middle minimum has two positive larger neighbors, and a negative strict middle maximum has two negative smaller neighbors. It adds two only when `resolve_stat_point` finds an actual opposite sign inside that same three-node interval. Thus the two zeros lie inside the two same-sign grid cells. Such triples cannot have adjacent centers, and centers two apart share only a definite endpoint. Their interiors are disjoint from one another and from the original opposite-sign transitions. Reports of the correct total therefore supply that many distinct critical-line zeros without any assumption about the zero pattern. [Original sign and stationary-point search](https://github.com/djplatt/arb_zeta/blob/d918aa093a304819a0f7d1c27bfaf67c8c0f0602/turing.c#L22-L163)

To re-execute the exact old-code searches from an inventory, run `python replay_original.py --binary /tmp/riemann-legacy/platt-original/arb_zeta --library-dir /tmp/riemann-legacy/old-libs/usr/lib/x86_64-linux-gnu --snapshot checkpoint-half-million.json`. The alternative `--transcript FILENAME.log` selects one job. The replay checks the executable hash, runs the exact original grid and precision, compares every old regional Turing upper and lower count and every sign-search success or failure, and prints a digest of those mathematical lines. Timing output varies across runs.

The [cross-implementation bracket check](repairs/check_intersections.py) intersects the two independently computed enclosures for each of the 2,158 zeros with matching global index. All intersections are nonempty. The historical eighth-grid gives indices 12363154831928–12363154831930 inside $(3000175658688.548828125,3000175658688.58984375)$. The three distinct simple zeros therefore fit inside one original mesh spacing of $21/512$.

For a combined endpoint replay, run `python check_modern_endpoints.py checkpoint-supplement-1500000.json ../checkpoint-0250.json` with python-flint installed. This binds the modern manifests to their ordered snapshot hash and checks every historical endpoint whose two neighboring zero indices lie inside that snapshot. If the time falls strictly between the adjacent modern brackets the count follows directly. Inside a bracket a separate scalar Hardy sign resolves which side of the one possible zero contains the endpoint. The parity relation is $\operatorname{sign} Z(t)=(-1)^{N(t)+1}$, from $Z(0)<0$, the even contribution of off-line pairs to $N(t)$, and the sign change at odd critical-line multiplicity. The frozen 1.6-million replay tested all 476 overlapping historical endpoint counts, 81 by separation alone and 395 with scalar Hardy signs.
