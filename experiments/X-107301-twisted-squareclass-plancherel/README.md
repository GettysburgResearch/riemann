# X-107301 — Twisted squareclass Plancherel replay

Run:

```bash
python3 verify.py
```

The replay checks the character-basis diagonalization of
\((A\star_2B)(r)=\sum_{xy^2=r}A(x)B(y)\), the nonresonant mode count, sharp
rank-free operator norm, and the two-place tensor norm.

It does not prove incomplete live-source completion, quadratic/principal
binding, RH, or GRH.
