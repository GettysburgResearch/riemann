# X-99420 — Calibration-coboundary replay

Run:

```bash
python3 verify.py
python3 tests/test_verify.py
```

The replay checks exact finite nilpotent algebra, a nontrivial signed
calibration, the first-order Volterra factorisation, a derivative-jump atom,
cumulative-tail transposition, causal coefficient mass, and hostile mutations.

It does not replay the frozen compact Hall or endpoint-frame directed
certificates and does not establish RH.
