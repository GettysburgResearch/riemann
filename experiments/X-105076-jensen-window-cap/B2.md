## 1. Windows

**Definition (admissible window).** A window is a triple (c, L, S) with c in R,
L > 0 (the window scale), and S a finite set of distinct zeros of F, such that,
writing H := 8, t* := c + iHL, rho := sqrt(4+H^2) L = 8.2463 L,
R := 2.4 rho = 19.791 L:

  (A1) S contains EVERY zero of F in the closed disk D(t*, R);
  (A2) every w in S has |Re w - c| <= L, and every non-real w in S has
       |Im w| <= L/4;  S is conjugation-closed;
  (A3) (DOM)  Sum_{w in Z(F) \ S} m_w * dist(w, D(t*,R))^{-2}
              <= theta_bg * N_S / L^2,    theta_bg := 0.0070026,
       where N_S := Sum_{w in S} m_w (pairs count both members) and the sum on
       the left runs over the multiset of zeros outside S.

A window COVERS a real interval J if J ⊆ [c - 2L, c + 2L]. For a cluster K,
any window with S ⊇ {z_j, conj z_j : j in K} whose [c-2L, c+2L] ⊇ K_span
covers K; the minimal choice is c = midpoint of the x_j-range and
L = max(half x_j-span, 4 y_max, K_span-half-span / 2) (then (A2) holds for K's
pairs and [c-2L,c+2L] ⊇ K_span since R4 y_max <= 3.733 * L/4 * ... <= 0.94 L).

**Remark.** (A1)+(A2) force: no real zero of F strictly inside the disk unless
it lies within L of c — in particular a window at scale L << dist(c, {a,b})
inside a gap automatically has S = K's pairs only and (A1) free. (DOM) is the
only quantitative hypothesis; everything else is bookkeeping.

## 2. The cone (center-value) lemma

**Lemma B2.1.** Let (c, L, S) be an admissible window. Then

  |h'(t*)| >= 0.0070026 * N_S / L^2.

Proof. Split (0.1) at t* into S-terms and the rest. For w in S: t* - w =
(c - Re w) + i(HL - Im w) with |c - Re w| <= L and HL - Im w in
[(H - 1/4)L, (H + 1/4)L] (using (A2); for real w, = HL). Hence
arg(t* - w) in [pi/2 - theta, pi/2 + theta] with theta = arctan(1/(H - 1/4)),
so arg((t* - w)^{-2}) lies in the cone of half-width 2 theta = 14.705 deg about
-pi. All S-terms of -h' therefore lie in a closed convex cone of half-angle
14.705 deg < 90 deg, and

  |Sum_{w in S} m_w (t*-w)^{-2}| >= cos(2 theta) Sum_S m_w |t*-w|^{-2}
      >= 0.967247 * N_S / (max_S |t*-w|^2) >= 0.967247 N_S / (69.0625 L^2)
      = 0.0140054 N_S / L^2,

since |t*-w|^2 <= L^2 + (H + 1/4)^2 L^2 = 69.0625 L^2 on S. The non-S terms
total at most theta_bg N_S / L^2 = half of that by (DOM) (each w outside S has
|t* - w| >= dist(w, D(t*,R)) trivially — t* is in the disk). Triangle
inequality. QED. (Constants machine-checked at 40 dps: jensen_constants.py.)

## 3. Theorem B2 (window cap)

**Theorem B2.** Let (c, L, S) be an admissible window, p_S := number of
distinct non-real CONJUGATE PAIRS in S, nu_S := number of distinct real zeros
in S. Then the number of zeros of h' (with multiplicity, real and complex) in
the disk D(t*, rho) — which contains the real segment [c - 2L, c + 2L] —
satisfies

  Z_mult(h', D(t*, rho)) <= 5.8129 p_S + 2.8500 nu_S + 0.8385.

In particular, for any real interval J covered by the window,
Z_mult(h', J) <= floor(5.813 p_S + 2.85 nu_S + 0.839).

Proof. Let q_j(t) := (t - z_j)(t - conj z_j) for each pair in S (real quadratic
> 0 on R) and r_n(t) := (t - t_n) for each real zero in S. Set

  g(t) := h'(t) * Prod_{pairs in S} q_j(t)^2 * Prod_{reals in S} r_n(t)^2.

By (A1) and the order-2 pole structure of h', g is holomorphic on D(t*, R)
(each pole of h' in the disk is a zero of F, hence in S, and is cancelled by
the corresponding squared factor; multiplicities m_w >= 1 affect only the
residue coefficient -m_w, not the pole ORDER, which is 2). Zeros of h' in the
disk are zeros of g with the same multiplicity (the divided factors vanish
only at S, and no point of S is a zero of h' — g(w) != 0 for w in S is not
needed; we only use Z(g) >= Z(h') on the disk minus S, and points of S are
poles, not zeros, of h').

Center value. |g(t*)| = |h'(t*)| * Prod |q_j(t*)|^2 * Prod |t* - t_n|^2. By
Lemma B2.1, |h'(t*)| >= 0.0070026 N_S / L^2. By (A2), |t* - z_j| >= (H-1/4) L
= 7.75 L (vertical part) and |t* - conj z_j| >= H L = 8 L, so
|q_j(t*)| >= 62 L^2; and |t* - t_n| >= H L = 8 L, so |t* - t_n|^2 >= 64 L^2.

Boundary max. On |t - t*| = R: for w in S, |t - w| >= R - max_S |t* - w|
>= (19.7909 - 8.3104) L = 11.4805 L, so |h'| <= N_S / (11.4805 L)^2 + (non-S
terms, each bounded by dist(w, D)^{-2}) <= (0.0075872 + 0.0070027) N_S / L^2
= 0.0145898 N_S / L^2. Also |t - z_j| <= R + 8.3104 L = 28.1013 L (same for
conjugates and reals with 8.2463 in place of 8.3104), so |q_j|^2 <=
(28.1013 L)^4 = 162.226 * (62 L^2)^2 and, since |t* - t_n| <= sqrt(65) L
= 8.0623 L, |t - t_n|^2 <= (27.8532 L)^2 = 12.1219 * 64 L^2.

Jensen. g is holomorphic on D(t*, R), g(t*) != 0 (the center value is a
product of strictly positive lower bounds). Jensen's inequality on the two
radii rho < R:

  Z_mult(g, D(t*, rho)) * log(R/rho)
    <= log max_{|t-t*|=R} |g| - log |g(t*)|
    <= log(0.0145898/0.0070026) + p_S log(162.226) + nu_S log(12.1219).

With log(R/rho) = log 2.4 = 0.875469: Z <= 0.83845 + 5.81288 p_S
+ 2.84992 nu_S. Finally [c-2L, c+2L] ⊆ D(t*, rho): for real u, |u - c| <= 2L,
|u - t*|^2 = |u-c|^2 + H^2 L^2 <= 68 L^2 = rho^2. QED.

be any cluster — T_K arbitrary — with minimal window scale L_K (§1). If the

  Z_mult(h', K_span ∩ G) <= floor(5.813 m_K + 0.839) <= 6 m_K,

where m_K = number of distinct pairs of K. With L-105067 Lemma 1.2 and
FINAL_LEMMA §3 Step 5 (both T-free), if EVERY cluster of G admits such a

## 4. Where the log(g/y_min) obstruction went, and the stopping recursion

**4.1 The telescoping is a single disk.** L-105063 §4 (R-C1) recorded the
Jensen route as stalling on an unabsorbable log(g/y_min): with a REAL center
c* the pair factors satisfy |q_j(c*)| ~ y_j^2 against |q_j| ~ R^2 on the
boundary, so each pair is charged log(R/y_j) — the Whitney-telescoping plan of
this lane was to spread that log over scales. Executing the plan showed the
telescoping DEGENERATES to one disk: putting the center at HEIGHT H L above
the window makes every S-factor comparable at center and boundary
(|q_j(t*)| >= 62 L^2 vs <= 162 * (62 L^2)^2 boundary — a fixed ratio,
independent of y_j), so the per-pair cost is the CONSTANT 5.813 at every
scale simultaneously, and no per-scale ledger is needed. The price moved into
the center-value problem — |h'(t*)| can no longer be floored by the real-axis
endpoint floor — and is paid by the cone Lemma B2.1: at height H L all
S-terms of (0.1) point into a 15-degree cone, so they cannot cancel each
other, and (DOM) prevents the outside field from cancelling them. The
log(g/y_min) term is GONE: nothing in Theorem B2 scales with any ratio of
scales. What remains scale-sensitive is only (DOM).

**4.2 When (DOM) holds at level 0 (S = cluster pairs only).** Outside mass at
distance >= D from the disk contributes <= (total mult)/D^2. For an interior
cluster (dist(c, {a,b}) =: d >= R + rho ~ 28 L) the outside field is the real
zeros at distance >= d - 28L plus all other pairs; in the normalization of the
scans, Sum m_n/dist^2 <= ~2/d^2 * O(1) + 8 W_far/g^2. So (DOM) holds whenever

  L^2 <= theta_bg * 2 M_K * d^2 / C_field,   i.e.   L <~ 0.084 sqrt(M_K) * d

with C_field := d^2 * (outside inverse-square mass) = O(1) for zero fields of
locally bounded density (C_field ~ 2 for an isolated gap; ~ pi^2/3 * (d/delta)^2
+ ... for spacing delta ~ d). SMALL clusters — span up to a fixed fraction of
sqrt(M_K) times their clearance — pass level 0 and get Z <= 6 m_K
unconditionally in T_K. This ALREADY covers every certified minimal example of
R-C1' in L-105067 §3(b) placed in a long gap (verified in §6).

**4.3 The stopping recursion (window inflation).** If (A1)/(A2)/(DOM) fail at
level 0, inflate: S <- all zeros of F within the current disk (plus whatever
(A2) forces), c <- midpoint of Re-span of S, L <- max(half Re-span, 4 y_max),
and retry. Each swallowed DISTINCT real zero costs +2.85, each swallowed
distinct pair +5.813, but also RAISES the budget N_S. For every finite
configuration (all scans; any polynomial F) the recursion terminates: when S
exhausts Z(F), the left side of (DOM) is empty. Thus for finite fields
Theorem B2 always applies with the terminal window:

  Z_mult(h', K_span ∩ G) <= 5.813 p_S* + 2.85 nu_S* + 0.839    (B2-T)

with (p_S*, nu_S*) of the terminal window. The bound is USEFUL iff the
recursion stops early (S* stays comparable to K); it is vacuous-ish if S* must
swallow mass >> M_K.

**4.4 Where the recursion genuinely fails (the honest frontier).** In an
infinite field with real zeros of spacing delta and a window at scale L, the
zeros in the horizontal annulus (L, 28 L) are inside the disk, hence forced
into S by (A1), but (A2) then forces L to inflate by ~28; self-similarly, at
every scale the annulus population is ~27 times the core population. Whether
(DOM) eventually holds is a race between the swallowed budget theta_bg * N_S
/ L^2 ~ theta_bg * 2/(L delta) * ... and the tail mass ~ 2/(28 L delta):
numerically theta_bg * 56 = 0.392 versus 2/28 = 0.0714 — the budget WINS by
factor 5.5 once a full annulus has been swallowed, PROVIDED the field density
is non-increasing outward at the relevant scales. So: for fields of
(eventually) subpolynomial density growth the recursion terminates in O(1)
inflations; the cost is nu_S* ~ 56 L*/delta real zeros at the terminal scale
L*. The bound (B2-T) then reads

  Z <= 5.813 p_S* + 2.85 * (#real zeros within ~28 L* of c) + 0.839,

and the second term is NOT dominated by C * W(G): a cluster whose terminal
scale L* is many real-zero spacings pays for real zeros that carry no gap
weight. THIS is the surviving obstruction — sharpened from "an unabsorbable
log(g/y_min)" to "2.85 per real zero inside the terminal window".
