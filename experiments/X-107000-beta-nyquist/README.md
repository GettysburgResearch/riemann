# X-107000 — beta Nyquist compression replay

This lightweight standard-library replay checks:

- normalization and monotonicity of the logarithmic box widths;
- the explicit active-factor bound underlying near-exponential decay;
- finite Fourier-product envelopes on a deterministic grid;
- exact finite Fourier-series Parseval identities;
- the almost-quadratic sample-count formula;
- the coherent rank-one countermodel.

It does not prove the infinite analytic theorem, `NBV107000`, or RH.
