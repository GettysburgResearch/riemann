# X-0701 — Carrier-shifted compact-support Weil search

**Status:** `EMPIRICAL`. No interval certificate and no counterexample.

## Question

Can compact Fourier support be translated to a carrier `T > 3e12`, avoiding the
`N roughly T*log(c)/(2*pi)` band requirement of an unshifted Galerkin basis, and
produce a finite negative Weil witness?

## Families

`triangular.py` implements

```text
g_hat(xi) = (1-|xi|/Delta)_+ cos(2*pi*T*xi),  Delta=log(c)/(2*pi).
```

The inverse transform is an average of two translated squared-sinc functions,
so it is even and nonnegative on the real axis.

`carrier_matrix.py` implements the richer finite Gram family generated by

```text
f_j(x) = 1_[−Delta/2,Delta/2](x) cos(2*pi*(T+j/Delta)*x),  -N<=j<=N,
g_v(z) = (sum_j v_j F_j(z))^2.
```

Every real vector gives a real-axis nonnegative entire test function. Its Fourier
weight is compactly supported in `[-Delta,Delta]`, hence the prime side is a
finite sum over prime powers `q<=c`.

## Exact identities encoded

For `ell=Delta-|xi|`, the convolution kernel is

```text
C_ab(xi) = ell/2 * [
  sinc((a+b)ell) cos(pi(a-b)xi)
  + sinc((a-b)ell) cos(pi(a+b)xi)
].
```

The Gram entry is `C_ab(0)`. The prime entry is the complete finite sum

```text
-(1/pi) sum_{q=p^r<=c} Lambda(q)/sqrt(q) C_ab(log(q)/(2*pi)).
```

The compact archimedean identity is recorded in `L-0701` and `L-0702`.
The Python evaluations are ordinary arbitrary precision, not balls.

## Discovery approximation

For frequencies `a_j=T+j/Delta` and huge `T`, the normalized leading matrix is

```text
log(T/(2*pi))/(2*pi) I - S(T),
```

where

```text
S_jk(T) = sum_{q<=c} Lambda(q)/(pi*sqrt(q))
          * (1-t_q) sinc((j-k)(1-t_q))
          * cos(T log(q)+pi(j+k)t_q),
t_q = log(q)/log(c).
```

The complete leading reevaluation includes every prime power through `c`.
It still omits small exact Gram, archimedean, pole, and negative-frequency
corrections, so even a leading negative would only nominate a candidate.

## Commands

```bash
python -m pytest -q
python search.py --c 10000000 --carrier 3157430112465.479 --N 12 \
  --output results/reproduce-near-miss.json
```

The large command uses 665,134 prime-power terms. In the recorded environment it
completed in about 13 seconds and used about 200 MB of resident memory.

## Main results

1. Top-prime truncations produced apparent negative values in dimensions 17 and
   25 above `3e12`.
2. Complete reevaluation over all 665,134 prime powers through `10^7` reversed
   both signs to positive. This is a concrete refutation of truncated-prime
   candidate promotion.
3. The best complete leading near miss retained was approximately
   `+0.18535251496676164` at
   `T=3157430112465.479`, `c=10^7`, `N=12`.
4. Increasing to `N=16` at the same carrier gave approximately
   `+0.18491323202279908`.
5. No `Z-####` candidate was created.

## Proof boundary

A valid counterexample from this family requires all of the following:

1. exact carrier, cutoff, and dyadic vector;
2. certified complete prime generation through `c`;
3. outward-rounded phases and finite prime entries;
4. rigorous compact archimedean and pole enclosures;
5. an exact generalized Rayleigh upper bound below zero;
6. independent reconstruction of the explicit-formula normalization;
7. independent reproduction.
