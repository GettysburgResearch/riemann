# X-9310 — Exact one-node Padé/support-gap checker

X-9310 verifies the finite algebra in L-9312 using only Python integers and
`fractions.Fraction`.

Given:

- directed old moment intervals \(a_0,\ldots,a_{2n}\);
- one exact new node \(w=x^2\);
- a directed interval for the sole new scalar \(b_0(w)\);
- an optional certified residual support lower bound \(A\);
- optional rational lower- and upper-bound witness vectors;

it reconstructs

\[
a_k=b_{k+1}+w b_k,
\]

and builds

\[
H_0=(b_{i+j}),
\qquad
H_A=(b_{i+j+1}-A b_{i+j}).
\]

## Decisive outputs

```text
CERTIFIED_NEGATIVE_LOWER_SQUARE_WITNESS
CERTIFIED_NEGATIVE_SUPPORT_LOCALIZER_WITNESS
CERTIFIED_POSITIVE_ONE_NODE_PADE_INTERVAL
UNRESOLVED_ONE_NODE_PADE_INTERVAL
```

A negative lower witness corresponds to the explicit response polynomial

```text
P(y) = q(y)^2.
```

A negative support-localizer witness corresponds to

```text
P(y) = (y-A) q(y)^2.
```

For positive closure, the checker performs exact rational LDL on each midpoint
matrix after subtracting a declared rational moat `closure_delta * I`.  It then
bounds the complete interval-box perturbation by the exact maximum row sum of
entry radii.  No floating eigensolver or SDP solver enters the trust boundary.

## Synthetic controls

The positive control is generated by the two-point old measure

```text
mu = delta_1 + delta_3
w = 1
```

with old moments

```text
a0=2, a1=4, a2=10
```

and exact new value

```text
b0 = 1/(1+1) + 1/(3+1) = 3/4.
```

The same old moments with fake values `b0=0` and `b0=2` produce, respectively,
a strict lower-square violation and a strict upper/localizer violation.

Seven adversarial tests pass.

## Reproduction

```bash
cd experiments/X-9310-one-node-pade-gate
python -m unittest discover -s tests -v
python verify_one_node_pade.py certificates/synthetic-positive.json \
  --output results/synthetic-positive-verification.json
python verify_one_node_pade.py certificates/synthetic-lower-negative.json
python verify_one_node_pade.py certificates/synthetic-upper-negative.json
```

The checker returns exit code `1` for a certified negative and `0` otherwise.
Malformed certificates return exit code `2`.

## Riemann-ξ production contract

A production certificate must bind:

1. the old directed moment artifact;
2. the new directed completed-ξ rectangle or an independently checked directed
   \(b_0\) contraction;
3. the exact node \(w\);
4. every selected-factor/count artifact;
5. the support lower bound \(A\), if used;
6. the rational witness vector or positive matrix moat;
7. normalization and common-scale fingerprints.

The synthetic files are checker controls only.  No Riemann-ξ negative is
included.
