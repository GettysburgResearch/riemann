# Fixed holomorphic defects

A signed correction may be harmless when it is genuinely fixed and its Mellin transform is holomorphic throughout the pole-detection half-plane.

The canonical typed decomposition is:

\[
f=d+e,\qquad d\ge0,
\]

where `e` is fixed and `M[e](s)` is holomorphic for `Re(s)>0`. Then `e` cannot cancel an off-critical reciprocal-zeta pole of `f`.

This rule does not permit:

- calling a signed observation a positive source;
- changing the defect with the hypothetical zero or horizon;
- using an unproved `sqrt(X)`-scale calibration as though it were holomorphic;
- changing source ownership or row normalization.
