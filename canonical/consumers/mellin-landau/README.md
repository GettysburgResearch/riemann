# Mellin-Landau consumer

This package is the canonical conclusion-facing API for the 2026-08-22 integration.

> **The consumer is reviewed. The arithmetic producer is open. RH remains unproved.**

The point of the API is to prevent a recurring category error: a clean Mellin/Landau implication is not itself a proof of the sign or one-sided estimate fed into it.

## Available fixed detectors

- fixed component rows;
- the fixed pair of rows `2` and `3`;
- the single fixed scalar `5c_X(2)+3c_X(3)`;
- corrected fixed annular rows `2` and `3`;
- other fixed zero-safe native scalars satisfying the contract.
