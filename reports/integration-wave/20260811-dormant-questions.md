## 1. Cycle-optimized boundary transference below the solved outer band

**Question.** Let the complete activated cutoff boundary be recombined at common arithmetic destinations. Can one construct explicit Pascal-cycle coordinates whose total negative capacity is polylogarithmic through every support-halving generation?

**Why it is live.** PR #315 proves that the macroscopic band responsible for the linear atomic lower bound has an exact nonnegative central carry realization. It also proves that the coherent boundary has only `O(log^2 X)` mass in the carry-column metric. PR #317 supplies exact shift terminalization and identifies the pure-central recombination firewall. PR #335 converts the target into negative Green occupation.

**Why it is not refuted.** PR #356 closes finite stationary atomic spectral-gap policies, not nonstationary Pascal-cycle corrections chosen from the current state.

**Binary falsifier.** Produce a family of feasible dual capacity drifts whose pairing with the recombined boundary is `X^c` for a fixed `c>0`, uniformly against the allowed cycle menu. A single unsolved central-row witness is insufficient because outer-band optimization is already known to change the norm by a power.

**Recommended first packet.** Freeze one half-scale generation, emit the exact destination-recombined boundary, solve its finite dual symbolically by quotient cells, and test whether the optimizer uses a bounded cycle vocabulary or genuinely growing state.

## 2. All-generation actual boundary norm stability

**Question.** For the exact decoder

```text
u_m = sum_{k<=X/m} mu(k) h(mk),
A(h) = sum_m u_{m+1}(T_{m+1}-T_m),
```

can the complete sequence of actual Duhamel/Euler boundary targets, after equal-destination recombination, satisfy a polylogarithmic total in a faithful carry or divisor-weighted norm?

**Why it is live.** The decoder is exact and noncoprime-safe. The former positivity and tensorization arguments failed, but the map itself did not. Later outer-band and Green-occupation results provide norms that were unavailable in the original attempt.

**Avoided trap.** Do not estimate formal modal components before arithmetic destinations are recombined. PR #304 proves that this can create a false linear obstruction.

**Binary falsifier.** An exact macroscopic cell on which the recombined, not formal, target is forced and has polynomial optimized carry debt.

**Binary falsifier.** One rigorously enclosed zero with `Re z>1/4` for a finite `N`.
