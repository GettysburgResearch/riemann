## Main result

For the Stieltjes density already proved on PR #758,

\[
\Psi(q)=\Phi(\sqrt q)=\int_{16}^{\infty}\frac{\rho(t)}{t+q}\,dt,
\]

the physical imaginary boundary satisfies:

```text
0 <= |y| < 4:
  Phi(iy) is positive real and strictly increasing in y^2;

|y| > 4, away from 4(2k+1):
  the right-face boundary has imaginary part -pi rho(y^2)<0;

|y| = 4(2k+1):
  Phi has a square-root branch singularity.
```

At the first edge,

\[
\Phi(iy)\sim\frac{288}{\pi^3\sqrt{16-y^2}}.
\]

At the \(m\)-th odd threshold, the new density channel has coefficient

\[
\frac{288}{\pi^4m^3\sqrt{t-16m^2}}.
\]

Therefore the limiting profile has no boundary zero.  The first edge is a
branch threshold, not a kernel-cancellation point.
