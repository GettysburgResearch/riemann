## Advance

PR #720 turns downward reverse Rolle into a first/second residue-moment
problem. Its first-moment continuation identifies a centered root variance,
but the second moment was left as a local-contour observable.

This packet gives the missing exact finite-polynomial ledger. For a monic
degree-n polynomial p, put

\[
\rho_c=\frac{p(c)}{p''(c)}
\quad (p'(c)=0),
\qquad
\tau_d=\frac{p(d)^2}{p'(d)p'''(d)}
\quad (p''(d)=0).
\]

If \(V_j=\sum_r(z_r-\bar z)^j\) is the centered root power sum, then

\[
\sum_{p'(c)=0}\rho_c^2+\sum_{p''(d)=0}\tau_d
=
\frac{(6n^2-18n+13)V_2^2
-3n(n-1)(n-2)V_4}
{n^4(n-1)^3}.
\]

For a real polynomial this yields an exact decomposition of the real
critical-residue second moment into:

1. an explicit complete-root fourth-moment ledger;
2. an off-real critical-point correction;
3. a second-derivative cross-residue debt.

The quartic \(x^4-2x^2+2\) proves that the debt is load bearing:

\[
\sum_{p'(c)=0,\ c\in\mathbb R}\rho_c^2=\frac9{32},
\qquad
\mathcal K_4(p)=\frac{37}{432},
\qquad
\sum_{p''(d)=0}\tau_d=-\frac{169}{864}.
\]

Thus the root ledger alone is not an upper bound for the desired second
moment.
