# Exact native cutoff-boundary identities

## 1. One-prime cutoff boundary

Define
[
R_Y(n):=sum_{substack{dmid n\dle Y}}mu(d).
]

Let (ellmid n) be prime and write (n=ell^a m) with ((ell,m)=1). Since only squarefree divisors contribute, divisors of (n) are partitioned into pairs (d,ell d) with (dmid m), and
(mu(ell d)=-mu(d)). Therefore
[
R_Y(n)
=
sum_{substack{dmid m\dle Y}}mu(d)
-
sum_{substack{dmid m\ell dle Y}}mu(d)
=
sum_{substack{dmid m\Y/ell<dle Y}}mu(d).
	ag{1}
]

Equation (1) is exact for every (Y,n,ellmid n). It identifies the residual as the signed set of divisor pairs separated by the cutoff.

For (1<nle Y), the full divisor sum is present and (R_Y(n)=0), recovering Möbius inversion.

## 2. Boundary support as an antichain for the least prime

Assume (ell=P^-(n)), the least prime divisor of (n). Put
[
mathcal B_{Y,ell}(m)={dmid m:mu(d)
e0,;Y/ell<dle Y}.
]

Then (mathcal B_{Y,ell}(m)) is an antichain under divisibility.

Proof. If (d_1mid d_2) are distinct squarefree divisors of (m), then (d_2/d_1) has a prime divisor (qmid m). Since (ell) is the least prime divisor of (n), (qge ell). Hence (d_2/d_1geell). But both points lie in ((Y/ell,Y]), so (d_2/d_1<ell), contradiction. (square)

This is structural information absent from arbitrary balanced coefficient models.

## 3. Boundary-vector formulation

For each prime (ell), define a signed boundary vector indexed by squarefree (d):
[
b_{Y,ell}(d):=
mu(d),mathbf 1_{Y/ell<dle Y}.
]

For (n=ell^a m) with ((m,ell)=1),
[
R_Y(n)=sum_{dmid m} b_{Y,ell}(d).
	ag{2}
]

The advantage of (2) is not a norm estimate by itself. It preserves the source-specific incidence relation (dmid m). Any useful gain must exploit that relation before replacing the signed sum by an absolute one.

## 4. Two-prime second-difference identity

Let distinct primes (p,q) divide (n), and write (n=p^a q^b m), ((m,pq)=1). Pairing in both coordinates gives
[
R_Y(n)
=
sum_{dmid m}mu(d)
Big(
mathbf 1_{dle Y}
-mathbf 1_{pdle Y}
-mathbf 1_{qdle Y}
+mathbf 1_{pqdle Y}
Big).
	ag{3}
]

Equivalently, the bracket is the discrete mixed second difference of the cutoff indicator on the multiplicative square ({1,p}	imes{1,q}).

Thus the residual can be represented not merely as 'missing divisors' but as a hierarchy of exact multiplicative boundary differences.

This is the closest elementary analogue in the current Newton setting to the Sylvester paper's rule 'take the arithmetic operation before the vanishing projection': delay coalescing/absolute values until after multiplicative boundary differences are exposed.

## 5. Relation to the existing Newton residual

For the literal truncated Möbius source
[
g_Y(n)=mu(n)mathbf 1_{nle Y},
qquad
e_Y=delta-mathbf 1*g_Y,
]
one has for (n>1)
[
e_Y(n)=-R_Y(n).
	ag{4}
]

The exact Newton identity already used in #848 is
[
mathcal N(g_Y)=g_Y+g_Y*e_Y,
]
and the general error identity is
[
mu-mathcal N(g_Y)=mu*e_Y*e_Y.
	ag{5}
]

Combining (1)--(5) says that the next-stage error is generated by **collisions of cutoff-crossing divisor boundaries**. That is a sharper source description than treating (e_Y) as an arbitrary small/balanced vector.

## 6. Interaction kernel to retain before Cauchy

Write
[
e_Y(n)=-sum_{ellmid n}^{star}
sum_{substack{dmid n/ell^{v_ell(n)}\Y/ell<dle Y}}
w_{n,ell},mu(d),
]
where (star) denotes a chosen deterministic prime assignment (for example the least prime divisor) and (w_{n,ell}) is 1 for that assignment and 0 otherwise.

Then a quadratic output energy can be expanded into terms indexed by pairs
[
(ell,d),(ell',d').
]

The proposed primitive covariance is therefore
[
mathfrak C_Y((ell,d),(ell',d'))
=
sum_{xin mathcal A_Y}
K_Y(x;ell,d),K_Y(x;ell',d')
]
with the actual Möbius signs (mu(d)mu(d')) left outside until the final sum.

The exact form of (K_Y) should be matched to the current #848 annular kernel / distinct-product covariance rather than introducing a new energy. The mathematical goal is to prove cancellation after grouping by boundary geometry (shared primes, lcm/gcd, interval overlap), not to assert pairwise negativity.

## 7. Important non-claims

- The antichain lemma alone does not imply a subpower bound.
- Boundary cardinality alone is too weak; it throws away signs.
- Pairwise covariance need not be nonpositive; #848 already has literal positive pairs.
- No cohomological object analogous to the elliptic-curve Tate boundary has been constructed here.
- The Sylvester norm--projector identity has no literal Hilbert-space scalar-division analogue.
- RH remains open.

The value of these identities is that they identify a narrower class of source configurations that generic counterfamilies do not satisfy.
