# Validation and trust boundary

This packet's Python code uses only the standard library, integer arithmetic,
and fractions. The elementary logarithms are enclosed by a range-reduced atanh
series with an explicit positive tail, then rounded outward to 112-bit dyadics.
No float, numerical optimizer, special-function library, zero table, or external
interval producer enters acceptance.

The new proof is a paper proof. The bounded checker is an error-detection aid
for its algebra, constants, and source bookkeeping, not a formalization of its
infinite analytic arguments. The SHA-256 manifest authenticates bytes; it does
not establish their mathematical correctness. Both inherited manuscript blob
identities are independently hard-coded and checked before reconstruction.

Fixtures cover one-atom Laurent derivatives and jumps; exact signed Green
integrals on rational scaled atoms; curvature, grid, and run constants; the
Mellin multiplier at exact half-integer/integer arguments; prime-factorization
and Mobius divisor identities; exact finite native renewal in formal prime-log
coordinates; six bounded native scalar enclosures; and nine interpolation
checks. The native enumeration stops at prime powers through 2500.

Normal and optimized executions, exact fixture counts, and the fixture digest
are recorded in result.json. Test rejections run the actual checker on temporary
copies and retain the full source layout. A changed result is compared by typed
canonical JSON, so Boolean/integer aliases do not pass. Deliberate corruptions
also exercise source pins, duplicate JSON keys, manifest and parent bytes.

No predecessor producer, full remote checkout, Lean/Comparator/kernel build,
CI run, zero verification, or independent referee acceptance is claimed. The
annular parent's conditional RH margin is a named inherited dependency, not a
freshly certified inequality in this packet. Publication and ZIP execution
receipts are delivered separately; they are not new mathematical premises.

Executed on the final packet: 522 bounded fixtures in 12 named groups passed
in both normal and optimized Python, with byte-identical reconstructed results.
All eight deliberate corruption cases were rejected in each mode (16 actual
subprocess refusals). These fixture counts include 256 small divisor identities
and 144 one-atom Green integrations; they are not theorem or independence counts.
