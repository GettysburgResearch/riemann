The all-scale statements are proposed written proofs, not extrapolations from
finite computations. No zeta evaluator, zero coordinates, random sampling,
floating-point arithmetic or external package enters accepting reconstruction.

binds those full rows rather than storing enormous repeated rational fractions.
Both programs recompute them; neither imports the other or repository modules.

- 18 prime-product injection panels give exact combinatorial plateau LOWER

## Distinct reconstruction routes

The producer uses a prime sign sieve, grouping by bitmasks, streaming integer
prefix squares, and streaming twin-label correlations for greedy selection.
It enumerates all signs only in the declared small families.

The verifier uses trial factorization, the complete ordered max-kernel work
identity with terminal subtraction, exact rough integrals at RATIONAL endpoints,
and causal Euler quotients to regenerate each twisted coefficient. Greedy
choices are obtained by separately computing both conditional energies, not
by importing the producer's correlation update. Prime-product lists for the
lower bound are reconstructed by subset products and factor counts.

The prime/smooth coefficient data, ensemble rows and full digest are identical.
The two implementations have the SAME author. Alternative code paths and Python
-O agreement are NOT independent mathematical review or a proof assistant.

## Acceptance and refusals

The accepting verifier authenticates a required flat nine-file packet and every
non-manifest file hash, rejects missing/extra/nonregular/symlink files, duplicate
JSON keys, noninteger numeric syntax and nonfinite constants, and compares its
new primitive reconstruction using canonical TYPED JSON. No assert implements
acceptance. A malicious replacement of both checker and manifest is outside
self-authentication; immutable Git/file pins provide that external boundary.

Each --self-test reconstructs the pristine report and refuses 12 distinct
resealed modified objects through the same acceptance function. Changes affect
status, source pin, coverage, energies' primitive digests, coefficient counts
and numeric types, including Boolean/integer and integral-float aliases.
Duplicate-key rejection is a separate parser test. These are not 12 complete
subprocess reconstructions. Additional copied-packet CLI checks, if performed,
are recorded separately outside this immutable packet.
