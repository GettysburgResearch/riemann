10^(-40) grid. The new checker uses only the Python standard library.

The 194 recomputed checks cover the finite rank-two atom identity,
two-channel strict independence and characteristic polynomial, gamma
partial-fraction coefficients, the triangle integral Gram factorization,
the independent primitive-norm identity, parent integrity, and actual
source inequalities used in the analytic local-positivity proof.

The actual constants are rebuilt from finite rational logarithm, arctangent,
exponential, harmonic and Euler--Maclaurin series with the remainders proved

acceptance. The normal and optimized command receipts are in REPLAY.json.

Corruption refusals cover a changed saved endpoint, a float alias for an
integer, a Boolean alias, a duplicate JSON key, changed new proof bytes,
a changed parent commit lock, and changed parent proof bytes. Every case
is run in both modes and required to fail for its intended diagnostic.
The genuine script does not use Python assert for acceptance checks.
