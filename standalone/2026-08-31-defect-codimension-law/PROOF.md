## Setting

Work over a field of characteristic 0. An EXPONENTIAL POLYNOMIAL is a
function `phi: Z -> K` of the form `phi(k) = sum_mu r_mu(k) mu^k`, a
finite sum over nonzero `mu in K^bar` with polynomial coefficients
`r_mu`. Every sequence satisfying a linear recurrence with nonzero
constant term is of this form on `k >= 0`, and `phi(-k)` (the CANONICAL
BACKWARD CONTINUATION) is well-defined: it is both "run the recurrence
backwards" and "evaluate the closed form at negative arguments" (these
agree, since both satisfy the same recurrence on all of Z with the same
initial window). Two exponential polynomials agreeing on all `k >= 0`
agree on Z (linear independence of characters + polynomial rigidity),
so products and compositions with affine maps `k |-> u k + v` (`u >= 1`)
of exponential polynomials have unambiguous continuations.

For a degree-`d` local object with Satake data `e_1, ..., e_d`
(`e_d != 0`), the coefficient sequence `h_k` is an exponential
polynomial with the CLASSICAL BACKWARD VANISHING

```text
(BV)    h_{-1} = h_{-2} = ... = h_{-(d-1)} = 0 ,
        h_{-d} = (-1)^{d-1} / e_d != 0 .
```

(Proof of (BV): `h_k = sum_i x_i^{d-1+k} / prod_{j != i}(x_i - x_j)`
for distinct roots; at `k = -1, ..., -(d-1)` this is the Lagrange
interpolation identity `sum_i x_i^t / prod_{j != i}(x_i - x_j) = 0` for
`0 <= t <= d-2`, and at `k = -d` it equals the `t = -1` case
`(-1)^{d-1}/prod x_i`. Both identities are the coefficients of the
partial-fraction expansion of `x^t / prod (x - x_i)`; they persist for
coincident roots by continuity/specialization.)

## Lemma (reciprocity; classical)

Let `phi` be an exponential polynomial and
`F(T) = sum_{k >= 0} phi(k) T^k = N(T)/Q(T)` its (automatically
rational, proper) generating function in lowest terms,
`Q(0) = 1`. Then the Laurent expansion of `F` at `T = infinity` is

```text
F(T) = - sum_{j >= 1} phi(-j) T^{-j} .
```

**Proof.** By linearity it suffices to treat `phi(k) = k^c mu^k`,
generated by `F_c,mu(T) = (T d/dT)^c [ 1/(1 - mu T) ]`. At infinity
`1/(1 - mu T) = - sum_{j >= 1} mu^{-j} T^{-j}`, and `T d/dT` maps
`T^{-j}` to `-j T^{-j}`, giving
`(T d/dT)^c [.] = - sum_{j>=1} (-j)^c mu^{-j} T^{-j}
= - sum_{j >= 1} phi(-j) T^{-j}`. ∎

## Theorem 1 (codimension law)

Let `phi` be an exponential polynomial with proper rational generating
function `F = N/Q` in lowest terms, `D := deg Q`. Define the BACKWARD
VANISHING ORDER

```text
nu(phi) := min { j >= 1 : phi(-j) != 0 }     (finite unless phi = 0).
```

Then

```text
deg N = D - nu(phi) ,
```

and the leading coefficient of `N` is
`c_top(N) = - q_D * phi(-nu)` where `q_D` is the leading coefficient
of `Q`.

**Proof.** Near `T = infinity`, `N/Q = (c_top(N)/q_D) T^{deg N - D}
(1 + O(1/T))`, so the vanishing order of `F` at infinity is exactly
`D - deg N`. By the Lemma that order is `min { j : phi(-j) != 0 } =
nu(phi)`, and the leading Laurent coefficient is `-phi(-nu)`, giving
`c_top(N)/q_D = -phi(-nu)`. (Finiteness of `nu`: if `phi(-j) = 0` for
all `j >= 1` then `F` vanishes identically at infinity to all orders,
impossible for a nonzero rational function.) ∎

Note the theorem needs NO genericity: `Q` is the true minimal
denominator, whatever degenerations the parameters have.

## Corollaries (the observed laws)

**Corollary 1 (codimension-d law for Hadamard powers).** For the
degree-`d` object, `phi(k) = h_k^m` has `phi(-j) = h_{-j}^m = 0` for
`1 <= j <= d-1` and `phi(-d) = ((-1)^{d-1}/e_d)^m != 0` by (BV), so
`nu = d` and

```text
deg N_{m,d} = deg Q - d .
```

Generically `Q = det(1 - Sym^m(A) T)` is full
(`deg Q = C(d+m-1, m)`), giving the grid law
`deg N_{m,d} = C(d+m-1, m) - d` verified in all ten atlas cells; every
degeneration lowers `deg Q` and `deg N` together, keeping codimension
`d` — this refines T-108500(5)'s degeneration bookkeeping.

**Corollary 2 (top-coefficient law).** For `phi = h_k^m`,
`c_top(N) = - q_D * ((-1)^{d-1}/e_d)^m`. For `m = 2`,
`Q = det(1 - Sym^2 A T)` has `q_D = (-1)^{C(d+1,2)} prod_{i<=j} x_i x_j
= (-1)^{C(d+1,2)} e_d^{d+1}`, so

```text
c_top(N_{2,d}) = (-1)^{C(d+1,2)+1} e_d^{d-1} = (-1)^{C(d-1,2)} e_d^{d-1}
```

(the two sign forms differ by `(-1)^{2d-1... }`: their exponents differ
by `C(d+1,2) + 1 - C(d-1,2) = 2d` — even — so they agree). This is
EXACTLY the top-coefficient sign law of T-108508, previously proved
only for `d <= 5`, now proved for ALL d.

**Corollary 3 (Hadamard products of several objects).** For
`phi(k) = prod_t h_k^{(t)}` over objects of degrees `d_1, ..., d_r`
(with multiplicities for repeated factors), `phi(-j)` vanishes as soon
as ANY factor does, so (BV) gives `phi(-j) = 0` for
`j <= max_t d_t - 1` unconditionally, and at `j = max_t d_t` the
deepest factor contributes `+-1/e_{d}` while the shallower factors
take generic nonzero backward values: GENERICALLY

```text
nu = max_t d_t :
```

the defect codimension of a Hadamard product is the MAXIMUM degree
among the factors (always `nu >= max_t d_t`). Verified: mixed cube
`h_A^2 h_B` with degrees `(2,2,2)`: codimension 2 (`deg N = 6 - 2 =
4`), six for six; and the discriminating mixed triple with degrees
`(2,3,4)`: codimension 4, not `min = 2` — the X-108510 replay's V3
test was BUILT expecting the min-law and refuted it, and this
corollary records the corrected statement. The Rankin case `h_A h_B`
(degrees `(2,2)`) has codimension 2 — matching the classical numerator
`1 - (det A)(det B) T^2`.

**Corollary 4 (shifts).** `phi(k) = h_{k+s}^m` (`s >= 1`) has
`phi(-1) = h_{s-1}^m` — generically nonzero — so `nu = 1`: ANY forward
shift collapses the codimension to 1. (Verified: shift-then-square at
`d = 2`: `deg (N, Q) = (2, 3)`, four for four.)

**Corollary 5 (sections).** `phi(k) = h_{uk}^m` (`u >= 2`) has
`phi(-j) = h_{-uj}^m`, first nonzero at the least `j` with `uj >= d`:
`nu = ceil(d/u)`. (Verified: `u = 2, d = 2, m in {1, 2}`: `nu = 1`,
degrees `(1,2)` and `(2,3)`, four for four.)
