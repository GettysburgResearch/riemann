```bash
./build.sh
```

```bash
./replay.sh
```

`T97500_GITHUB_TEXT_SHA256SUMS` text ledger, not the compiled PDF blob.  Replay
rebuilds the PDF locally before checking every tracked text artifact.  The
canonical compiled PDF mirror is:

