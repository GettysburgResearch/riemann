# Validation and review boundaries

Status: author checks supporting a proposed paper theorem, not independent
mathematical acceptance or a machine proof of the infinite argument.

## Executed scope

The standalone standard-library checker reconstructs 56 bounded fixtures:
24 rational two-vector geometries, 24 synthetic pigeonhole configurations and
eight rational constant identities. Each geometry checks the exact positive
metric, orthogonality, sharp condition number, spectral projector, and its exact
norm. These subchecks are not counted as separate theorems. Ordinary and optimized
isolated Python give identical JSON.

The mathematical proof is not based on numerical zeta values or a sampled zero
list. The classical Bui--Conrey--Young simple-zero theorem and Riemann--von
Mangoldt asymptotic are explicit imports. Their complete external proofs were
not replayed. The PDF theorem text was read; the web screenshot request failed.
No new zero-density result or numerical threshold is claimed.

Five actual changed-copy refusals are exercised in EACH Python mode, after a
pristine control: resealed false RH status, resealed Boolean/integer alias,
resealed duplicate JSON key, resealed producer change reversing the sharp metric
ratio, and an unsealed altered manuscript. The producer change is rejected by
independent rational reconstruction, not merely a checksum comparison.

Seven payload files and six hashes are checked. The copied parent manuscript's
19,077 bytes were locally authenticated to Git blob
`ef01f74c50d4efacb615176cbfed4a3de2fd1147`. The parent proof was read; no parent
producer or test suite was executed. Package hashes authenticate bytes, not
truth of mathematical claims.

Commands:

```
python -I -S -B check.py --check result.json
python -I -S -B -O check.py --check result.json
```

`--emit` is a producer mode and does not authenticate the file inventory. It is
not interchangeable with `--check`.

## Delivery checks

A temporary minimal Git repository is used for the add-only patch roundtrip;
its unrelated sentinel is preserved, every payload byte is compared, and both
checker modes are rerun. A separately extracted ZIP is checked in both modes.
These are isolated packet checks, not a complete riemann checkout, full graph
validation, remote CI, formalization, or a native Windows execution.

## Review priorities

Reconstruct the exact exponential/sine eigenvectors and their membership in the
infinite intersection, the distinction between counting simple zeros and counting
multiplicity, the factor lost when converting sine vectors to unit norm, and the
adjoint convention for invariant restrictions. The local-weight result has a
finite-measure condition; the sine extension additionally uses Fourier decay.
Do not infer a failure of RH from failure of bounded similarity. Real spectrum
does not imply bounded similarity to a self-adjoint operator.
