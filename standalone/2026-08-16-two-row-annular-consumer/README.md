The old endpoint consumer is withdrawn: exact native saturation prices `P_Lambda`, not `J_Lambda`. The replacement uses the Mellin transform of the annular coefficient itself.

```text
eventual a_X(2)>=0 and a_X(3)>=0
 -> exact fixed-row transform with (1-4^-s)/zeta(s+1/2)
 -> exact P2/P3 noncancellation

```
