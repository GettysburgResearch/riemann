# Validation scope

The accepting program is standard-library Python with exact integers and
Fractions. It does NOT evaluate theta, zeta, gamma, a complex contour, or any
actual zero. The mathematical theorems are paper arguments; external Lee--Yang
and Li--Radziwill theorems and the parent's seed evidence remain stated inputs.

## Reconstructed finite objects

Five complete clone graphs (largest 12 spins) retain every spin configuration:
5568 configuration instances in total. The checks verify graph degree and
connectedness, the entire bad-event probability, exact alignment-conditioned
source law including bridges, and all six raw-moment error bounds. Zero
observable weights in the original model are included in a test case.

Seven separate small graphs are evaluated by TWO different finite expansions:
134 spin configurations and 559 random-cluster edge subsets. Every cluster
weight and covariance term is retained. These are independent algebraic
expansions by the same author, not non-author verification.

177 exact binomial bath moments check the paired-index lower bound and falling
factorial cost. Eighteen formal rational jet panels check the implicit derivative
identity; these are NOT a new evaluation of the actual K8/4096-spin seed.
Three two-spin lattice polynomials and 31 finite variance panels complete the
finite controls. Configuration instances and subchecks are not counted as new
mathematical theorems.

## Commands

```
python -I -S -B check.py --check result.json
python -I -S -B -O check.py --check result.json
python -I -S -B test_check.py --part 1
python -I -S -B test_check.py --part 2
python -I -S -B test_check.py --optimized --part 1
python -I -S -B test_check.py --optimized --part 2
```

Each test part begins with a pristine copy. Across both parts there are eight
actual refused cases per mode: resealed false RH and all-order claims, Boolean
alias, duplicate JSON, removal of the random-cluster 2^k weight, corruption of
an original edge during cloning, source drift, and an unsealed changed proof.
The producer changes are detected by the competing physical reconstruction,
not merely by changed hashes. No acceptance condition uses Python assert.

Nine regular files and eight SHA256 entries are authenticated. The manifest
binds bytes, not theorem truth. The --emit operation is explicitly a producer
mode and does not authenticate the packet.

## Execution and delivery limits

Ordinary and optimized accepting commands reconstruct the same result JSON.
The test parts record refusals through the actual copied CLI. The separate
handoff receipt records executed commands, stdout hashes and return codes.
A clean ZIP extraction and a minimal add-only Git patch application are also
replayed. The latter preserves an unrelated sentinel and compares every file;
it is NOT a full repository checkout, integration validation, Lean/Comparator
build, remote CI run, Windows execution or independent referee acceptance.

An initial formal jet fixture landed at an excluded zero-radical boundary and
was rejected. It was replaced by an interior rational point (t=1/3) before
freezing output. No source theorem or actual theta certificate changed. The
failed initial producer run is not counted as successful execution.

No new connected 4104-spin parameter is numerically certified. CT1's exact
existence is based on the parent's authenticated strict margins and a written
uniform implicit-function proof. No eighth- or higher-moment match or all-order
feasibility computation is claimed. The limits in CT3--CT5 are not proved by
these finite tests. The full Li--Radziwill mollifier argument was not re-audited;
its theorem statement and scope were read. PDF page-image attempts for that
reference failed, as recorded in SOURCES.json.
