# Execution and proof boundaries

The analytic manuscript is proposed mathematics requiring independent review.
The finite checker does not prove its infinite asymptotic or the missing native
upper estimate. The following describes the authoring Linux/Python execution.

## Exact controls

The accepting implementation uses standard-library integers, Fractions and a
small Gaussian-rational class. There is no binary64, numerical quadrature,
zeta-value evaluator or supplied zero list. The complete gamma integrals in the
controls concern finite exponential sums specified inside the checker.

Six groups, 1,109 finite panels:
- 30 exact strip-shape identities on a rational gamma/delta grid.
- 900 ordered pair comparisons, including the strict equality classification.
- 52 whole finite-exponential energy/log-derivative panels. A direct pair-power
  formula is compared with recursive exponential differentiation and explicit
  polynomial gamma integration. All cross terms and infinite time are retained.
- 65 orders of both the real and nonreal closed forms, plus the rational base
  budget that supports the paper's all-n synthetic growth argument.
- 17 multiplicity splitting/regrouping controls.
- 45 complete finite-section error comparisons for declared finite rate sets.

The two calculations have the same author and use the same rational backend.
They do not constitute independent mathematical acceptance. The 900 elementary
geometry panels are not 900 independent theorem checks. No native energy has
been evaluated, no physical derivative mesh is being certified, and no new
native high-order moment or zero computation is claimed.

Commands:

    python -I -S -B check.py --check result.json
    python -I -S -B -O check.py --check result.json

Both ordinary and optimized executions reconstruct the same exact JSON. The
--emit mode reconstructs mathematics but does not authenticate the inventory;
it must not be substituted for --check in a delivery receipt.

## Integrity and changed-copy tests

Eight regular files/seven manifest entries authenticate. Strict JSON rejects
duplicate keys, floating numeric tokens, nonfinite numeric tokens and Boolean
aliases under canonical typed comparison. Source identity is bound to the
frozen predecessor commit. Hashes authenticate bytes, not mathematical truth.

An external harness accepts a pristine copied packet and runs SEVEN actual
changed-copy CLI rejections per mode: resealed false RH flag; resealed Boolean
alias; resealed duplicate JSON; resealed removal of conjugation in the pair
formula; resealed wrong normalization in that formula; source-commit drift;
and an unsealed manuscript alteration. Mathematical mutations fail an exact
identity after fresh reconstruction, not merely a checksum. The harness and
logs are delivery extras, not code imported by the accepting program.

## Delivery checks

An isolated minimal Git repository applies the add-only patch while retaining
an unrelated sentinel. Every new file is compared byte-for-byte, and both
accepting modes are rerun. A separately extracted ZIP also runs both modes.
These are packet tests, not a complete repository checkout or remote CI.
The prior 24,692-byte principal manuscript was authenticated to Git blob
f2053068565ab28f673eb537ed4cdb6b6ec9d8fa and read; none of its numerical programs
or earlier Ising/theta certificates was rerun.

No full repository validation, Lean/kernel proof, Windows run, native spectral
computation, external theorem reproving, independent referee, or cofinal native
descent is claimed. Publication is recorded separately only after the actual
remote ref and complete added subtree have been read back.
