## Arithmetic and coverage contract

`check.py` is standard-library Python. No floating-point number, zeta/zero oracle,
numerical eigenvalue routine or quadrature enters acceptance. Strict JSON refuses
float and nonfinite literals and duplicate keys; canonical JSON comparison keeps
Boolean/integer types distinct. Acceptance uses explicit errors, never `assert`.

The new interval helper stores integer endpoints in units 2^-160. Addition is
exact. Multiplication takes all four products and rounds out. Division first
excludes zero, reverses reciprocal endpoints, then rounds out. Rational inputs
are enclosed by integer floor/ceiling and reject inexact types. Natural logs
are reconstructed using n=2^k r, 1<=r<2, and

```
log r = 2sum_(j=0)^79 z^(2j+1)/(2j+1) + remainder,
z=(r-1)/(r+1),
0 <= remainder <= 2 z^161/[161(1-z^2)].
```

The same formula at z=1/3 supplies log2. The complete remainder is retained.
Only A-prime log values, the next prime, and a fixed few checks are evaluated.
Large B-prime arrays are used in exact rational products, not log quadrature.

Scope:

  (1900 primes). This bounded source prefix covers all selected first crossings.
- Seven finite, fully enumerated graph panels: 79 vertex instances and 127 edge
  instances. Edges generated by prime-coordinate additions are independently
  compared with all integer pair ratios. Rates here are explicitly FORMAL
  positive rationals, not ordinary logarithms.
- Twenty-eight exact global variance identities; seven exact root-Green trial
  quotients; seven rational compressed lower matrices with 65 nonnegative LDL

  checks, not the all-scale min-max proof.
- Six ACTUAL log-prime trials, y=2,3,5,7,11,13, first-crossing P=5,31,191,1013,
  3847,14549. Every A subset is used (maximum 63 nonconstant modes). Each B
