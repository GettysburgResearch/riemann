# Common-parent random-key realization for the factor-67 child budget

## Abstract

This note proves a simultaneous source-ownership theorem for the factor-67 causal coefficients. The weighted children can be carved from one literal parent by one auxiliary uniform random key whenever they are submeasures in the same unnormalized source coordinate. The total child density is below `1/sqrt(67)<1/8`, leaving more than seven eighths of the parent pointwise.

Two interfaces are then separated exactly: normalize only after source partition, and replace expectation-only rounding by integral Hall-flow quantization. The note does not claim that the repository's full native producer already satisfies those interfaces, and does not claim RH.

## Theorem

The complete proof is `L-99100`; its factor-67 specialization is

\[
 s_kP+\sum_j\lambda_j(P-r_jC_j)
 =P-\sum_j\alpha_jC_j,
\]

\[
 \sum_j\alpha_j<\frac1{\sqrt{67}}<\frac18.
\]

If `C_j<=P`, the cumulative child density is below `1/8`. On `Omega x [0,1]`, cumulative density intervals give disjoint child owners and an explicit residual.

## Application protocol

1. Freeze one unnormalized labelled native source.
2. Prove every weighted child is a submeasure there.
3. Apply the one-key partition.
4. Normalize target/row/score data after partition via `L-99101`.
5. If a finite row is needed, decompose the fractional Hall flow into integral feasible leaves via `L-99102`.
6. Verify any non-network score or endpoint constraints on every leaf.

## Boundary

The remaining application theorem is the exact native source-to-integral-leaf identification described in `M-99100`. It is not supplied by the abstract partition theorem.
