# An explicit bound for the least prime ideal in the Chebotarev density theorem

Jesse Thorner, Asif Zaman. arXiv:1604.01750v2, 2016-08-17. Journal issue date 2017-07-12, Algebra &amp; Number Theory

Theorem 3.2 gives \(\sum_{\chi\bmod H}N(\sigma,T,\chi)\ll\{e^{O(n_K)}D_K^2QT^{n_K+2}\}^{81(1-\sigma)}\) for \(1/2\le\sigma<1\), \(T\ge\max\{n_K^{5/6}D_K^{-4/(3n_K)}Q^{-4/(9n_K)},1\}\), with 73.5 replacing 81 for \(1-10^{-3}\le\sigma<1\). The Chebotarev application uses this family density theorem with the separate repulsion estimate and an abelian subgroup meeting the target conjugacy class.

Level 0. Density theorem and main Chebotarev setup inspected, proofs outside scope. PDF pp. 1–45 available privately.

Source locator Theorems 1.1, 3.2–3.3.
