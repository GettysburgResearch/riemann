# An explicit log-free zero density estimate for the Riemann zeta-function

Chiara Bellotti. arXiv:2405.12545v2, 2024-05-25. Journal issue date 2025-04, Journal of Number Theory

Theorem 1.1 gives \(N(\sigma,T)\le C T^{B(1-\sigma)}\) with height and real-part parameters specified in Table 2. A single explicit instance has \(B=1.448,\ C=1.62\times10^{11}\), \(3\times10^{12}<T\le\exp(6.7\times10^{12})\) and \(0.9927\le\sigma\le1\). The finite upper height is essential for interpreting this log-free estimate.
