## Exact quantifiers and the counted object

The exact Lean declarations are retained in [Challenge.lean](../../sources/latest62_density_frontier/palomar_Challenge.lean) and [Solution.lean](../../sources/latest62_density_frontier/palomar_Solution.lean). The proof source is the latter. The challenge imports only Mathlib and intentionally contains specification holes. The solution independently defines the matching notions and imports Mathlib, CurveBoundaryAudit and MiddleLargeValues. Comparator's configuration lists both definition and theorem names, with permitted axioms propext, Classical.choice and Quot.sound.

`GuthMaynardStatement.global_uniform (ε : ℝ) (hε : 0 < ε)` has conclusion `∃ C : ℝ, 0 < C ∧ ∀ σ T : ℝ, 1/2 ≤ σ → σ ≤ 1 → 2 ≤ T → actualZeroBound σ T (C*T^((39/17)*(1-σ)+ε))`. Thus \(\sigma,T\) are real, every \(T\ge2\) is covered, and a single \(C\) works for all allowed \(\sigma,T\) at each fixed positive \(\varepsilon\). There is no RH hypothesis or additional dependence on a family of \(L\)-functions. The result gives exactly
\[
N_{\pm}(\sigma,T)\ll_\varepsilon T^{(39/17)(1-\sigma)+\varepsilon},
\quad 1/2\le\sigma\le1,\ T\ge2.
\]
It implies the same bound for the usual positive-ordinate convention by subset inclusion. The theorem gives an epsilon loss and an existential implied constant. It supplies neither a numerical constant nor a quantified logarithmic loss, and it does not justify substituting a chosen \(\varepsilon(T)\) while ignoring the dependence of \(C_\varepsilon\).

The solution's definition `actualZeroBound` explicitly requires a finite set \(Z\) whose members are exactly the \(\rho\) satisfying `riemannZeta ρ = 0 ∧ 0 < ρ.re ∧ ρ.re < 1 ∧ σ ≤ ρ.re ∧ |ρ.im| ≤ T`. The bound applies to the sum of `analyticOrderNatAt riemannZeta ρ` over this set. Thus it counts the analytic multiplicity of actual Mathlib zeta zeros. The cutoffs include real-part equality and both height endpoints and ordinate signs. The usual open critical strip excludes edge zeros by definition. At \(\sigma=1\) the specified count is zero by definition, so the theorem alone does not prove absence of zeros on \(\Re s=1\).

The bridge `actualZeroBound_of_count` uses `MathCollab.Density.zetaZeroFinset σ (-T) T` and `mem_zetaDensityFinset`. The count implementation in [ZetaCounting.lean](../../sources/latest62_density_frontier/palomar_semantic_audit/ZetaCounting.lean) proves finiteness by containment in a compact ball, proves the analytic order finite via the identity theorem anchored at a nonzero zeta value at 2, and proves positivity at each nontrivial zero. It then sums these natural orders. This rules out a hidden empty or ad hoc witness set and rules out counting distinct zeros without multiplicity.

## Separate curve and large-value declarations

`full_curve` has \(C_{\sigma,\varepsilon}\), because \(\sigma\) comes before the existential quantifier. Its coefficients are \(3/(2-\sigma)\), \(18/(7\sigma+3)\), \(9/4\), and \(3/(2\sigma)\) on the exact intervals \([1/2,9/13]\), \((9/13,5/7]\), \((5/7,3/4]\), and \((3/4,1]\). They multiply \(1-\sigma\) in the exponent. The right branch is strict at its lower boundary. The actual curve exponent equals \(9/16\) at \(3/4\), with right limit \(1/2\). Hence the finite-grid argument joining uniformly Lipschitz pieces cannot directly give a uniform constant for the exact curve across that join. `uniform_away_boundary` puts \(C_{\delta,\varepsilon}\) before \(\sigma,T\) for fixed \(\delta>0\) and the union \([1/2,3/4]\cup[3/4+\delta,1]\).

`middle_large_values` quantifies one \(C_\varepsilon\) before every real \(N,T,V,t_0\), coefficient family, and finite separated observation set. The domain is \(2\le N\), \(N^{6/5}\le T\le N^{5/3}\), \(V>0\), a translate \([t_0,t_0+T]\), and distinct sample spacing at least 1. The polynomial sums over \(\lfloor N\rfloor<n\le\lfloor2N\rfloor\) with \(|a_n|\le1\). Its phase \(t\log(n/N)\) differs from \(t\log n\) by a common phase. The bound is \(C_\varepsilon N^\varepsilon(N^2/V^2+N^{18/7}T^{6/7}/V^4)\). This is a bounded-coefficient polynomial theorem with an explicit middle range, independent of any extra zero hypothesis.

The global proof wrapper calls `GuthMaynard.Improvement.global_density_uniform` in [GlobalDensity.lean](../../sources/latest62_density_frontier/palomar_semantic_audit/GlobalDensity.lean). It discharges the premise of `global_density_uniform_of_ingham` using the actual formal `ingham_lower_density` in NativeIngham.lean. The branch proof in [GlobalDensityIngham.lean](../../sources/latest62_density_frontier/palomar_semantic_audit/GlobalDensityIngham.lean) uses that Ingham input through \(9/13\), short density through \(5/7\), upper density through \(3/4\), and the older formal density-hypothesis coefficient 2 strictly above \(3/4\). ShortDensityUniform.lean then puts one constant before \(\sigma,T\) via monotonicity and an epsilon-budget finite grid. The exact stronger right branch is a different imported proof from NativeDensity.lean. The inspected endpoint wrapper does not leave a conditional Ingham premise, margin premise or large-value premise in its type.

The comparison \(30/13-39/17=3/221\) is between uniform density coefficients. It does not say that every pointwise exponent is improved. For example the registered curve gives \(9/16\) at \(3/4\), where Guth–Maynard gives \(5/9\). It also does not establish a nontrivial zero-free half-plane: the upper bound can remain larger than one for unbounded heights.
