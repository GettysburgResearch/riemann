# Antecedents of the derivative-weighted prime-phase CLT

The strongest match in this search is a combination of three antecedents. Heap–Li–Zhao supply the discrete shifted and twisted prefix formula from which the repository derives the required uniform derivative twist. Fazzari had already obtained a Gaussian moment calculation for a real prime sum with the same harmonic-prime centering under a continuous \(|\zeta|^2\) weight. Çiçek had already done a real prime-polynomial moment calculation at actual zeros sampled by counting. Bui–Gonek–Milinovich also write the exact derivative-squared prefix character sum used here, then evaluate a particular weighted combination of those characters. The project’s CLT is a method-of-moments corollary of its refined character estimate. This bounded search did not identify an explicit prior statement with the simultaneous derivative-squared sampling, growing cutoff and strict-tail weight. Publication priority remains unresolved.

## Statement being compared

For RH zeros \(\rho=1/2+i\gamma\), sample with probability proportional to \(|\zeta'(\rho)|^2/(1/4+\gamma^2)\) on the strict two-sided tail \(|\gamma|>Y\). For any fixed \(D>0\), use \(P=(\log Y)^D\), \(W_P=\sum_{p\leq P}p^{-1/2}\cos(\gamma\log p)\), \(H_P=\sum_{p\leq P}1/p\) and \(V_P=\tfrac12\sum_{p\leq P}(1/p-1/p^2)\). The real statistic \((W_P-H_P)/\sqrt{V_P}\) tends to the standard normal with all fixed moments. In this range \(H_P=\log\log\log Y+O_D(1)\) and \(V_P\sim H_P/2\). This is a Gaussian theorem for the scalar prime sum on that sampling measure. Its arithmetic input is the refined uniform HLZ character estimate, with range and saving available at each fixed moment order. ## What a prefix or dyadic antecedent would imply

For a rational character \(q\), let \(A_q(t)=\sum_{0<\gamma\le t}a_\gamma e^{i\gamma\log q}\) with \(a_\gamma=|\zeta'(\rho)|^2\), and put \(K(t)=(1/4+t^2)^{-1}\). For an inclusive prefix, the strictly-lower-endpoint tail with both signs is
\[
2\Re\!\left[-K(Y)A_q(Y)-\int_Y^\infty K'(t)A_q(t)\,dt\right].
\]
The term at infinity vanishes because \(|A_q(t)|\leq A_1(t)\ll t\log^4t\). If \(A_{m/n}=c_{m,n}A_1+E_{m,n}\), where \(c_{m,n}=\gcd(m,n)/\sqrt{mn}\), and uniformly for all \(t\ge Y\), \(m,n\le(\log Y)^{D'}\),
\[
|E_{m,n}(t)|\ll_{D',B}t\log^4t
\left[c_{m,n}\frac{\log(mn/\gcd(m,n)^2)}{\log t}
+\frac{(\log t)^{-B}}{\sqrt{mn}}\right],
\]
then endpoint subtraction and integration give the same normalized error form at \(Y\). This uses \(\int_Y^\infty t^{-2}(\log t)^A dt\ll_A Y^{-1}(\log Y)^A\), the main tail mass \(\asymp Y^{-1}\log^4Y\), and \(m,n\le(\log t)^{D'}\) throughout the integral. Choosing \(D'\ge Dj\) at fixed order \(j\), expanding \(W_P^j\) with nonnegative coefficients and choosing \(B\) after \(j\) gives the needed moments. Thus a prior prefix theorem at this strength would be a substantive antecedent even if it omitted the explicit tail statement. The repository's audited prefix estimate has this strength after real symmetrization.

Conversely, for a fixed relative window \(Y<\gamma\le cY\) with \(c>1\), a uniform prefix relative estimate gives the same character estimate for the unweighted window by subtraction, since \(A_1(cY)-A_1(Y)\asymp_c Y\log^4Y\). A theorem giving only the distribution for unweighted dyadic \([T,2T]\) blocks does not itself supply this prefix remainder or permit insertion of \(K(\gamma)\) inside the blocks. \(K(\gamma)\) varies by an asymptotic factor of four across a dyadic block. To use dyadic distribution theorems alone, one needs uniform localization within each contributing block or an estimate for the weighted blocks themselves, plus a summable tail bound. Fixed-polynomial convergence without uniform constants also gives insufficient information because a moment of degree \(j\) samples every word up to \(P^j\). An absolute \(O(1/\log Y)\) error per character, summed against the absolute coefficients, can cost \(O_j(P^{j/2}/\log Y)\) before normalization. It cannot prove convergence for all fixed \(D,j\) by this argument.
