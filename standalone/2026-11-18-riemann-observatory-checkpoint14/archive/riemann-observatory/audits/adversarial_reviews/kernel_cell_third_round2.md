## Fourier kernel and derivative bounds

The source window is

f(x)=1_[−1/2,1/2](x)[1+∑_(n=1)^6 a_n cos(2πnx)],
a=(193305,−23105,29166,13952,−21009,41052)/10^6.

Exactly ∑|a_n|=321589/10^6<1, so f≥0, and ∫f=1 by integer cosine orthogonality. Its real even Fourier transform is

K(t)=sinc(t)+(1/2)∑a_n[sinc(t−n)+sinc(t+n)],
sinc(t)=sin(πt)/(πt), sinc(0)=1.

At noninteger t this equals sin(πt)r(t)/π with

r(t)=1/t+∑a_n(−1)^n t/(t²−n²).

The factor and sign match the code exactly; no missing1/2 remains after combining the two shifted sinc denominators. Differentiation gives

K'(t)=cos(πt)r(t)+(sin(πt)/π)r'(t),
r'(t)=−1/t²−∑a_n(−1)^n(t²+n²)/(t²−n²)².

The code's `rr` and `dd` are these exact rational quantities. Compact support of f permits differentiation under the integral at every real t, including integer removable singularities. Positivity and mass1 give |K'|≤π and |K''|≤π². The discontinuity of f at support endpoints does not affect differentiation in the Fourier variable.

The Machin enclosure uses100 terms of atan(1/5) and40 of atan(1/239), with the next alternating term giving an exact rational enclosure. The identity π=16atan(1/5)−4atan(1/239) is justified by tangent addition: tan(4atan(1/5))=120/119 and subtracting atan(1/239) gives tangent1 in the first quadrant. Thus the difference isπ/4. Outward rounding at10^(−55) preserves the bounds.

For j=0,…,H/2−1 the reduced rational argument b=(2j+1)/(2H) is in(0,1/2). The code asserts π_U b<π_L/2, so all argument bounds remain inside the true sine-increasing/cosine-decreasing interval(0,π/2). Eighteen Taylor terms end with a negative term and give a lower bound; nineteen end positive and give an upper bound. Tail magnitudes decrease from well before either truncation. The first two cosine term magnitudes need not decrease, but this does not affect the alternating tail bound; the code's comment correctly acknowledges this.

The sine lower bound is divided by π_U and the upper by π_L, in the correct directions. Cosine bounds need no division. All four are outward rounded to denominator2^100. `up(x)=floor(Qx)/Q+1/Q` is conservative even if x happens to lie exactly on the grid.

## Modulo/reflection signs and poles

For k=qH+j, midpoint t=q+(j+1/2)/H. Both sine and cosine acquire the same sign(−1)^q. That shared sign can be dropped when bounding |K| and |K'|. When j≥H/2, reflection j↦H−1−j preserves positive sine and reverses cosine; the code correctly changes `(cl,cu)` to `(−cu,−cl)`. The exact rational r and r' still use the full global t, so only the trigonometric factor is reduced periodically.

Every midpoint is(2k+1)/(2H), hence is neither0 nor any integer. None of the rational denominators vanishes, including in cells adjacent to0 or n=1,…,6. Close denominators can amplify interval width but cannot invalidate exact Fraction arithmetic. Integer points inside or at cell endpoints are handled by the globally analytic Fourier K, not by substituting a pole into the rational representation.

The derivative interval uses interval products separately for r cos and r' sin/π. It loses correlation but is an enclosure. Taking max absolute endpoints therefore bounds the magnitude of K' at the midpoint even when cancellation is substantial.

## Whole-cell step and quantization

Let h=1/(2H), midpoint t_k. The code obtains A≤|K(t_k)| and D≥|K'(t_k)|. For all y in the cell, the global second derivative bound gives

|K'(y)|≤D+π²h,

while the global first derivative bound gives |K'(y)|≤π. Thus `local=min(π_U,D+π_U²h)` is still a valid whole-cell upper bound. Then

|K(y)|≥max(0,A−h·local)=:ell.

The code uses A=|r(t_k)|sin_lower; sine_lower encloses |sin(πt_k)|/π from below. The mean-value argument therefore covers the entire closed cell. Squaring is valid because ell≥0. Finally, if `floor(V ell²)≥c_k`, then

c_k/V≤floor(V ell²)/V≤ell²≤K(y)².

The code compares in precisely this direction. No floating-point value enters any inequality; timers use floating point only for elapsed display. Binary unpacking is explicitly little-endian and the exact file length4(R+1) is checked.
