This rounds downward from 13,926.4 and enlarges the covered domain. The cutoff is 262,143. On or beyond that total span, the positive span margins below pay all rewards and the absolute sum of each gap potential's worst negative knot. Positive or zero pair weights make the kernel terms nonnegative. Within the retained span, each gap or pair upper endpoint is capped by the total budget after reserving other gaps' lower endpoints. Restriction to these feasible distances is valid because the discarded span has already passed. The stack bisects closed intervals at an integer midpoint, covering the real interval including the common endpoint.

Each binary entry bounds the squared kernel on a closed cell. For a nondegenerate integer-grid pair range ([a,b]), cells (a,ldots,b-1) cover the full range. A singleton uses cell (a). The source computes range minima over these cells. Piecewise-linear potentials are minimized at endpoints and interior knots, and the zero outer knots agree with the zero extension. The affine kernel test chooses the lower intercept by bounding the trial slope at the adverse endpoint of each cell. A potential minus its trial affine bound is minimized at an endpoint or knot. These lower bounds remain valid after summing nonnegative pair weights and then minimizing the affine expression over the rectangle. ## Exact retry and checkpoint design

Both workers in the second unmodified attempt were interrupted by another execution environment outage. At recovery they were zombies with wait status 9 and empty stdout. The second window reached 50,000,000 boxes and the third reached 100,000,000 boxes. These remain interrupted executions. [Second attempt 2](../experiments/results/839_reference_second_attempt2.json) · [Third attempt 2](../experiments/results/839_reference_third_attempt2.json)

The separately staged verifier uses the exact pinned input/parser and mathematical search transitions. Its added hooks save the pending boxes and counters at the top of the original traversal loop, before popping the next box, once per million processed boxes. Saving therefore occurs after all effects of one node are complete and before any effects of the next. Let the retained state be the stack size, the ordered prefix of the stack array at that size, and the five statistics. The model's current box is rebuilt from that stack on the next pop. The basic bound writes its arrays relevant to a later affine test and resets the per-box base value. The affine test builds its own bounds whenever it runs. These per-box scratch values need no carry across nodes. The certificate and kernel table are reloaded from identical input bytes.

By induction on the next processed node, a faithful restored state has the same next box and transition as the uninterrupted loop. Acceptance removes one node and adds one leaf. A split removes one node and adds two boxes in the original array order. The pending-count invariant at each saved boundary is (1+mathrm{nodes}-2mathrm{leaves}). The parser checks it, the partition of leaf counters, stack bounds, the interval coordinates, the format and the run identity. When the stack empties the verifier persists the final state before emitting success. A crash after that final save can recover the same result. None of these hooks changes the checked domain or acceptance predicates.

The checkpoint file uses a synced temporary file, atomic replacement and a directory sync. The supervisor lock is also held by live workers. The run identity includes the staged and upstream source hashes, parameter and input hashes, compiler identification and flags. These checks reject accidentally mixed jobs and incomplete files. The checkpoint is trusted locally generated traversal state. Shape checks and an identity label alone cannot certify the prefix of an arbitrary externally supplied checkpoint. The staged runs and the unmodified author runs have separate result files and scopes.
