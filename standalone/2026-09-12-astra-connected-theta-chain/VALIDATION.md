Status: proposed mathematical component proofs, not independent acceptance.
The mathematical producer/checker and the changed-copy tests are standard-
library Python. No assert statement implements numerical acceptance.

## Native numerical reconstruction

The accepting command reconstructs all of the following rather than merely
checking hashes of a saved result:

- The complete theta normalization and moments2,4,6: 84 degree80 cells at
  192-bit outward dyadics, four analytic time tails, and every omitted index.
- The field-calibration constant: composite Simpson intervals of512 and4096
  subintervals, complete fourth-derivative errors and the infinite tail.
  Euler's constant, pi, and the entire sum from32 of log(n)/n^2 have explicit
  complete remainders.
- Every tail weight from32 through16384 (16,353 indices), the forward formal
  majorant, and the reversed endpoint response. The entire infinite variance,
  fourth-cumulant and sixth-cumulant tails remain in the accepting comparisons.
- Two strict fourth-moment endpoint signs on their true variance-root brackets,
  and sixteen covering parameter boxes proving the sixth-moment mismatch.
- Fourteen direct-enumeration small-chain panels, twelve joined-segment panels,
  five rational transfer-product panels, five exact integral-derivative panels,
  three all-future coefficient-induction panels, and two density constants.

The rational transfer panels use q=1/4 so that the positive transition square
root is rational. The direct-spin panels and actual infinite chain use q=1/5.
No rational panel is misidentified as an actual theta spectrum calculation.

The interval class and theta Taylor integration are adapted from #863. This
is not a second independent transcendental implementation. Its earlier code
blob was authenticated and inspected, but its full producer and numerical
campaign were not replayed. No stored parent moment is a numerical input to
this checker. The new theta target is independently reconstructed from the
same formula and adapted primitive method.

The delivery runs the two complete accepting commands in README.md, normally
and optimized, with byte-identical mathematical output. The two rejection
partitions run in each mode. Each partition includes a pristine complete
reconstruction before attempting changed copies.

There are eleven intended refusals per mode: duplicate JSON, floating and
Boolean numeric aliases, false RH header, changed unsealed proof, extra file,
symlinked proof, resealed parent-source drift, a resealed change of the actual
chain rate in the primitive recurrence, a resealed change from4 to5 in the
defining theta coefficient, and a changed saved numerical endpoint. The
primitive-rate mutation is caught by independent direct spin enumeration,
not just by a hash. Hash/inventory/format refusals have their separate scope.
Linux symlink tests are performed; no Windows run is claimed.

Exact execution output and external archive/patch receipts accompany the ZIP.
A clean archive extraction and a minimal temporary-Git add-only patch roundtrip
reproduce every file and replay both accepting mathematical modes. The patch
roundtrip preserves an unrelated sentinel and the supplied predecessor
manuscripts. Neither fixture is a complete repository checkout or build.

## Preliminary failures retained in the record

The initial bisection stopped on an interval-overlapping midpoint too early,
so its resulting fourth-moment enclosure was not strict. It was repaired by
quarter-point refinement, retaining both strict bracket signs. A single coarse
parameter rectangle then failed to enclose the variance curve sharply enough;
sixteen subintervals cover the SAME entire lambda interval and prove the
needed signs. Neither failed run is counted as a successful theorem check.
The final root-existence argument uses only the successful strict inequalities.

Non-directed scouts selected the construction and brackets; they are not proof
evidence. Some simpler-tail and few-head fits failed. An unreliable short
correlation-sum scout near correlation one was discarded. No impossibility
claim follows from those exploratory searches.

## Analytic and publication limitations

The code does not machine-prove the infinite limit, the Perron-product
comparison, the Riemann-sum asymptotics, the Lee--Yang theorem or Hurwitz.
Those are the complete proposed paper arguments in PROOF.md. No zero
location, high-rank Ising enumeration, numerical large-field growth curve,
full repository validation, Lean/Comparator build, remote CI result,
independent referee identity or external novelty determination is claimed.

The current GitHub connection was used to read the exact parent. In the
available tool set no create/push action was exposed; plugin discovery
confirmed GitHub is already installed. The local container could not resolve
GitHub and had no gh executable or GitHub auth environment. The delivery is
therefore an add-only ZIP/patch handoff, not a claimed remote commit or PR.
