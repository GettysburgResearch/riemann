# Validation contract and limits

The executable is a bounded exact-algebra companion to PROOF.md. It is not a machine proof of SPL1 or SPL2 and does not replay the imported six-gap continuum search or analytic number theory.

## Reconstruction

```
python -I -S -B check.py --check result.json
python -I -S -B -O check.py --check result.json
```

All mathematical acceptance uses standard-library integers and `Fraction`. Pi is enclosed by complete alternating arctangent series in Machin's identity. H_MT is enclosed directly using cos(1/sqrt(2)) and sin(1/sqrt(2))/(1/sqrt(2)), both rational alternating series in 1/2. The square root in the older 280-block constant uses integer-square-root enclosures. Decimal output bounds are rounded outward by integer floor/ceiling.

The receipt records 49 triangle-convolution cases; 88,480 seven-window incidence cases; 21,846 complete rational matching configurations (including empty, repeated and exact-threshold points); 90 synthetic rank-stability matrices; 15 synthetic pinching matrices; 73 adapter-constant cases; and 1,029 multiplicity-accounting cases. Counts describe bounded fixtures, not theorem counts. The all-size matching proof and analytic majorant are written separately.

No actual large kernel Gram or actual zero is evaluated by the accepting code. Small exploratory floating-point eigenvalue tests were used only as a sanity check of the proposed inequality, and are not part of acceptance. They compared five selected configurations of 240–300 points. They supply no theorem or precision certificate.

## Tests and actual refusals

```
python -I -S -B test_check.py
python -I -S -B -O test_check.py --optimized
```

Five methods cover full reconstruction, exact threshold cases, longer independent scalar-series bounds, typed parsing, and copied-package CLI tests. Each successful suite executes one pristine acceptance and ten actual refusals: a false new constant, incorrect pair price, negative majorant minimum, false RH flag, wrong Fourier support, Boolean/integer alias, duplicate JSON key, unsealed proof drift, undeclared file, and a resealed producer whose separation constant was changed. Numerical changes are resealed before checking, so their refusal is not merely a stale checksum.

The same arithmetic backend is used in normal and optimized modes. Repeated execution is not independent mathematical review. No assertion statement implements the acceptance contract. Hash authentication assumes a trusted manifest; replacing the entire checker and trusted manifest maliciously is not claimed detectable by that same checker.
