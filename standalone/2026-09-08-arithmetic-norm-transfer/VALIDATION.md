# Validation and trust boundaries

The mathematical claims are paper proofs, except for the bounded exact controls
and the complete variation-profile constant enclosure explicitly identified
below. No finite test count certifies RH, an unbounded native estimate, or an
external theorem.

## Executed work

The final sealed verify.py --check result.json passes in ordinary and optimized
isolated Python with byte-identical mathematical output. It reconstructs seven
named groups, 728 bounded panels:

- 512 sieve values compared against independent trial factorization;
- 48 exact three-constraint algebra panels;
- 27 finite higher-jet variations and their complete coefficient norms;
- seven full prime-log graph identities, compared between edge and matrix
  reconstructions, with maximum graph integer 256;
- 31 exact physical interval lower bounds for Y=2,...,32;
- 99 independent rational continuum floor-integral comparisons;
- four rational exponent and constant identities.

Separately, all 4095 rational integral cells through T=4096 are summed for the
EXPLICIT VARIATION profile. The complete tail is bounded by 10000/(3T^3), giving
C_* in [1.704219450036,1.704219498544]. Cells are coverage units, not additional
independent analytic theorem counts. The large exact rational sum is recorded
by a hexadecimal-integer SHA256 fingerprint, avoiding decimal conversion limits.

Nine deliberately corrupted packets reject through the actual CLI in each
interpreter mode. The two partitions each include a pristine copied control.
Resealed semantic mutations cover false RH and power-saving claims, Boolean
aliases, a wrong profile interval, duplicate JSON, source-parent drift, and a
changed multiplier in the producer. Altered proof bytes and an extra inventory
file are also rejected. Integrity rejection alone does not assess altered
mathematics; the producer mutation exercises exact reconstruction.

All nine regular files and all eight SHA256 entries authenticate. Acceptance
uses explicit checks, not assert. No floats, gamma/digamma, numerical zeta,
zero oracle or quadrature enters verify.py. The directed displayed enclosure
is formed by integer rounding of exact Fraction endpoints. No arithmetic core
or research code is imported from another packet.

A clean ZIP extraction and a temporary-Git add-only patch application both
reproduce the new bytes and replay both verifier modes. The latter preserves
an unrelated sentinel. This is not a full repository checkout, remote CI,
Windows execution, Lean/library build or independent mathematical review.

## What was and was not read or imported

SOURCES.json records exact manuscript heads and the scoped direct reads.
Locally available parent manuscript bytes were compared with their known Git
blob identities. Those are source-byte checks, not fresh producer replay.
The complete original numerical campaigns of the parent or other agents were
NOT rerun. The source metadata manifest is not a transitive source audit.

Lee--Leong's classical unconditional Mertens bound and the standard zeta
convexity consequence are imported analytic theorems. Their published numerical
constants, code and zero-verification campaigns are NOT rerun. The new norm
upper bound uses existence of constants only. No numerical value of the
all-Y residual upper bound, new native minimum, or native sign range is computed.

The asymptotic arguments (partial summation, dominated convergence and the
logarithmic-scale limit) are not consequences of the finite tests. They require
independent mathematical review. There is no external novelty claim.
