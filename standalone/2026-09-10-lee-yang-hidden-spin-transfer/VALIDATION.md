# Validation and mathematical scope

This packet supplies proposed PAPER proofs, not independent acceptance or a
formal proof. Its seven files form a standalone add-only research directory.
The checker uses Python integers and exact fractions only. It does not evaluate
actual theta integrals, zeta, gamma, a limiting spin law, or a complex spectrum.

## Finite controls

- Twenty hidden-pressure panels retain every hidden configuration.
- Fifteen complete direct-spin versus hidden-summed partition comparisons
  enumerate 2,016 configuration instances in total; maximal graph has nine
  spins. Repeated configurations in different models are not distinct theorems.
- Twenty-five entropy contrast panels retain exact target degrees, all scalar
  terms and permitted magnetization levels. Their N can be large algebraically;
  their enormous many-spin systems are NOT enumerated.
- One connected four-spin graph is fully enumerated (16 configurations), with
  the exact rational de-binomialized contrast reported in result.json.
- Thirty-nine finite entropy-remainder panels, twenty-four product-factor
  panels, an exact Laurent-derivative reconstruction and elementary rational
  source constants check the formulas. They do not prove their infinite domains.

Normal and optimized isolated Python reconstruct identical JSON. Acceptance
checks the exact inventory, six SHA-256 entries, strict JSON, source-head lock
and complete reconstructed result, without assert-based acceptance.

The self-test creates fresh copied packets. In each Python mode a pristine
control accepts, and SEVEN actual altered copies reject: false realization
status, Boolean schema alias, duplicate key, wrong rational result, resealed
producer change of the witness exponent, an unsealed altered proof, and an
extra file. The producer change is rejected by the independent fixed witness
identity, not solely by a hash. This is not a comprehensive code-security audit.

Commands:

```
python -I -S -B check.py --check result.json
python -I -S -B -O check.py --check result.json
python -I -S -B check.py --self-test
python -I -S -B -O check.py --self-test
```

`--emit` is unauthenticated producer mode and is not an acceptance command.
The exact execution outputs and return codes are retained in the external
delivery receipt, rather than adding generated files to the sealed directory.

## Dependencies and omissions

The complete parent proof is locally authenticated to its remote Git blob and
SHA-256 named in SOURCES.json. No parent executable, earlier moment certificate,
full repository validator, Lean/Comparator, Windows test or remote CI ran.
The classical Lee--Yang theorem is an explicit import. Its general product
consequence, the explicit quartic graph lift, whole-tail passage, weak-limit
compactness and theta derivative contradiction remain paper arguments for
referees. Finite controls do not establish the requested source realization.

The three-level finite obstruction requires UNIFORM visible-to-hidden couplings
and uniform visible pair couplings. The four-spin witness shows this hypothesis
cannot be dropped. The weak-closure exclusion is for the particular densities
exp(-a*x^4-b*x^2) M_B(x), not all Griffiths--Simon measures or all pair graphs.

An initial local document-writing helper had a Python quotation SyntaxError;
acceptance commands on its incomplete inventory correctly refused. Those are
not successful validation runs. The corrected complete packet was sealed and
all retained commands below were rerun successfully. No mathematical repair
was required for that staging failure.

During blob transfer, a single leading prose space differed from the first
local manuscript. The final local file was reconciled before commitment, then
the manifest, normal/optimized checks and delivery roundtrips were rerun. This
was a whitespace-only change with no mathematical effect.

## Delivery checks

The new directory is applied as an add-only patch in an isolated minimal Git
fixture with an unrelated sentinel, compared byte-for-byte and replayed in both
Python modes. A clean ZIP extraction is checked separately. These are packet
checks, not a full authenticated riemann checkout. Remote publication, when
successful, is recorded with a read-back SHA and complete subtree comparison
in the external delivery receipt. No asynchronous execution is promised.
