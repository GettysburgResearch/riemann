## Authentication and rejection contract

The checker requires an exact nonempty eleven-entry checksum list and an exact
flat twelve-file inventory. Symlinks, directories, missing or extra paths, and
duplicate manifest entries reject. The proof, source-lock, reused interval core,
and new certificate have literal SHA-256 pins in the checker. Producer modules
are compiled directly from authenticated bytes, without using bytecode caches.
No arbitrary repository code or predecessor producer is executed.

The actual CLI mutations are: empty manifest, duplicate JSON key, float alias,
false RH status, boolean degree alias, narrowed coverage, resealed changed energy
endpoint, changed/rehashed interval core, changed/rehashed source lock, extra
path, and symlink. A resealed energy mutation must reach and fail the full
primitive reconstruction rather than only fail a checksum. Acceptance uses
explicit exceptions, not removable Python asserts. A person able to edit and
reseal the checker itself is outside this local authentication contract; the
published Git identities bind the delivered checker.
