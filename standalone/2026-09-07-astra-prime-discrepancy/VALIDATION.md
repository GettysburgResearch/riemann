# Validation and computation boundaries

## Executed finite checks

Environment: Python 3.13.5, standard library only; Git 2.47.3, Linux.

The standard-library checker performs nine groups / 636 bounded cases:

- 511 integer primality comparisons (sieve versus independent trial division);
- 64 binomial prime-divisibility controls;
- 9 rational majorant constants;
- 11 actual finite prime-square physical norm calculations (cutoffs through 97);
- 5 prime-base tail endpoint controls;
- 24 signed atomic full-state identities;
- 5 formal-logarithmic continuous/mixed source normalization identities;
- 2 exact first-prime X=2 checks;
- 5 elementary controls for the continuous synthetic lower-bound argument.

These are not 636 mathematical theorems. Most cases only authenticate the finite
prime input. The rational Fourier identities exactly eliminate logarithms from
those particular norms. No non-directed floating point is called interval data.

Both normal Python and Python -O recompute the complete result. Their retained
JSON files are byte-identical. The checker uses explicit exceptions, not assert.
JSON canonical-type comparison rejects a float alias for an integer count;
duplicate keys and changed signs/constants are also rejected.

The rejection script executes four altered-result and three altered-package
cases through the real command-line checkers, plus two pristine controls, in
EACH mode. It does not claim semantic proof verification or resistance to an
attacker changing both the checker and every external trust anchor.

## Source and file authentication

SOURCES.json records the exact Git commit, blob, SHA-256, length and role of two
parent manuscripts. The uploaded copies were read and their blob IDs agree with
the frozen published records. The optional --repo-root validator authenticates
those exact available parent bytes. It is not a full repository checkout.
Parent mathematical checkers and historical numerical campaigns were NOT rerun.

SHA256SUMS authenticates fourteen members of the exact fifteen-file packet.
The manifest excludes itself. Missing/extra files, changed bytes and symlinks
are rejected. A distribution receipt outside this inventory records the actual
publication status, so a prepared packet is not confused with a remote push.

## Analytic arguments and unperformed work

The infinite higher-power convergence, PNT-dependent tail asymptotic, full
frequency estimates, and conditional RH deductions are PAPER PROOFS. They are
not machine-proved by these finite controls. Ordinary PNT is used only where
marked; the stronger prime-error bound is explicitly conditional on RH.

No actual entropy integral, full signed prime-discrepancy energy, high-ordinate
xi values, or zero census was computed. No large asymptotic campaign, Lean,
Comparator, remote CI, Windows run, exhaustive novelty audit, or independent
mathematical acceptance is claimed.

The add-only patch is checked by application and byte comparison in a temporary
Git fixture, not by running the full repository. The final archive is validated
after extraction and the mathematical checker is rerun there in both modes.
The original source files, main and other research branches are unchanged.

## Execution interruption

One oversized combined shell invocation reached its execution timeout after
printing both rejection-run summaries. That combined command is not recorded
as a successful complete run. The result comparisons, both package validations,
and each full rejection run were then executed separately and completed.
