# Original research snapshots

These directories preserve original manuscripts, source locks, author programs and execution histories. Their bytes and original status headers are not rewritten when a later review qualifies a result. A copied source directory is not blanket mathematical or executable acceptance.

For the current statement, required hypotheses and proof route, use the [cumulative statement guide](../research/integrated/CURRENT_RESULTS.md) and the [native-source proof library](../research/integrated/native_sources/SOURCE_INDEX.md). The latter maps the selected snapshots to their current interpretation, including six explicit repairs. [Selected evidence contracts](../research/integrated/native_sources/EVIDENCE.md) identify which numerical statements and accepting programs were reviewed; unselected programs remain archival.

The [candidate source manifest](../integration/2026-09-08/SOURCE_TREES.json) pins exact source commits and directory trees. Later changes on a research branch need separate delta review. Earlier standalone packets retain their prior recorded scope; the new candidate does not re-review or strengthen them.
