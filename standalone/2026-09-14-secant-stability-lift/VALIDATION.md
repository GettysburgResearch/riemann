# What the finite certificate does and does not prove

The accompanying `validation.json` records executed normal and optimized
commands, actual exit codes, durations, output and code/data SHA256 hashes.
Both final accepting reconstructions pass with identical stdout. The semantic
digest is

    d8895a597ad387011d815465590d750fa8bf595b3cb8596a455eb5622dfc9268

The certificate is a short exact arithmetic computation, not a new replay of
the inherited six-gap continuum search. No accepted row uses floating point,
a numerical eigenvalue routine, sampled zeta zeros or an unquantified tail.

## Arithmetic

H0 is evaluated as 3/2-cos(x)/sinc(x), x^2=1/2. The alternating series have
rational terms and decreasing magnitudes. Adjacent48/49-term partial sums
bound both functions, with a positive denominator. Independent longer56/57
partial-sum bounds must be nested. This is an alternative truncation check,
not an independent transcendental backend or separate author's computation.

Square roots use integer square roots at200-bit binary scale. Every resulting
interval is checked by squaring both rational endpoints. Fractional-linear
outputs are bounded by evaluating all interval corners with positive
denominators. The printed30-place decimals are widened using integer floor
and ceiling; decimals are not assumed exact inputs to transcendental functions.

The spectral predicates compare a radical inequality by squaring only after
checking the sign of the nonradical side. Thus these controls do not pass an
uncertified approximate eigenvalue to an acceptance test.

## Acceptance and adversarial checks

The CLI accepts `--check result.json` only after rebuilding the entire expected
body. It checks the submitted digest and then compares canonical TYPED JSON
bytes, preventing Boolean/integer and integral-float aliases. Duplicate keys,
noninteger number syntax, nonfinite syntax and symlink report paths are
rejected by the parser. Ten changed and resealed reports are passed through
the same acceptance function in every self-test; all are rejected. A separate
duplicate-key parser test is also rejected. These are in-process tests, not
11 complete fresh subprocess reconstructions.

`--write NEW_PATH` is producer-only and refuses an existing output. Acceptance
never overwrites the canonical receipt. No removable Python assert controls
acceptance. The external delivery manifest binds the source bytes but cannot
make a malicious simultaneous replacement of a checker and its manifest
self-authenticating. Immutable publication identities and review are separate.

## Development and limits

Ordinary exploratory scalar arithmetic nominated m322; every published
comparison was then rebuilt with exact intervals. Some initial unconstrained
seven-gap numerical scouting was abandoned and is NOT evidence for a stronger
pressure theorem. No sampled pressure minimum enters the final result.
A final wording change restricted the mixture claim explicitly to fixed
FINITE convex mixtures; the receipt was regenerated before final validation.
It changed the semantic scope string, not any bound or optimizer.

This is one implementation with alternative scalar checks, by the same author
as the proof. Normal/optimized agreement is not independent mathematical
acceptance. No P7 continuum search, original Arb tables, Gabor data, large
matrix campaign, external formalization/axiom build, complete repository
validator, historical parent executable or remote CI was run. The primary
analytic source was inspected only to the depths stated in SOURCES.md.

Any fresh ZIP or addition-only patch application is recorded in the external
delivery receipt. A local fixture preserving unrelated files is not a complete
GitHub checkout. No theorem gains accepted status through packaging.
