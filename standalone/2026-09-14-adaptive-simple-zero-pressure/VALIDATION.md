## Completed in this session

Both standard-library isolated Python modes reconstruct the same complete
results.json. All SIX unittest methods pass normally and under -O, with
zero failures, errors, or skips. Each mode includes one pristine command-line
acceptance and TEN actual altered-receipt refusals, each after a complete
fresh reconstruction. Refusals cover false RH/replay claims, type aliases,
a changed lower bound, the wrong span factor, reduced coverage, false status,
and duplicate JSON keys. No assertion implements the accepting checker.

All accepting arithmetic is integer/Fraction arithmetic. Square roots use
integer square-root enclosures; trigonometric constants use alternating
rational Taylor series with complete next-term bounds. The outward decimal
brackets are independently checked against their underlying rational bounds.
No floating-point optimizer, special-function evaluator, or zero list enters
acceptance. Earlier mpmath evaluations merely suggested numerical targets;
they are not part of the proof or accepting data.

Bounded coverage consists of 6,560 small gap lists, 24 long profiles with the
native pressure constants, 451 outer-size/offset controls, 969 rational
four-point spectra and their 2,907 pinching controls, and 441 scalar panels.
These are finite examples of the general lemmas, not native zeta Gram
computations and not independent proofs of the all-size assertions. The
same implementation runs in both modes; this is not a second referee.

The first-crossing implementation is compared against direct recomputation
from spans on every small list and on shorter prefixes of the long profiles.
The latter include zero gaps, very large gaps, nonmonotone pressure, no
crossing, multiple crossings, and incomplete or empty final blocks. Outer
averaging checks retain all offset-specific point losses and gap charges.
