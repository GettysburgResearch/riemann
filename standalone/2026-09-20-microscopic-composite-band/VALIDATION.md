used 1 instead of delta(8)=0 in the divisor residual. A baseline fixture inserted
Python ints where Fraction coefficients were required and thus accidentally
introduced floating division. Both fixtures were corrected. The default accepting
source already used Fraction and the correct divisor identity. These fixes did
not change the proposed theorem or conceal a failed native inequality.

new arithmetic excerpt. It was removed before publication, and the complete
report and receipt were regenerated; this changed the backend hash, not any
mathematical values. The failed packaging attempt is not counted as a patch
application or archive replay.
