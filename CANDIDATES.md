# Counterexample Candidates

There are currently **no `Z-####` candidates**.

A negative ordinary floating-point or mpmath value is not sufficient for entry
in this registry.  For the active finite-Weil route, a candidate must include:

1. exact `c`, `N`, basis convention, and nonzero rational or dyadic vector;
2. independently generated interval enclosures for the cutoff-free matrix;
3. an exact verifier result proving the Rayleigh interval has upper endpoint
   strictly below zero;
4. a complete audit of the finite Guinand--Weil implication;
5. reproduction by an independent implementation.
