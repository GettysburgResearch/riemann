## Evidence hierarchy

The integration uses the following evidence in descending order:

1. an exact frozen SHA independently recorded in a review report;
2. a direct GitHub read of the present head;
3. checked-in artifacts authenticated by durable hashes and replay;
4. reconstructed metadata, including commit timestamps;
5. PR prose or workflow intent.

A lower level cannot silently replace a higher one. In particular, the snapshot script's “latest commit timestamp before cutoff” is a reconstruction, not proof of the historical PR head. The exact reviewed SHAs in the nine review reports are the authority for the 126 verdicts.

This pass integrates repository architecture and review-backed metadata rather than indiscriminately merging source branches:

- the complete exact-SHA review matrix and its `29 / 55 / 39 / 3` aggregate;
- one advisory disposition for every cutoff PR;
- a claim-level synthesis that separates finite, conditional, proposed, empirical, blocked, refuted, and superseded material;

- a lightweight standard-library consistency checker.

No source PR is merged or closed by this branch. No reviewed theorem is broadened. No expensive computation is rerun.

## What was deliberately not integrated

- unreviewed current-head mathematics;
- invalid or incomplete proof objects, including #200's serialized interval and #211's incomplete archive;
- source-dependent carrier/RH implications blocked by D-0001;
- workflow triggers without result artifacts;
- cofinal conclusions inferred from finite ladders;
- a universal claim registry generated by copying every colliding branch ID.

Those objects remain visible in the ledger with explicit next actions.

## Updating this state

Do not rewrite the cutoff evidence in place. A later pass should create a new timestamped directory, import this ledger, refresh present heads directly, classify each delta, and append new aliases or provenance records. Historical review verdicts and source SHAs remain fixed historical facts even when a later repair is accepted.
