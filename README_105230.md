# T-105230 — companion-corona continuation

Checkpoint three on PR #731 removes the arbitrary interpolation polynomial
from T-105222.

For one derivative level put

```text
G_(k,delta) = F_(k+1) + i delta F_k
```

and use the fixed meromorphic field

```text
S = F_(k+1)/F_k
  + 2 lambda F_(k-1)/F_k
  + lambda^2 F_(k-1)^2/[F_k G_(k,delta)].
```

At every simple real zero of `F_k`, its residue is exactly
`(1+lambda rho)^2`.  The only replacement poles are zeros of the canonical
Hermite--Biehler companion `G`.  In the lower half-plane their global count is
exactly the number of nonreal conjugate pairs of `F_k`.

Thus interpolation degree and node-coalescence blowup are replaced by a
source-owned companion-pole charge.  The remaining theorem is a one-sided
boundary-plus-pole-amplitude estimate.  90%, density one, and RH remain open.
