## Conservative identity-census boundary

The census inspected 233 S and 237 G frozen text/JSON/Python files selected
by their exact base-to-head diffs plus named old source-front notes, together
with exact commit messages. Literal forty-hex tokens were filtered by actual
Git object type; blob hashes, tree objects, missing identities and mock test
values were not promoted to source commits. Explicit manifest source lists,
the exact heads, and planned QR were included.

This produced 195 actual commit identities: 134 retained by current S/G
ancestry, 45 additionally by the existing archive set, five additionally
by planned QR ancestry, and eleven outside those sets. Working-front text
was also inspected but added no identity absent from frozen evidence.
The resident replay reconstructs the same 195-identity set using frozen
inputs only; it does not depend on the later state of those working files.

The JSON preserves the exact identity set and witness locations. This is
a deliberately conservative, declared-input census, not a general static
analyzer and not a guarantee that every shortened SHA, dynamically computed
path, arbitrary executable import, external paper, or later-added dependency
has been found. The eight maxima are minimal for this declared uncovered
commit set, not a universal optimal archive design.

## Read-only resident replay

The helper performs no filesystem or Git-ref writes, fetch, or push.

    python -B research/exploratory/sixhour_source_acquisition_review.py --replay-manifests
    python -B -O research/exploratory/sixhour_source_acquisition_review.py --replay-manifests

Optional --check-remote verifies all thirty-two old targets and reports how
many proposed new targets are now advertised correctly. Missing proposed
refs remain planning status, not a successful publication claim. Optional
--verify-descendant FINAL_TIP REQUIRED_SHA can be repeated for accepted
final QR/JR sources and reviews. That local ancestry check is still not a
fresh network-fetch test.

The artifact/payload seals authenticate this resident evidence at its
frozen review commit. Replay of this acquisition helper is not a substitute
for the scientific packets' own producers or independent proof reviews.
