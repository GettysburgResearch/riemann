# Isolated retune with two expanded count windows

**Status:** The isolated Lean dependency closure has compiled, the candidate and Riemann-zeta corollary report only the standard axioms, and `leanchecker --fresh` replayed `Candidate.Main` successfully. Tracker admission and the semantic/source audit remain outstanding. It uses the same count and physical sources and the same `1/250` floor-budget change as [the prior candidate](../2026-10-29-arvi-return/README.md). The active prior candidate and build were not modified.

Set `theta=4369347/5000000 = 0.8738694`, `h=80599/100000 = 0.80599`, and physical numerator cap `619/10000`. The geometry checker verifies the existing parameter and non-row schedule conditions with the smaller floor reserve. The proposed result would be only `8·10^(−7)` below the prior `0.8738702` candidate.

The original 31 windows do **not** certify these parameters. At `delta=81161/200000`, `p=437499999/1000000000`, and distance `d=h`, only `old` and `capP` are admitted by the original windows. With **zero** row-margin reserve the cleared margins are negative: approximately `−0.0008901775` and `−4.8040·10^(−9)`, respectively. This is an obstruction to that fixed-window certificate, not a lower bound on possible zero-free regions or on other analytic sources.

Two changes to the count-window scheme make this numerical test feasible:

* Replace the old weakC7 window 9 by `397/1000 ≤ delta ≤ 27/64`, `43/100 ≤ p ≤ 1/2`.
* Add a capC window `39/100 ≤ delta ≤ 3971/10000`, `43/100 ≤ p ≤ 1/2`.

The windows overlap, avoiding a cover gap. The exact Bernstein checker verifies all fifteen admission guards are strictly positive throughout each new box. The full-domain rational row checker retains the original branches and windows except these modifications and uses the strict reserve `theta−10^(−8)`. It covers all four physical/old capacity edges; the last edge uses 66 rational Bernstein boxes, with old, capP, C, weakC7 and capC branches. These independent tests check an exact arithmetic transcription. The altered windows, admission proofs, return envelope and row proofs have since been generated and compiled in the isolated candidate; the original PR94 `Windows.lean` admits only the old windows.

## Reproduce

Python 3 and SymPy are required. Each row or admission checker insists that the original `Windows.lean` has SHA-256 `3d436434bf8a76f2246f12bb942840f33e4d8ce3d2155660e4572dccab15a799`; each script also parses the 31 original entries and checks their order and values against its transcription. With the pinned PR94 source locally available, run:

```sh
python research/exploratory/2026-10-29-return-retune-8738694/check_geometry.py
python research/exploratory/2026-10-29-return-retune-8738694/check_admissions.py --windows /path/to/Return/Windows.lean
python research/exploratory/2026-10-29-return-retune-8738694/check_rows.py --windows /path/to/Return/Windows.lean
```

The admissions script prints exact coefficient minima and asserts they are nonnegative; the observed minima are positive. The row script checks all branch guards and the row-margin polynomial via exact rational Bernstein coefficients on its chosen subdivision, and terminates with four edge summaries. An independent source-level review checked its formulas and coverage against Lean, including the two changed windows.

The pristine source is PR94 head `e5a82f72d8ff39a3cc1ad044e6acd727e77a3fc4`. Its `Formulas.lean`, `Constants.lean`, and `CountWindow.lean` hashes are respectively `e7dfed2c335372dde5a609ec2b53bf268d6fe7c40807bdb7ee83c5d7f3f3216b`, `96f2a770b68bc4d3ba34e896995514c040315dbc8584e19dbfe479dced8ce4b7`, and `21fb4e2c88be82e3f14cbdc3eec69f55650f42cc188d6c314cc78e80c3f1ebe3`. These are provenance, not assertions that every Lean source dependency has been replayed. `Constants.lean` fixes `reserve=1/100000000`; the successful test retains that exact reserve. The `1/10000000000` in `dp=h+1/10000000000` is a distinct geometric slack, also retained.

It can be regenerated by passing `--certificate research/exploratory/2026-10-29-return-retune-8738694/edge-certificates.json` to `check_rows.py`. `check_original_failure.py`, with the same `--windows` argument, independently checks the stated fixed-window witness and its exact signed margins.
