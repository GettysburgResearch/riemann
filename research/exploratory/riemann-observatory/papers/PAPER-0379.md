**Main result (as stated in index content).** Assuming mu(n) behaves like random +-1 signs for squarefree n, derives (heuristically) the Riemann hypothesis via the sum of mu(n).

**Research potential (curator).** Instructive heuristic; compare with Mertens-bound failure and random multiplicative function models.

**Expert seed note (['F']; unverified recollection).** Heuristic: if μ(n) on squarefree n behaved like independent fair ±1 coin flips, then M(x)=O(x^{1/2+ε}) with probability one, i.e. RH holds 'almost surely'.
