**Main result (as stated in index content).** Any non-vanishing analytic function in a disc of radius <1/4 about 3/4 can be uniformly approximated by shifts zeta(3/4+it).

**Techniques.** universality; Kronecker-type approximation

**Expert seed note (['B']; unverified recollection).** Proves that for 0 < r < 1/4, every function f continuous and non-vanishing on |s| <= r and analytic inside can be approximated uniformly to any epsilon > 0 by zeta(s + 3/4 + i tau) for suitable real tau.

**Expert seed note (['F']; unverified recollection).** For 0<r<1/4, any non-vanishing continuous f on |s|≤r analytic inside, and ε>0, there are (a positive lower density of) T with max_{|s|≤r}|ζ(s+3/4+iT)−f(s)|<ε.
