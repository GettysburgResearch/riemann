**Main result (as stated in index content).** Ihara zeta of PGL_2(Q_p) lattices is rational via determinant formula.

**Techniques.** graph zeta

**Expert seed note (['D']; unverified recollection).** Defines the Ihara zeta function for torsion-free cocompact lattices in PGL_2(Q_p) and proves its rationality via a determinant formula. In graph form (Serre, Sunada) this reads ζ(u)^{−1} = (1 − u²)^{r−1} det(I − Au + q u² I) for (q+1)-regular graphs, and the graph RH holds iff the graph is Ramanujan.

**Expert seed note (['E']; unverified recollection).** Defines a Selberg-type zeta function for torsion-free cocompact Γ⊂PGL_2(Q_p), i.e. for (q+1)-regular graphs. Proves it is rational, Z(u)^{-1}=(1−u^2)^{(q−1)n/2} det(I−Au+qu^2 I), so its RH (nontrivial poles on |u|=q^{-1/2}) is equivalent to the graph being Ramanujan.
