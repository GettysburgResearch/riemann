**Main result (as stated in index content).** For fixed d>=3 and eps>0, random d-regular graphs have all nontrivial eigenvalues <=2 sqrt(d-1)+eps with probability 1-o(1).

**Expert seed note (['E']; unverified recollection).** For fixed d ≥ 3 and ε > 0, a random d-regular graph on n vertices has all nontrivial eigenvalues bounded by 2√(d−1)+ε with probability 1−o(1) as n → ∞. This is 'almost RH' for the Ihara zeta function of random graphs.
