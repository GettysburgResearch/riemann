**Research potential (curator).** Foundation for the de Bruijn-Newman constant Lambda>=0 and Rodgers-Tao.

**Expert seed note (['A']; unverified recollection).** Shows the heat-deformed H_lambda(z) = int e^{lambda u^2} Phi(u) cos(zu) du has only real zeros for lambda >= 1/2, so the de Bruijn-Newman constant satisfies Lambda <= 1/2.

**Expert seed note (['B']; unverified recollection).** For H_t(z) = integral e^{tu^2} Phi(u) cos(zu) du, proves that if H_{t0} has only real zeros then so does H_t for all t >= t0, and that H_t has only real zeros for t >= 1/2 (Lambda <= 1/2 in later notation).
