**Main result (as stated in index content).** Frobenius eigenvalues on H^i_et of smooth projective variety over F_q have absolute value q^{i/2}.

**Techniques.** etale cohomology; Weil conjectures

**Expert seed note (['D']; unverified recollection).** Proves that the Frobenius eigenvalues on H^i_et of a smooth projective variety over F_q have absolute value q^{i/2}. This is RH for function fields realized as a spectral statement via the Grothendieck–Lefschetz trace formula.

**Expert seed note (['E']; unverified recollection).** Proves RH for smooth projective varieties X/F_q: Frobenius eigenvalues on H^i(X_{F̄_q},Q_l) have absolute value q^{i/2}. The proof uses Lefschetz pencils, Kazhdan-Margulis monodromy and a Rankin-style tensor-power trick. Corollary: the Ramanujan-Petersson conjecture, e.g. |τ(p)| ≤ 2p^{11/2}.
