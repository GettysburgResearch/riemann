**Main result (as stated in index content).** Using computed zeros in Ingham-type inequalities, shows L(x)>0 for some x (near 1.845x10^361), disproving Polya's conjecture (zbMATH review and seed notes).

**Techniques.** Ingham argument; zero computation

**Research potential (curator).** Template for refuting sign conjectures.

**Expert seed note (['C']; unverified recollection).** Using the first zeta zeros in an Ingham-type argument, proves L(x)>0 for some x (non-constructively, near 1.845×10^{361}), disproving Pólya's conjecture.

**Expert seed note (['F']; unverified recollection).** Using computed zeta zeros, proves L(x)=Σ_{n≤x}λ(n) is positive for some x (disproving Pólya's conjecture) and that Σ_{n≤x}λ(n)/n is negative for some x (disproving Turán's hypothesis), without explicit x.
