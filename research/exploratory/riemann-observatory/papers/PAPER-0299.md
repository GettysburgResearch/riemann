**Main result (as stated in index content).** Old and new conjectures and results about a class of Dirichlet series (Amalfi 1989); defines Selberg class and conjectures on primitive functions and GRH.

**Techniques.** Selberg class

**Research potential (curator).** Core framework for generalized GRH.

**Expert seed note (['B']; unverified recollection).** Defines the Selberg class and states the orthonormality conjectures. Formulates a CLT for log F(1/2+it) for primitive F and a result on zeros of linear combinations of L-functions.

**Expert seed note (['E']; unverified recollection).** Defines the Selberg class S: Dirichlet series with the Ramanujan hypothesis, meromorphic continuation, a functional equation with Γ(λs+μ) factors, and an Euler product. Conjectures (A) Σ_{p≤x}|a_p|^2/p = n_F log log x + O(1); (B) orthonormality of primitive elements; and RH for S.
