# Diagnostic replay

`catalan_audit_replay.py` is a non-directed, non-proof consistency check for
selected formulas in arXiv:2609.04176v1.

It requires SciPy. Its frozen output was generated with Python 3.13.5 and
SciPy 1.17.0.

The script does **not** certify the theorem. Read `../NUMERICAL_REPLAY.md` for
scope and limitations.
