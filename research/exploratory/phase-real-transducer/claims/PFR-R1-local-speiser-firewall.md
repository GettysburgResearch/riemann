# PFR-R1 — An off-axis quartet need not create a nonreal derivative critical point

Status: **PROVED EXACT COUNTERMODEL / FIREWALL**

For `a>b>0`, put

\[
Q_{a,b}(z)=((z-a)^2+b^2)((z+a)^2+b^2).
\]

Its four zeros `+/-a +/- ib` are nonreal, but

\[
Q'_{a,b}(z)=4z(z^2-a^2+b^2)
\]

has the three real zeros

\[
0,\quad +/-\sqrt{a^2-b^2}.
\]

Hence there is no generic local assignment

```text
off-axis symmetric zero quartet -> nonreal derivative branch point.
```

Speiser's theorem must use global zeta structure rather than only local
quartet or flower geometry.
