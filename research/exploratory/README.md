# Exploratory research

Exploration is intentionally free-form.

A contribution may be a speculative reformulation, synthetic countermodel, numerical reconnaissance, literature connection, failed proof, or unconventional attack. It does not need the full machine provenance schema or an integrated-packet format.

Please state at least:

```text
Status: PROPOSED / EMPIRICAL / SYNTHETIC / IMPORTED / REFUTED / ...
Scope: finite / local / conditional / cofinal / global
Exact sources or dependencies:
What was actually run:
Smallest remaining gap:
```

Keep discovery and proof boundaries visible:

- ordinary numerical output is not a directed certificate;
- a workflow marker is not a result;
- a finite positive ladder is not a global theorem;
- a fitted model may nominate a witness but should not enter the final certificate;
- a new theorem or repair should receive a new identity and review.

When a result becomes stable and important, request exact-SHA review. After review, a future integrator may extract it into `research/integrated/` while preserving the exploratory source.
