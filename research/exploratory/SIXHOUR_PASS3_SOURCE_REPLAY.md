shallow clone. The wildcard is restricted to this repository's source-archive
namespace; none of the existing archive refs should be moved or deleted.

scientific heads recorded by the replay panels when verifying a historical

## Scientific replay

Each programme includes `sixhour_pass3_replay_panel.json`,
`sixhour_pass3_replay.py`, and normal/optimized result reports. The panel
explicitly locks each test module and producer by normalized-LF SHA256.
The runner uses a new process for every test module and producer check and
checks those hashes again afterwards.

Use the system Python for exact/SymPy packets and the independently pinned
python-flint environment for actual-Xi ball certificates. The FLINT runtime
is CPython 3.12.10, python-flint 0.9.0 / FLINT 3.6.0, with the package-native
44-file aggregate
`36c07323af58dec0eb6fd82a99bf871924eb69f1833d9af626fc09437ae5b0cc`.
The packet producers themselves authenticate their declared runtime.

Pass `--repo`, `--panel`, `--system-python` and, for Structures,
`--flint-python` to the runner; repeat with `--optimized`.
The 35-test source-closure workflow suite is separate from science totals.
A green replay is not a replacement for the exact-SHA mathematical reviews.

No PR or main-branch merge, force-push, archive deletion, new zero census,
RH/GRH claim or external-priority claim is implied by this release.
