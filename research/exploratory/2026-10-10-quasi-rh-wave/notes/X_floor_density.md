## 0. Verdict in one paragraph

The premise of note U sec. 4(b) is half wrong, and the half that is right is worth exactly 0. The count "R(delta) = 1 for
delta <= 1/3" is the sextic-sieve *envelope* (9.16) (line 4068); for every bin above the floor, 1/50 < delta <= 5/6, the
paper replaces it by the witness count R* of Prop. 19.2/(20.8) (line 11781: "For 1/50 < delta < alpha, use ... R = R* +
Delta/4"), and R* is already a zero-density estimate for the family with slope dR*/d delta = -0.68 (x = 0) to -0.81
(x = 1/2) at the floor edge (Sec. 1.4). A Selberg/Montgomery density from DIPP's mollified second moment (mollifier length
U^{1/11}) plus the paper's own sextic large sieve (Lemma 9.1) gives N_U(1/2 + delta/2, T) << U^{1 - delta/11 + eps} T^A
(Sec. 1.2-1.3): c = theta = 1/11 per unit delta, seven to nine times weaker than what the paper already proves, and it
does not cover the sextic or eta-twisted rows (Sec. 1.3). Fed into the bookkeeping as min(R*, 1 - theta*delta) it changes
nothing: B = 0.874957, active class (delta, x) = (0.386, 1/2), for theta = 1/11, 1/2, and even for the density hypothesis
restricted to delta <= 0.3 (Sec. 2). The only count that moves B is the density hypothesis at *all* classes (13/15 =
0.866667), i.e. at the binding class delta = 0.389, which is not near the floor. Note N's floor ceiling +0.0012
(Z-exponent, 0.0003 in B) also needs ideal counts at the far classes, not at the floor; with any near-floor improvement
alone it is 0.0000. The floor bin itself (rows with no zero above a0 + e) is not a zero-density object and no density
estimate counts it. Nothing here is a movement of the bound; it is not even a reparametrisation — it is a redundant input.

## 1. The statement, and its derivation

### 1.1 Family and rows (paper's definitions)

Rows: sixth-power-free primary u with q_u ≍ U = Z^d (line 4063), restricted to the ray class fixed by the detector. For
each row the finite set of presentations is X_u = {psi_{u,nu,sigma}(n) = nu(n) chi_n(u)^sigma : nu in Theta, sigma = ±1},
Theta = <eta, T_b> the finite group generated by the target eta and the fixed ray twists (lines 3380-3388). The bin of a
row (Lemma 8.1, lines 3419-3425): with T1 = Z^tau <= U^{1/100} and a grid step e < 10^-3,
    M_j(u) = max({51/100} ∪ {Re rho : L(rho, psi*) = 0, psi in X_u, Re rho >= 51/100, |Im rho| <= 3 j T1}),
a = the grid point with a <= M_i(u) < a + e, delta = 2a - 1. The floor bin a = 51/100 (delta0 = 1/50) is the set of rows
with M_i(u) < 51/100 + e, i.e. **no presentation has a zero with Re >= 51/100 + e and |Im| <= 3 i T1**; it is counted
trivially, "#B << U applies; it agrees with R(1/50) = 1" (line 4077) and "uses no witness" (line 4571). Note the height:
T = 3 i T1 <= U^{1/100 + o(1)} with i = O(1/e); all counts carry (1 + T1)^{A_A} (line 4068).

Hence the object: for sigma in (1/2, 1], T >= 1,
    N_U(sigma, T) = #{u : q_u ≍ U, some psi in X_u has a zero rho with Re rho >= sigma, |Im rho| <= T},        (X.1)
and the row-count exponent R(delta) of a bin is bounded by the exponent of N_U(1/2 + delta/2, T) at T = U^{1/100+o(1)}.
Since |X_u| = 2|Theta| = O(1), it suffices to treat one presentation psi_u = nu chi_u^{±1} at a time.

### 1.2 Montgomery's argument with a mollifier of length U^theta (constant c = theta)

Fix psi_u = nu chi_u, a Hecke character of F = Q(sqrt(-3)) of conductor norm Q_u << U (line 3392). Let X = U^theta,
M_u(s) = sum_{q_a <= X} mu(a) psi_u(a) q_a^{-s} (sum over primary generators of ideals coprime to S), Y = U^lambda with
lambda > theta, and a(n) = sum_{a | n, q_a <= X} mu(a), so a(1) = 1, a(n) = 0 for 1 < q_n <= X, |a(n)| <= tau(n).
Let rho = beta + i gamma be a zero of L(s, psi_u) with beta >= sigma > 1/2, |gamma| <= T. Mellin inversion gives
    (1/2 pi i) ∫_{(2)} L(rho + w, psi_u) M_u(rho + w) Gamma(w) Y^w dw = sum_n a(n) psi_u(n) q_n^{-rho} e^{-q_n/Y}.
Move the line to Re w = 1/2 - beta < 0. The pole at w = 0 contributes L(rho)M(rho) = 0. Hence
    e^{-1/Y} + sum_{X < q_n} a(n) psi_u(n) q_n^{-rho} e^{-q_n/Y}
        = (1/2 pi) ∫_R L(1/2 + i(gamma + v), psi_u) M_u(1/2 + i(gamma + v)) Gamma(1/2 - beta + iv) Y^{1/2 - beta} dv.   (X.2)
Truncating the n-sum at q_n <= Y log^2 U (error O(U^-1)), one of the two alternatives holds for the row:
  (A)  |D_u(rho)| >= 1/4, D_u(s) := sum_{X < q_n <= Y log^2 U} a(n) psi_u(n) q_n^{-s} e^{-q_n/Y};
  (B)  Y^{1/2 - sigma} ∫_{|v| <= log^2 U} |L M_u(1/2 + i(gamma + v), psi_u)| e^{-|v|} dv >= 1/4   (Stirling for Gamma).
Count (B): square it and apply Cauchy–Schwarz on the v-integral (weight e^{-|v|}, total mass 2), then sum over the
counted rows:  N_B <= 32 Y^{1 - 2 sigma} sum_u ∫_{|t| <= T + log^2 U} |L M_u(1/2 + it, psi_u)|^2 dt,
and with the mollified second moment  sum_u ∫_{|t| <= T'} |L M_u(1/2 + it)|^2 dt << U^{1 + eps} T'^{A}  (input (M))
    N_B << U^{1 - lambda(2 sigma - 1) + eps} T^{A'}.                                                             (X.3)
Count (A): split D_u dyadically, q_n ≍ N, X < N <= Y log^2 U (O(log U) pieces); by partial summation in q_n (the factor
q_n^{-(beta - sigma)} e^{-q_n/Y} is monotone, |.| <= 1) and Gallagher's lemma in the height (|D(sigma + i gamma)|^2 <<
log N ∫_{|t - gamma| <= 1} |D(sigma + it)|^2 dt + ..., D a Dirichlet polynomial of length N), with one zero rho_u chosen per
row,
    sum_u |D_{u,N}(rho_u)|^2 << (log U)^3 ∫_{|t| <= T + 1} sum_u |sum_{q_n ≍ N} a(n) q_n^{-sigma - it} psi_u(n)|^2 dt.
The inner sum over u is the sextic large sieve, Lemma 9.1 (line 3692), with coefficients c_n = a(n) q_n^{-sigma - it}
(fixed independently of the row, as the lemma requires; nu is absorbed into c_n):
    sum_u |...|^2 << (UN)^eps (U + N + (UN)^{2/3}) sum_{q_n ≍ N} |a(n)|^2 q_n^{-2 sigma} << U^eps (U + N + (UN)^{2/3}) N^{1 - 2 sigma}.
For N <= U^{1/2} the bracket is << U, and the worst dyadic piece is the shortest, N ≍ X:
    N_A << U^{1 + eps} T · X^{1 - 2 sigma} = U^{1 - theta(2 sigma - 1) + eps} T,   provided  Y log^2 U <= U^{1/2}.      (X.4)
Combining (X.3)-(X.4) with lambda = 1/2 (so (X.3), exponent 1 - delta/2, is dominated once theta <= lambda = 1/2):
    N_U(1/2 + delta/2, T) << U^{1 - theta delta + eps} T^{A},  i.e.  R_D(delta) = 1 - theta delta.                  (X.5)
The constant is c = theta per unit delta (2 theta per unit sigma - 1/2): the Montgomery/Selberg density inherits the
mollifier length and nothing else, because the family's large sieve is "square-root" only up to length U^{1/2}
(the (UN)^{2/3} term, sharp by DFDH 2026, note K). Even the ideal mollifier length theta = 1/2 would give R_D = 1 - delta/2.
Referee check of c: the only place theta enters is the shortest dyadic block N ≍ X of D_u in (X.4); a longer mollifier
removes the blocks X < N <= X' and lowers the exponent linearly; the (B)-term is slack by (lambda - theta)·delta.

### 1.3 DIPP's input, and how its family differs from the paper's

* Theorem (import): DIPP Theorem 10.5.2 is the twisted second moment  sum_a mu^2(a) L^S(1/2, psi_1 chi_a) L^S(1/2, psi_2
  chi_a) rho(a) W(|a|/X) (via the series (17), line 1904-1909: psi_1, psi_2, rho Hecke characters "of order dividing r,
  unramified outside S"), used for the mollification of Theorem C with mollifier length M = X^{theta_kappa - eps},
  theta_kappa = (1 - delta~_kappa)/(1 + (2r - 1)(1 - delta~_kappa)) (eq. (38), line 3335-3340); r = 3, kappa = 1: delta~_1
  = 5/6, theta_1 = 1/11. Unconditional: GRH is mentioned only as what *would* improve the error X^{5/6} to X^{3/4}
  (lines 104-112); Theorem C's proportion is stated as unconditional (line 182). The mollifier is a smoothed lambda_b, not
  an optimised truncated Möbius sum ("would considerably increase the technical complexity ... without ... new ideas",
  lines 186-190); a Möbius mollifier of the same length is what (X.2) needs — "routine" by their account, not done.
* Differences from the paper's family (each a real gap, none deep, none worth closing given Sec. 2):
  (i) order: DIPP need F ⊃ mu_{2r} (lines 34-35, 472-476, 1092-1096). The paper's rows are *sextic* symbols chi_•(u)
      over Q(sqrt(-3)) = Q(mu_6), which lacks mu_12; so only the cubic sub-family (r = 3 over Q(sqrt(-3))) is covered as
      stated. The sextic presentations (and all of X_u with sigma = ±1 of a sextic symbol) are outside the theorem.
  (ii) twist: DIPP's psi_1, psi_2 have order dividing r = 3; the paper's eta is any finite-order Hecke character
      (the target of the half-plane); the row presentations are nu chi_u with nu in Theta = <eta, T_b>.
  (iii) index set: DIPP sum over squarefree (kappa = 1) or cube-free (kappa = 0) ideals coprime to S with a ≡ 1 (mod c);
      the paper's rows are sixth-power-free primary elements in a fixed ray class, with the sextic sieve's "fixed
      restriction of the row set" allowed (line 3699) — compatible, but the main-term constants differ.
  (iv) height: DIPP evaluate at s = 1/2 (shifts s_1, s_2 in (17) allow small displacements); (X.3) needs the t-integral
      over |t| <= T = U^{1/100+o(1)}, a polynomial-in-T loss is harmless, but the uniformity in t of Theorem 10.5.2 is not
      stated. The paper itself proves its moments with (1 + T1)^{A} losses (line 4068), so this is the expected form.
  So the honest provable statement today is (X.5) with theta = 1/11 for the cubic-twist presentations of the family; the
  full X_u version needs the sextic second moment over Q(mu_6) (DIPP Remark 1.4.1 / 4.1.8: "certainly possible").

### 1.4 The decisive comparison: the paper's Prop. 19.2 is already the stronger density theorem

(20.8) (line 11670) gives, in closed form (note A), R*(delta, x) = 1 - delta + (alpha - delta) delta P_x / (2J), J =
(alpha - delta) D_x + delta P_x. At the floor edge (script, Sec. 1 of the log):
    x = 0:   R*(delta0+) = 0.98656,  dR*/d delta = -0.678   (small-delta law 1 - delta(1 - P_x/2D_x) = 1 - 2delta/3)
    x = 1/4: R*(delta0+) = 0.98521,  dR*/d delta = -0.743
    x = 1/2: R*(delta0+) = 0.98375,  dR*/d delta = -0.814   (law 1 - 0.811 delta)
versus (X.5): 1 - delta/11 (DIPP), 1 - delta/2 (ideal large-sieve mollifier), 1 - delta (density hypothesis). The paper's
own count is a zero-density estimate with c = 0.68-0.81, i.e. between the ideal-mollifier value 1/2 and the density
hypothesis 1 — because its "mollifier" is Lemma 17.1's marked inverse polynomial of length up to U^{1-c'} with prime
products (note K sec. 2), an upper-bound mollified moment far beyond the asymptotic literature's 1/11, combined with
Lemma 18.1's fourth mean value of length U^{1/2}. Table (log, Sec. 2): at every delta in [delta0, alpha], R* < 1 - delta/2
< 1 - delta/11; the two counts coincide only at delta = alpha (both 1/6). So min(R*, R_D) = R* identically, and the premise
"R(delta0+) = 1" of (U.4) with (9.16) is the envelope, not the count the proof uses: note N's bracket h(1 - R(delta0)) =
0.0132 already used R*(delta0, 1/2) = 0.98375. What stays at R = 1 is the floor bin itself: rows with no zero above
a0 + e in the height window, which under GRH for the family is *all* rows; no density estimate counts it.

## 3. What rigour inside the paper would require

* Nothing in the paper changes for this item: the clause "the floor bin a = 51/100 is excluded from the witness assertion"
  (line 4076) concerns rows *without* a zero above a0 + e, and the first bin a = 51/100 + e (delta = 1/50 + 2e) is already
  counted by Prop. 19.2 with R* < 1 (line 11781). A density theorem (X.5) would be inserted as a second upper bound in
  Prop. 9.2's envelope, R(delta) := min{R_(9.16), 1 - theta delta}, which is < 1 for delta < 1/3 — true but never used,
  since Section 20 takes R* there. Liu's parameters stay (b, ell) = (-4/29 + 230 sqrt 921/26709, (33 + 8 sqrt 921)/1653)
  = (0.123405, 0.166838), B_new = 0.874957069799 (liu lines 22-25, 165-168); his stationarity ∂_delta E(b, ell; delta_c,
  1/2) = 0 (line 190) is at delta_c = 0.389, untouched by any near-floor count.
* To state (X.5) as a theorem for the full row family one needs: (a) DIPP's Theorem 10.5.2 extended to the sextic symbol
  over Q(mu_6) (their mu_{2r} convenience hypothesis removed, Remark 1.4.1), to twists nu of arbitrary finite order
  unramified outside S (Theta), and to the height window |t| <= U^{1/100+o(1)} with polynomial loss; (b) a Möbius
  mollifier of length U^{1/11} in place of their lambda_b (they call this routine); (c) the sextic large sieve exactly as
  Lemma 9.1 (already in the paper, unconditional). All unconditional; GRH enters nowhere. The result would be R_D(delta) =
  1 - delta/11, a correct but redundant input. Alternatively the paper's own tools give the stronger (X.5)-type statement
  directly: Prop. 19.2 *is* "N_U(1/2 + delta/2, U^{1/100}) << U^{1 - (0.68..0.81) delta}" uniformly for 1/50 < delta <= 5/6,
  amplitude-resolved — a family zero-density theorem of density-hypothesis quality up to the factor 1 - P_x/(2D_x),
  which is new relative to the moment literature (note K) and is already proved there.

## 4. Honest verdict

* Provable now: (X.5) with theta = 1/11 for the cubic-twist presentations of the family, unconditionally, from DIPP
  Theorem 10.5.2 (with a Möbius mollifier and the t-aspect to be written out) plus Lemma 9.1 and the argument of Sec. 1.2;
  the sextic/eta-twisted version after removing DIPP's mu_{2r} convenience hypothesis. The constant c = theta is forced by
  the large sieve's U^{1/2} square-root range; c <= 1/2 for every mollifier-based route.
* Worth: 0.000000 in B (Sec. 2 table), 0.00000 in note N's floor ceiling. The 0.0003 quoted in note U sec. 4(b)/6 was the
  ideal-counts ceiling of note N (density hypothesis at *all* classes, i.e. at delta_c = 0.389); it was never attributable
  to a near-floor density, and a near-floor density of any strength (even 1 - delta for delta <= 0.3) realises 0 of it.
* Classification: not a movement of the bound, and not a reparametrisation inside the model — a redundant input. The
  paper's Prop. 19.2 already contains a stronger family zero-density theorem near the floor (c = 0.68-0.81 vs 1/11), a
  point this wave's notes N/U mis-stated when they wrote R(delta0+) = 1 "with (9.16)" (envelope) while computing with
  R*(delta0+) = 0.984 (count). The floor bin proper — rows with no zero above a0 + e — is the GRH-generic set and is not a
  zero-density object; the structural ceiling of note U (U.4) should be read with the proof's R*: f <= 1 - R*(delta0+) =
  0.0163, and it is still not the binding piece of (N.3). Correction to carry into FINDINGS sec. 6 item 1 and note U
  sec. 4(b): delete "provable, new, small, worth <= 0.0003"; replace by "already in Prop. 19.2 with a larger constant; worth 0".
