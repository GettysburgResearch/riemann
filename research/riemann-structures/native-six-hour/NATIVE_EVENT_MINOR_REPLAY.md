# Replay and composition of fixed-minor event panels

This is the separate event campaign registered in
NATIVE_EVENT_MINOR_PREREGISTRATION.md. Its target is permanent rank20
on the actual curvature/current variation; it is not full ambient64
tensor faithfulness. Its finite certificates do not require a successful
infinite-tail test.

The source is the fixed H900 minor and immutable local helper of
3ba479241acf9db1554af067d5e2bea85533dde5. Generic authentication,
canonical rational encoding and the complete supported-alias enumerator
are taken from the exact utility freeze
63e1742ec319c532baa36f6568809f6a6b32e6e2, code blob
bb69109f81bca6e814a87c82be86ac7b92934d27. The utility authenticates its
own source chain before use. No frozen constants or entry points are
changed.

Calibration reconstructs every selected source alias at900, including
the complete36-coordinate curvature and original1/g weight. All full
row sums and the twenty-by-twenty matrix must match the frozen exact
capture. Its retained exact inverse is checked on both sides. Thus the
base rank certificate does not depend on a favorable modular image.

Each subsequent job covers one prescribed dyadic interval and takes
only its immediately preceding VERIFIED frozen endpoint as a proof
input. Every alias event in the new interval is regenerated from its
source, including zero updates. All simultaneous row updates are
applied before a fresh modular elimination. Complete pivots, swaps,
multipliers, echelon matrix and determinant are retained. The primary
prime65521 is followed only by the declared1000003 fallback when
needed. Both modular states are always maintained. Actual denominators
are checked and their residues retained; each modulus has a complete
trial-division primality certificate.

A completed panel can contain UNKNOWN_MODULAR_RANK groups. The exact
closed integer intervals which remain certified are retained without
filling any gap. An interrupted or refused job is not a completed panel.

Root's serialized base commands are:

    python research/riemann-structures/native-six-hour/native_event_minor.py --phase calibration --write
    python research/riemann-structures/native-six-hour/native_event_minor.py --phase calibration --check

Run ordinary and optimized checks/tests before treating a component as
a verified source input. Freeze the base artifact with the four owned
campaign files before any target panel. No later owned-file change is
permitted inside this campaign.

The first panel command is:

    python research/riemann-structures/native-six-hour/native_event_minor.py --phase panel --upper-power 10 --predecessor-commit BASE_SHA --write

The check has the same arguments with --check. Freeze its accepted
complete artifact, then use its commit for power11, and continue
consecutively through at most48. A mathematical UNKNOWN can still be
an accepted, fully verified component, provided its incomplete coverage
is retained.

A final, possibly partial, composition uses:

    python research/riemann-structures/native-six-hour/native_event_minor.py --phase collection --chain-commits BASE_SHA PANEL10_SHA PANEL11_SHA --write

The ordered list must contain the base followed by consecutive panels.
The collector authenticates every immutable record and unchanged owned
files, verifies predecessor hashes and endpoint equality, reconstructs
the complete event-address census, checks grouped-horizon coverage and
recomputes the union of certified integer intervals.

It first authenticates and discards all component bytes before any
component is parsed. It then reauthenticates and parses one component
at a time, retaining only compact predecessor state/hash/coverage and
summary fields. All forty raw or decoded components are never retained
together; per-component memory refusals remain possible and explicit.

This collector composes previously verified proofs. It does not
regenerate their local source coefficients or modular eliminations, and
its output expressly says so. It must not be used to claim that an
arbitrary unverified artifact was mathematically checked, or that a
monolithic full-chain numerical rerun occurred. Root's successful
per-component write/check and independent acceptance records establish
the premise used by the composition. The per-panel --check, rather than
the collector, freshly regenerates every source update and witness in
that panel.

The eighteen bounded controls cover exact base replay; source
authentication before use; both prime certificates; actual denominator
eligibility; complete modular elimination and fallback/UNKNOWN
semantics; the simultaneous-update singular-intermediate counterexample;
complete small event and alias censuses; literal source1/g records;
precise integer gaps and no-event intervals; predecessor/power gates;
typed JSON/body corruption; unchanged source/arithmetic caps; and the
twenty-versus-sixty-four scope distinction. They do not acquire a target
panel before the campaign freeze.

Keep the128MiB worker target and2GiB reserve,4096-bit stored-rational
cap, original local64/80 limits,32MiB input and16MiB artifact caps.
There is no claim that a whole panel necessarily finishes under ten
seconds; a timed or reserve stop is retained and does not become PASS.
No second agent starts a scientific job.

Historical implementation handoff: no author execution, target panel
or final chain result is asserted. Subsequent root runs and exact
freezes belong in the branch progress log and separate review records,
without changing these frozen campaign instructions. A full finite
chain and a separate successful tail certificate would be needed for
the final permanent-threshold corollary; neither is assumed here.
