# Preregistered higher-arity native cluster discovery

This declaration is written before the first run of the higher-cluster
producer. The coordinating agent runs the bounded job; no computation has
been run by its author.

The object is the leading energy of the complete squarefree native
L-102707 primitive, with all factor allocations and the original kernel.
For a strictly increasing rational shape x and activation q in the simplex,
maximize exactly

`H_x(q) = sum_k sum_(|S|=|T|=k) q(S) q(T) |x(S)-x(T)|`.

Every cardinality band is retained. No Gram surrogate is substituted for
the physical observation: this is the analytically derived first cusp term
of its exact cluster expansion. The actual finite-kernel remainder is
proved separately and is not estimated by this combinatorial discovery.

Fixed panels, in this order:

1. r=2: (0,1).
2. r=3: (0,1,2), (0,1,4).
3. r=4: (0,1,2,3), (0,1,2,4), (0,2,3,4), (0,1,3,4),
   (0,1,4,6), (0,3,4,5).
4. Held-out discovery: r=5, (0,1,2,3,4); r=6, (0,1,2,3,4,5).

The r=4 analytical prediction is fixed before the run. Let a,b,c be the
adjacent gaps. If c>=a, put v=(c-a)/(3(2c-a)), u=v/2. The unique optimizer
should be `(u,1/2-u,1/2-v,v)`. If a>=c, reflect this formula. At a=c it is
the face `(0,1/2,1/2,0)`. Changing only b should not change the optimizer.
The r=5/r=6 answers are not prescribed, and a different face or pattern is
a valid discovery rather than a failed run.

The producer builds the exact symmetric matrix by enumerating all subset
pairs of equal size, and independently rebuilds it from cumulative masses
and consecutive gaps. It enumerates every nonempty active support of the
simplex, solves the rational KKT system, and accepts only positive active
coordinates with correct inactive inequalities. Strict concavity proves
that one accepted point is the unique optimizer. All answers, source
counts, active supports and exact objective values are retained.

Hard caps: r<=6, 64 subsets, 63 active supports, matrix dimension<=7,
integer shape coordinates between0 and12, one streamed job. No prime search,
floating-point optimization, external CAS, or numerical integration is used.
These rational shapes are limiting prime configurations; equal subset sums
on a shape wall are not claimed to be exact equal products of distinct
physical primes.
