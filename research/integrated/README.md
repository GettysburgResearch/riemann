## Packet policy

An integrated packet must contain readable mathematics, exact provenance, review evidence, scope boundaries, and the next missing step. It may summarize a large computation instead of copying every artifact, but it must identify the exact proof object and state whether the integration pass replayed it.

A packet never silently modifies a frozen claim. Corrections are separate objects. Alternate proofs and superseded forms remain discoverable through the source and internal alias records.
