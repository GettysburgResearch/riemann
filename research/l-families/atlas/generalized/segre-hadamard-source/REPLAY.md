# Exact replay contract

The producer has no executable dependency imports. It authenticates exact
captured Git blobs of the external claim/source notes, binds its own proof,
preregistration, contract and tests, and recomputes all declared arithmetic.
The captured notes are source attribution and interface records; no theorem
is established merely by hashing them.

Run from the repository worktree with the configured Python runtime:

    python research/l-families/atlas/generalized/segre-hadamard-source/replay.py --scout
    python research/l-families/atlas/generalized/segre-hadamard-source/replay.py --write
    python research/l-families/atlas/generalized/segre-hadamard-source/replay.py --check
    python -O research/l-families/atlas/generalized/segre-hadamard-source/replay.py --check
    python -m unittest discover -s tests -p test_segre_hadamard_source.py
    python -O -m unittest discover -s tests -p test_segre_hadamard_source.py

The parent serializes these jobs under the shared RAM gate. The scout only
constructs the ternary cube's degree-two multiplication and Koszul maps.
The complete packet has eleven bounded source complexes, with each chain
sum capped at 5,000 and each weight block at 800. Rational image bases carry
the literal factor-permutation action; the quotient traces are not inferred
from scalar Hilbert coefficients.

Separate character controls enumerate binary permutations only up to `8!`,
and evaluate small fixed diagonal matrices through the declared degree bound
plus three exact tail coefficients. Those finite checks do not establish an
all-grade theorem. The source theorem and its explicitly imported classical
ingredients provide the all-grade statement.

The fixture records actual Tor characters and a digest of each literal
differential, all character panels, strict scope flags, and canonical-LF
hashes for the owned files. Snapshot authentication reconstructs the pinned
LF Git blobs after normalizing Git's possible CRLF checkout conversion;
mathematical-byte changes are rejected. The complete ordered source-pin list
is fixed, so deleting an input cannot produce a passing incomplete capture.
