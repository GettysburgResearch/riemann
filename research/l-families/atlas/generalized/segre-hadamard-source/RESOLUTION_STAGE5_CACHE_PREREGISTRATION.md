# Durable stage-five resolution acquisition

The immutable staged producer is `full_resolution_replay.py` at `b1c48ff9f09ec521a7f33b2ecbf81f661e8145cd`. Its degree-five run succeeded, but two later runs were stopped by the machine-wide free-memory reserve while repeating that work. This separate acquisition does not change the frozen producer, its maps, or any scientific hypothesis.

Root will run `resolution_stage5_cache.py --acquire` once. It calls the authenticated frozen `build_maps(5)` and atomically writes **all** returned data to `resolution_stage5.pending.json`: F0, D1, both parts of D2, the degree-five D3 columns, every original-coordinate kernel vector, basis and matrix digests, every lower-degree multiple, and every selected quotient class. This file is only an acquired candidate, not a certified cache. Atomic replacement after flush/fsync prevents a partially written file from replacing a complete acquisition.

A separate root command `--verify-pending` reconstructs the actual three graded matrices and certifies the candidate without repeating the expensive rational kernel elimination:

1. Authenticate the source algorithm, source preregistration and already frozen stage-five summary before importing code. Reauthenticate all predecessor maps through that algorithm. Compare the complete cached F0 and D1 with the frozen primitive source.
2. Reconstruct every ordered free-module basis and graded matrix from its polynomial maps. Check their complete weight lists and stream digests against the candidate.
3. Check every cached integer kernel vector has zero composition, a single homogeneous weight, primitive positive normalization, and a distinct largest nonzero coordinate. The distinct largest coordinates prove rational linear independence.
4. Certify the complementary matrix rank by exact finite-field elimination on each original weight block. The only allowed primes, in fixed order, are 65521 and 1000003; their primality is checked by bounded trial division. A field rank is a lower bound for rational rank of the integer matrix. An independent family of r rational kernel vectors gives the opposite bound rank <= number of columns-r. Equality therefore certifies the full rational kernel. If neither declared prime reaches that bound, verification stops; no unregistered prime or rank assumption is substituted.
5. Retain the finite-field pivot rows and source-column indices as rank witnesses. Recompute the actual 650 lower-degree multiples, their rank639, and the20 new quotient classes with the frozen exact quotient selector. Reconstruct both D2 parts and the11 degree-five D3 columns from the certified original-coordinate vectors, and compare every polynomial entry and all Tor weights.

Only after those checks does the producer atomically write `resolution_stage5.cache.json`. Root must freeze the complete cache and verifier bytes before a later, separate continuation wrapper may use it. The continuation will authenticate that exact cache commit/blob and rerun the cheap witness verification. Neither a summary alone nor an unfrozen pending file is a permitted continuation input.

The original 512 supported-row/column block cap, 4096 exact-bit cap, 90000 total rows, 16000 total columns and64 MiB artifact cap remain unchanged. No root memory reserve is lowered. Finite-field arithmetic certifies rational rank; it does not replace the rational maps or their compositions. Diagnostic intermediate bit counts are inherited from the frozen algorithm, while all load-bearing maps, dimensions, kernels and minimality quotients receive the checks above.

The candidate and certified cache bind this declaration, verifier and tests. Strict canonical JSON distinguishes bool/int/float aliases and rejects nonfinite values. A root reserve stop after acquisition can be resumed with `--verify-pending`; it cannot promote an unverified prefix. A stop inside acquisition still requires acquisition again. This is a resource-control change, not a new minimal-resolution theorem.
